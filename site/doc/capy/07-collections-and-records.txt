:title
7. Arrays, tuples, and structs

:content
Use an array for an ordered collection of one type. Use a tuple for a short fixed group. Use a struct when fields need names.

## Arrays

:example capy render
function RENDER(request : dval) {
    var names := ["Ada", "Grace"]
    print(names[0], "\n")
}

:output
Ada

:content
Array indexes start at zero. An invalid index traps.

Declare the item type when an array starts empty:

:example capy render
function RENDER(request : dval) {
    var names : [string] = []
    names.push("Ada")
    print(names[0], "\n")
}

:content

`push`, `pop`, `insert`, `remove`, `clear`, `reserve`, and `resize` change an array.

## Array values

An array is a mutable reference value inside one workspace:

:example capy render
function append_three(values : [s32]) {
    values.push(3)
}

function RENDER(request : dval) {
    var first := [1, 2]
    var second := first
    append_three(second)
    print(first[2], " ", second[2], "\n")
}

:content

Assignment and parameter passing share the array identity. Returns and captures also share it. Content mutation through a parameter affects the caller. A parameter binding remains immutable, so `values = [3]` is invalid. Array growth preserves identity.

A `for` loop reads array items in order:

:example capy render
function RENDER(request : dval) {
    var names := ["Ada", "Grace"]
    for name, index := names {
        print(index, ": ", name, "\n")
    }
}

:content

The optional index follows the value and has type `s32`. The loop rechecks the current array length. It safely stops after shrinkage and can visit appended items. The loop retains each current managed item while the body runs.

The loop item is a value, not an assignable array position. Use an index to replace an item.

## Tuples

A tuple is immutable. It has fixed positions and can contain different types:

:example capy render
function RENDER(request : dval) {
    var result := (200, "ok")
    print(result[0], " ", result[1], "\n")
}

:content

`(value)` only groups an expression. It does not create a one-item tuple.

A tuple can spread into matching function parameters:

:example capy render
function add(left : s32, right : s32) s32 { -> left + right }

function RENDER(request : dval) {
    var pair := (20, 22)
    var answer := add(...pair)
    print(answer, "\n")
}

:content

## Structs

A struct defines a named fixed layout:

:example capy render
struct Point {
    x : s32
    y : s32
}

function RENDER(request : dval) {
    var point := Point(3, 4)
    print(point.x, " ", point.y, "\n")
}

:content

The generated constructor takes fields in declaration order. A struct instance is a mutable reference value inside one workspace. Assignment, parameters, returns, and captures share its identity. Struct fields are assignable:

:example capy render
struct Point {
    x : s32
    y : s32
}

function move_right(point : Point) {
    point.x = point.x + 1
}

function RENDER(request : dval) {
    var point := Point(3, 4)
    move_right(point)
    print(point.x, "\n")
}

:content

The field mutation affects the caller. The parameter binding itself remains immutable.

A receiver-first function can use method syntax:

:example capy render
struct Point {
    x : s32
    y : s32
}

function total(point : Point) s32 { -> point.x + point.y }

function RENDER(request : dval) {
    var point := Point(3, 4)
    print(point.total(), "\n")
}

:content

This is the same call as `total(point)`.

## Choose the right shape

Use an array when every item has one static type. Use a tuple for a small fixed return value. Use a struct for application data with a stable shape. Use a `dval` map or list for decoded input and data that crosses a Bearer boundary.

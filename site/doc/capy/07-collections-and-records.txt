:title
7. Arrays, tuples, and structs

:content
Use an array for an ordered collection of one type. Use a tuple for a short fixed group. Use a struct when fields need names.

## Arrays

:example capy render
function RENDER {
    var names := ["Ada", "Grace"]
    print(names[0], "\n")
}

:output
Ada

:content
Array indexes start at zero. An invalid index traps.

Declare the item type when an array starts empty:

```capy
function RENDER {
    var names : [string] = []
    names.push("Ada")
    print(names[0], "\n")
}
```

`push`, `pop`, `insert`, `remove`, `clear`, `reserve`, and `resize` change an array.

## Array values

Arrays use copy-on-write value semantics:

```capy
function RENDER {
    var first := [1, 2]
    var second := first
    second.push(3)
    print(first[0], " ", second[2], "\n")
}
```

`first` still has two items. Capy shares storage until one copy changes.

A `for` loop reads array items in order:

```capy
function RENDER {
    var names := ["Ada", "Grace"]
    for name = names {
        print(name, "\n")
    }
}
```

The loop item is a value, not an assignable array position. Use an index to replace an item.

## Tuples

A tuple has fixed positions and can contain different types:

```capy
function RENDER {
    var result := (200, "ok")
    print(result[0], " ", result[1], "\n")
}
```

`(value)` only groups an expression. It does not create a one-item tuple.

A tuple can spread into matching function parameters:

```capy
function add(left : s32, right : s32) s32 { left + right }

function RENDER {
    var pair := (20, 22)
    var answer := add(...pair)
    print(answer, "\n")
}
```

## Structs

A struct defines a named fixed layout:

```capy
struct Point {
    x : s32
    y : s32
}

function RENDER {
    var point := Point(3, 4)
    print(point.x, " ", point.y, "\n")
}
```

The generated constructor takes fields in declaration order.

A receiver-first function can use method syntax:

```capy
struct Point {
    x : s32
    y : s32
}

function total(point : Point) s32 { point.x + point.y }

function RENDER {
    var point := Point(3, 4)
    print(point.total(), "\n")
}
```

This is the same call as `label(user)`.

## Choose the right shape

Use an array when every item has one static type. Use a tuple for a small fixed return value. Use a struct for application data with a stable shape. Use a DValue map or list for decoded input and data that crosses a Bearer boundary.

## Strings

A `string` stores bytes. String literals use double quotes. They may span lines. Supported escapes are `\n`, `\r`, `\t`, `\"`, and `\\`. Other escape sequences are compile errors.

```capy
var first := "Ada"
var last := "Lovelace"
var full := first + " " + last
```

The `+` operator concatenates strings. `==` and `!=` compare their bytes. `length(text)` returns the byte count. Bearer provides functions such as `substr`, `strpos`, `find`, `contains`, `replace`, `lower`, `upper`, `trim`, `split`, and `join`. String offsets refer to bytes, not Unicode characters. Negative substring starts count from the end, and a negative length excludes bytes from the end.

```capy
var words := split("one,two,three", ",")
print(join(words, " | "))
```

Use the API reference for each function's handling of empty strings, negative offsets, and missing matches.

## Markup

A markup expression keeps HTML readable and escapes inserted text:

```capy
var title := "Tea & Biscuits"
var page := <>
    <article>
        <h1><?= title ?></h1>
    </article>
</>
```

Bearer escapes strings inside `<?= value ?>`. It formats scalar numbers and booleans as text. An inserted `markup` value keeps its existing HTML.

Use `<?: value ?>` only when `value` already has type `markup`. Use `trusted_markup(value)` to convert a trusted HTML string:

```capy
var icon := trusted_markup("<svg aria-hidden='true'>...</svg>")
var button := <><button><?: icon ?> Save</button></>
```

Never give untrusted data to `trusted_markup`. This includes request values, database text, and remote content. Keep untrusted data as strings and use escaped interpolation.

You can store, return, nest, and print markup. Each interpolation expression runs once. Dynamic markup computes one exact escaped result and remains ARC-managed like a string.

Inside literal markup, write `\<>` or `\</>` when the delimiter text itself must appear without opening or closing a fragment. Use markup to produce HTML in Capy handlers and components.

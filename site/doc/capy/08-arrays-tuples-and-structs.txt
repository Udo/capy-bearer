:title
8. Arrays, tuples, and structs

:content
## Arrays

An array contains values of one static type. Write its type as `[T]`:

```capy
var colors := ["red", "green", "blue"]
print(colors[0])
```

Array indexes start at zero. An index outside the array traps and reports its source location. Empty `pop`, invalid `insert` or `remove`, and negative `reserve` or `resize` values also trap. A typed declaration can create an empty array:

```capy
var colors : [string] = []
colors.push("red")
colors.push("green")
colors[0] = "blue"
```

Arrays provide vector operations:

- `push(value)` adds an item.
- `pop()` removes and returns the last item.
- `insert(index, value)` adds an item at an index.
- `remove(index)` removes and returns an item.
- `clear()` removes all items.
- `reserve(capacity)` reserves storage.
- `resize(length, fill)` changes the length.
- `capacity()` returns the reserved item count.

Assignment and parameter passing have value semantics. Changing a copy does not change the original. Capy uses copy-on-write storage to avoid an immediate deep copy, including for nested arrays and managed elements.

Use `for` to read each value:

```capy
for color = colors {
    print(color, "\n")
}
```

Spread arrays into another literal or a variadic call:

```capy
var more := [...colors, "purple"]
print(...more)
```

Arrays can contain narrow or wide scalars, strings, and managed aggregate values. Use a list-shaped `dval` when data must cross an API or unit boundary.

## Tuples

A comma expression creates a tuple. A tuple has a fixed length and can contain different types:

```capy
function dimensions() (s32, s32) {
    (640, 480)
}

var size := dimensions()
print(size[0], " x ", size[1])
```

`()` is the empty tuple. `(value)` groups an expression and does not create a one-item tuple. The compiler treats `use(a, b)` and `use((a, b))` as different calls. A tuple can spread into fixed call parameters with `use(...tuple)`.

Tuple layouts can own managed values, but they do not yet accept `s64`, `u64`, or `f64` fields.

## Structs

A struct is a named value with declared fields:

```capy
struct User {
    name : string
    active : bool
}

var user := User("Ada", true)
print(user.name)
```

The generated constructor uses field declaration order. The compiler checks member names. You can add other constructor overloads by declaring functions named `User`, but you cannot replace the generated field constructor.

A struct can spread into call parameters in field declaration order. Struct layouts can own managed values, but they do not yet accept `s64`, `u64`, or `f64` fields.

A field can hold a function value:

```capy
struct Formatter {
    format : function(value : string) string
}
```

The call `formatter.format("text")` invokes that field. Dot syntax can also call a function that takes the receiver as its first argument.

Use structs for data with a stable shape. Use DValues for request data, decoded JSON, database rows, and messages between units.

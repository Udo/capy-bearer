:title
5. Operators and control flow

:content
## Operators

The arithmetic operators are `+`, `-`, `*`, `/`, and `%`. Both operands must have the same numeric type. Unary `-` supports `s32`, `s64`, and `f64`. The `%` operator supports integer types but not `f64`. Integer arithmetic uses the corresponding WebAssembly signed or unsigned operation; division by zero traps.

The comparison operators are `==`, `!=`, `<`, `<=`, `>`, and `>=`. Their operands must have the same type. The boolean operators are `!`, `&&`, and `||` and require `bool` values. The `&&` and `||` operators use short-circuit evaluation. Capy evaluates the right side only if the result requires it.

```capy
if enabled && count > 0 {
    print("ready")
}
```

The `..` operator creates a half-open `s32` range. The range `0..3` contains `0`, `1`, and `2`. A range whose start is not below its end is empty.

## Conditions

An `if` condition must have type `bool`:

```capy
if score >= 90 {
    print("excellent")
} else {
    print("keep going")
}
```

An `if` expression currently has type `void`, including when it has an `else` branch. Assign to an outer variable when the branches must choose a later value.

## Loops

Use `while` for a loop controlled by a condition:

```capy
var count := 0
while count < 3 {
    print(count, "\n")
    count = count + 1
}
```

Use `for` for ranges and collections. A range or array loop has one binding:

```capy
for number = 0..3 {
    print(number, "\n")
}

for item = ["red", "green", "blue"] {
    print(item, "\n")
}
```

A DValue loop can provide a value alone or both a key and a value:

```capy
for key, value = profile {
    print(key, " = ", dval_to_string(value), "\n")
}
```

Use `break` to leave the nearest loop. Use `continue` to start the next iteration. Neither accepts a value. Use `return` to leave the current function and provide its result. Capy releases owned values on each normal loop, `break`, `continue`, and `return` path.

:title
1. Getting started

:content
A Capy program is a text file with the `.capy` extension. Save the file in Bearer's configured site directory. Bearer compiles the file when you request it. Bearer recompiles the file after its source changes.

## Your first web page

Create `site/hello.capy`:

```capy
function RENDER {
    print("Hello, world!")
}
```

Open `/hello.capy` in a browser. Bearer calls `RENDER` for a normal HTTP request. `print` adds text to the response body.

Use a markup expression to write HTML:

```capy
function RENDER {
    var name := "Ada"
    print(<>
        <main>
            <h1>Hello, <?= name ?></h1>
        </main>
    </>)
}
```

Bearer escapes the text inside `<?= ... ?>` for HTML.

## A command-line program

Use `CLI` to run a file through Bearer's command-line tool:

```capy
function CLI {
    print("Hello from the command line\n")
}
```

Run this command from the project directory:

```text
scripts/bearer-cli /hello.capy
```

A source file can contain helper functions, constants, structs, and Bearer handlers. Most guide examples use `CLI` because it shows output directly. The same language also supports pages, components, custom HTTP servers, WebSocket handlers, lifecycle hooks, and durable tasks. Read the handler guide for the complete handler list and parameter rules.

:title
3. Values and types

:content
## Purpose

Use types to describe each value before the program runs. Capy checks types when it compiles a source file.

## Minimal executable example

:example capy render
struct User {
    name : string
    active : bool
}

type Count = s64

function RENDER {
    var title := "Capy"
    var enabled := true
    var small := 7
    var signed : Count = 8s64
    var unsigned := 9u64
    var ratio := 2.5
    var empty := ""
    var missing := none
    var tags := ["guide", "types"]
    var point := (3, 4)
    var user := User("Ada", enabled)
    var profile := {nickname: "Ada"}

    print(title, "|", small, "|", signed, "|", unsigned, "|", ratio, "|")
    print(tags[0], "|", point[1], "|", user.name, "|", profile.nickname, "|")
    print(empty == "", "|", missing?, "\n")
}

:output
Capy|7|8|9|2.5|guide|4|Ada|Ada|true|false

## Output

The program writes:

```text
Capy|7|8|9|2.5|guide|4|Ada|Ada|true|false
```

## Explanation

`string` stores bytes. `bool` has the values `true` and `false`. An integer literal has type `s32` by default.

Use `s64` and `u64` suffixes for wide integer literals. A decimal point or exponent makes an `f64` literal. The compiler rejects a literal outside its selected type range.

`dval` is a copied dynamic value. `none` has type `dval` and represents missing data. An empty string is a present string value. It is not `none`.

`missing?` is false because `missing` is `none`. The empty string comparison is true because `empty` has a string value.

`[T]` is an array of one item type. A tuple has fixed positions and can use different types. A struct is a named value with declared fields.

A `type` alias is a compile-time spelling for another type. `Count` has the same type identity as `s64`. It creates no runtime value or tag.

## Common variants

State a local type when inference is not clear:

```capy
var total : u64 = 12u64
```

Result: compiles.

Use a DValue list when data must cross a Bearer boundary:

```capy
var items := dval(["one", "two"])
```

Result: compiles.

Use a map literal for a dynamic record:

```capy
var settings := {theme: "dark", alerts: true}
```

Result: compiles.

## Edge cases

A bare list is a typed array. A list inside `dval(...)` becomes a DValue list. Arrays and DValue lists are different value types.

Use bracket indexing for DValue keys that are dynamic, numeric, or not identifiers. Use member syntax for an identifier key.

`void` is a function result type. It is not a local value or array item type. `module` is opaque and cannot enter an aggregate or DValue.

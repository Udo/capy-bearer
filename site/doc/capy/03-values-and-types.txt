:title
3. Types

:content
Every Capy value has a type. The compiler checks types before the program runs. It usually infers the type of a local value.

## Integers

An integer literal has type `s32` when no other type is stated:

:example capy render
function RENDER {
    var answer := 42
    print(answer, "\n")
}

:output
42

:content
State a wider type on the local, or construct the value explicitly:

```capy
function RENDER {
    var signed : s64 = 8
    var inferred_signed := s64(9)
    var unsigned : u64 = 10
    var inferred_unsigned := u64(11)
    print(signed, " ", inferred_signed, " ", unsigned, " ", inferred_unsigned, "\n")
}
```

Both forms produce the stated wide integer type. `var signed : s64 = s64(8)` also compiles, but the constructor repeats information already supplied by the annotation.

Parameters, function results, assignments, typed arrays, struct fields, and the other operand in an expression can also state the integer type. Thus, a function that accepts `u64` can receive the plain literal `8`. An unconstrained literal remains `s32`.

Arithmetic requires operands of the same type. Use a constructor when the surrounding code does not state the required type.

## Booleans and floating-point numbers

A `bool` is either `true` or `false`. Conditions require a boolean value.

```capy
function RENDER {
    var enabled := true
    var ratio := 2.5
    print(enabled, " ", ratio, "\n")
}
```

A decimal point or exponent makes an `f64` literal.

## Strings

A `string` stores bytes:

```capy
function RENDER {
    var name := "Ada"
    var empty := ""
    print(name, empty, "\n")
}
```

An empty string is still a string value. It is not missing data.

## Arrays, tuples, and structs

An array contains values of one type:

```capy
function RENDER {
    var names := ["Ada", "Grace"]
    print(names[0], "\n")
}
```

A tuple has a fixed number of positions, which can have different types:

```capy
function RENDER {
    var point := (3, 4)
    print(point[0], " ", point[1], "\n")
}
```

A struct gives names to fixed fields:

```capy
struct Point {
    x : s32
    y : s32
}

function RENDER {
    var point := Point(3, 4)
    print(point.x, " ", point.y, "\n")
}
```

The collections chapter covers these types in detail.

## Dynamic values and none

A `dval` holds data whose shape is known only at run time. The `none` value represents missing dynamic data:

```capy
function RENDER {
    var profile := {name: "Ada"}
    var missing := none
    print(profile.name, " ", missing?, "\n")
}
```

`none` is different from `""`, `false`, an empty map, and an empty list. The dynamic-values chapter explains safe reads and conversions.

## Type aliases

A type alias gives another name to a type:

```capy
type Count = s64

function RENDER {
    var total : Count = 12
    print(total, "\n")
}
```

An alias does not create a new runtime type.

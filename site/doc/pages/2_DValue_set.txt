:params
value : Capy `dval` to replace
source : replacement `dval`
s, p, f : C++-only string, pointer, and `f64` overload values

:returns
replacement `dval` in Capy. C++ changes the receiver and returns nothing

:see
0_DValue
2_DValue_set_bool
2_DValue_set_array

:content
`dval_set(value, source)` replaces the target content. It mutates `value` and returns that same identity. All workspace aliases observe the mutation. Assigning the result back remains valid.

A custom export or C++ boundary copies BRRB. Identity does not cross that boundary.

Capy does not accept a C++ pointer or `StringMap` overload. Use `dval(...)` to create the source value.

## C++ API

`DValue::set()` changes the object in place. C++ overloads accept a string, pointer, f64, `DValue`, or `StringMap`.

:example capy render
var value := dval_set(dval(""), "hello")
print(value, "\n")

:example cpp render
DValue v;
v.set("hello");
print(v.to_string(), "\n");

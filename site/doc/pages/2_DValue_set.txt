:title
Replace a dynamic value

:sig
function dval_set(value : dval, source : as dval) dval

:params
value : target value
source : replacement value

:returns
The changed target value.

:content
`dval_set` replaces the content of `value`. It changes and returns the target value.

:example capy render
var value := dval("")
value = dval_set(value, "hello")
print(value, "\n")

:sig
String time_format_relative(u64 timestamp, String format_very_recent = "", u64 medium_recency_seconds = 0, String format_medium_recent = "", u64 not_recent_seconds = 0, String format_not_recent = "")

:params
timestamp : Capy Unix timestamp to compare with the current time
format_very_recent : text for recent timestamps. An empty value uses `just now`.
medium_recency_seconds : recent cutoff in seconds. Zero uses `90`.
format_medium_recent : text after the recent cutoff. An empty value uses `%deltaM minutes ago`.
not_recent_seconds : older cutoff in seconds. Zero uses `5400`.
format_not_recent : text after the older cutoff. An empty value uses `%deltaH hours ago`.
return value : formatted relative-time string

:see
>time
>time_format_local
>time_format_utc

:content
Use `time_format_relative` to show a Capy timestamp relative to the current time. Pass the timestamp. You can also set the three output formats and their two cutoffs. The function returns a Capy `string`.

The formatter uses `format_very_recent` before `medium_recency_seconds`. It uses `format_medium_recent` before `not_recent_seconds`. It uses `format_not_recent` at or after that cutoff.

All time formatters support relative-time delta tokens.

Default behavior examples:


Capy uses `u64` and `string` values. C++ `.uce` uses `u64` and `String`, as the signature shows.

:example capy render
print(time_format_relative(0u64), "\n")

:example cpp render
print(time_format_relative(0, 0), "\n");

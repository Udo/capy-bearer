:sig
String request_script_url(Request& context)

:see
>uri
request_base_url
request_query_route

:content
In Capy, this function reads the current request. Do not pass a `Request` value.

It returns the script URL from `DOCUMENT_URI` or `SCRIPT_NAME`. For a front controller, it changes a URL that ends in `/index.uce` to the containing directory URL.

:example capy render
if request_script_url() != "" { print("script url\n") } else { print("empty\n") }

:example cpp render
print(request_script_url(context) != "" ? "script url\n" : "empty\n");

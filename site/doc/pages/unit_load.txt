:sig
module unit_load(String file_name)

:params
file_name : unit source path

:returns
a `module` value for the unit

:see
>ob
>unit_compile
>unit_info
>unit_call

:content
In Capy, call `unit_load(path)` to get a `module` value for a readable unit.

Call an exported function with `module.call(name[, input])`. Inputs and results are `dval` values. The no-input form passes an empty `dval` value. A Capy unit uses `EXPORTS` to declare callable functions.

Use `unit_load()` when several calls use one unit. A missing unit or export is an error.

C++ cannot use a Capy `module` value. Use `unit_call()` with the `DValue*` API instead. C++ exports use `EXPORT DValue* name(DValue*)`.

:example capy cli
var module := unit_load("examples/sample_unit.capy")
var output := module.call("echo", "hello")

:example cpp cli
DValue input; input = "hello";
DValue* output = unit_call("examples/sample_unit.uce", "echo", &input);
delete output;

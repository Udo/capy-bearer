:sig
function sqlite_insert_id(handle : u64) u64

:returns
Last inserted row ID.

:content
Use `sqlite_insert_id` after an insert that creates a row ID.

:example capy render
var db := sqlite_connect(":memory:")
sqlite_query(db, "create table t(id integer primary key)")
sqlite_query(db, "insert into t values(1)")
print(sqlite_insert_id(db), "\n")
sqlite_disconnect(db)

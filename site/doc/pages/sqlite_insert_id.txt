:sig
u64 sqlite_insert_id(SQLite* db)

:params
db : Capy SQLite connection value

:returns
last row ID for this connection

:see
>sqlite
sqlite_query
sqlite_affected_rows
sqlite_error
sqlite_disconnect
sqlite_connect
:content
Use `sqlite_insert_id` after `sqlite_query` inserts a row. Pass the Capy connection value. The function returns the last inserted row ID for that connection.

In C++, a null connection pointer returns `0`. C++ `.uce` uses an `SQLite*` pointer, as the signature shows.

:example capy render
var db := sqlite_connect(":memory:")
sqlite_query(db, "create table t(id integer primary key autoincrement, v text)")
sqlite_query(db, "insert into t(v) values('x')")
print("new row id: ", sqlite_insert_id(db), "\n")
sqlite_disconnect(db)

:example cpp render
SQLite* db = sqlite_connect("/tmp/doc-sqlite-insertid.db");
sqlite_query(db, "drop table if exists t");
sqlite_query(db, "create table t(id integer primary key autoincrement, v text)");
sqlite_query(db, "insert into t(v) values('x')");
print("new row id: ", sqlite_insert_id(db), "\n");
sqlite_disconnect(db);

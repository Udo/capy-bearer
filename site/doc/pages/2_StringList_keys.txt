:title
Get list keys

:sig
function keys(items : dval) dval

:returns
This function returns a list-shaped `dval` of string keys.

:content
`keys` returns the keys from a list-shaped `dval` in list order.

Use `dval_keys` when you need keys from any `dval` map or list.

:example capy render
var items := split("one,two", ",")
print(join(keys(items), ","), "\n")

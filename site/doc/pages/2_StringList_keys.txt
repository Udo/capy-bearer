:sig
DValue::keys() (legacy `StringList` page)

:content
`keys(items)` takes a list-shaped `dval` and returns a list-shaped `dval` of numeric string keys in list order. It returns copied values.

Capy has no separate `StringList` type. Use `dval_keys` when you need keys from any `dval` map or list.

## C++ API

`DValue::keys()` provides the legacy StringList operation.

:see
0_DValue
2_DValue_keys

:example capy render
var items := split("one,two", ",")
print(join(keys(items), ","), "\n")
:example cpp render
DValue items; DValue one; one = "one"; DValue two; two = "two";
items.push(one); items.push(two);
DValue item_keys = items.keys();
print(item_keys[0].to_string(), ",", item_keys[1].to_string(), "\n");

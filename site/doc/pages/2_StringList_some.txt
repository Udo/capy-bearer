:sig
DValue::some(String predicate) (legacy `StringList` page)

:content
`some(items, predicate)` takes a list-shaped `dval` and a string predicate. It returns true when any item satisfies the predicate. An empty list returns false.

Capy has no separate `StringList` type. It uses list-shaped DValues. This function does not mutate `items`.

## C++ API

`DValue::some()` provides the legacy StringList operation.

:see
0_DValue

:example capy render
var items := split("one,two", ",")
if some(items, function(value : string) bool { return value == "two" }) { print("found\n") } else { print("missing\n") }

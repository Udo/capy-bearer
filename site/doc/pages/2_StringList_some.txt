:sig
DValue::some(String predicate) (legacy `StringList` page)

:content
Removed as a separate StringList API. List-shaped `DValue::some()` returns true when any string satisfies the predicate.

:see
0_DValue

:example capy render
var items := split("one,two", ",")
if some(items, function(value : string) bool { return value == "two" }) { print("found\n") } else { print("missing\n") }
:example cpp render
StringList items = split("one,two", ",");
print(items.some([](String value) { return value == "two"; }) ? "found\n" : "missing\n");

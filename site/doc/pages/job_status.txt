:title
job_status

:sig
DValue job_status(u64 job_id)

:content
`job_status()` returns a `dval` status map for a job. The map can include `state`, `done`, `kind`, `pid`, and `job_id`.

`state` can be `pending`, `running`, `done`, `failed`, `cancelled`, or `missing`. Use it to poll without waiting for a result.

In Capy, pass the job ID as `dval`. In C++ `.uce`, pass the `u64` job ID shown above.

:see
>sys

:example capy render
var spec := dval({"cmd": "printf x", "timeout_ms": 1000})
var job := shell_spawn(spec)
job_await(job, 3000)
print("state: ", dval_to_string(job_status(job)["state"]), "\n")

:example cpp render
DValue spec; spec["cmd"] = "printf x"; spec["timeout_ms"] = (f64)1000;
u64 job = shell_spawn(spec);
job_await(job, 3000);
print("state: ", job_status(job)["state"].to_string(), "\n");

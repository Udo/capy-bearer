:sig
DValue& DValue::deref()
const DValue& DValue::deref() const

:returns
referenced target when resolvable, otherwise this value

:see
0_DValue
2_DValue_is_reference

:content
Capy has no `dval_deref` API. DValues share identity inside one workspace, but Capy does not expose C++ pointers or internal reference nodes. Thus, no explicit dereference operation is available.

C++ `deref()` follows internal reference links. It returns the resolved target when possible. Otherwise, it returns this value. Most C++ accessors dereference values automatically.


:capy-status unsupported

Capy exposes no host pointer or internal reference-node identity, so dereferencing has no equivalent.

:example cpp render
DValue target;
target.set("value");
DValue ref;
ref.set_reference(&target);
print("through ref: ", ref.deref().to_string(), "\n");

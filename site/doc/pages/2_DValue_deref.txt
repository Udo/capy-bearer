:sig
DValue& DValue::deref()
const DValue& DValue::deref() const

:params
return value : referenced target when resolvable, otherwise this value

:see
0_DValue
2_DValue_is_reference

:content
Capy has no `dval_deref` API. Capy passes `dval` values by copy. They have no pointer or alias identity, so no dereference operation is needed.

C++ `deref()` follows internal reference links. It returns the resolved target when possible. Otherwise, it returns this value. Most C++ accessors dereference values automatically.


:capy-status unsupported

Capy exposes no host pointer or alias identity, so dereferencing has no equivalent.

:example cpp render
DValue target;
target.set("value");
DValue ref;
ref.set_reference(&target);
print("through ref: ", ref.deref().to_string(), "\n");

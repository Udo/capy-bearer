:sig
bool mkdir(String path)

:params
path : directory path

:returns
`true` if the API creates the directory

:content
In Capy, this function creates one directory at `path`.

Use it when the parent directory already exists. It does not create missing parent directories. The C++ API has the same behavior.

:example capy render
var root := file_temp("/tmp/doc-mkdir-")
file_unlink(root)
mkdir(root)
if bool(file_stat(root)["is_dir"]) { print("created\n") } else { print("not created\n") }
dir_remove(root, true)

:example cpp render
dir_remove("/tmp/doc-mkdir-demo", true);
mkdir("/tmp/doc-mkdir-demo");
print(file_stat("/tmp/doc-mkdir-demo")["is_dir"].to_bool() ? "created" : "not created", "\n");
dir_remove("/tmp/doc-mkdir-demo", true);

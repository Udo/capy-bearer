:sig
u8 ws_opcode()

:params
return value : opcode of the current WebSocket message

:see
>websocket

:content
In Capy, `ws_opcode()` takes no inputs and returns the current WebSocket message opcode as `s32`.

Use it to identify the message type. Text messages use `1`, and binary messages use `2`.

Outside a WebSocket handler, it returns `0`. The zero value is the normal no-message result.

C++ returns the opcode as `u8` through the signature above.

:example capy render
print("opcode: ", u64(ws_opcode()), " (0 outside a WS frame)\n")

:example cpp render
// ws_opcode() returns the WebSocket frame opcode (1 text, 2 binary, 8 close, ...).
print("opcode: ", (u64)ws_opcode(), " (0 outside a WS frame)\n");

u64 DValue::to_u64(u64 default_value = 0) const

:params
u64 : fallback returned when conversion is not possible

:returns
converted value or the fallback

:see

:content
`u64(value)` is Capy's unsigned integer constructor for a `dval`. `u64(value, fallback)` returns the fallback for `none` or a failed conversion.

Exact decimal strings, in-range nonnegative finite f64 values, and booleans can convert. An f64 conversion truncates toward zero. Empty or invalid strings, negative values, overflow, maps, and lists return the fallback.

## C++ API

`DValue::to_u64()` also converts C++ pointers, resolved references, and one-child maps. It can clamp values outside its range. These C++ rules do not change the Capy constructor rules.

:example capy render
var value := dval("42")
print(u64(value), "\n")

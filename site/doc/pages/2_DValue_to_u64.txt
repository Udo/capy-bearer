:title
Convert to an unsigned integer

:sig
function u64(value : dval, fallback : u64 = 0) u64
function u64(value : string, fallback : u64 = 0) u64

:params
value : value to convert
fallback : value to return when conversion fails

:returns
The `u64` value or `fallback`.

:content
`u64(value)` converts a dynamic value to `u64`. Use the optional fallback for invalid input.

:example capy render
print(u64(dval("42")), "\n")

:content
`dval_to_u64(value, fallback)` takes a `dval` and an optional u64 fallback. It returns an unsigned integer. Use it to read an unsigned value from structured data.

Strings, f64 values, booleans, and one-child maps can convert. Empty or invalid strings return the fallback. Negative values clamp to zero. Oversized values clamp to `u64` maximum.

## C++ API

`DValue::to_u64()` also converts C++ pointers and resolved references.

:example capy render
var value := dval("42")
print(dval_to_u64(value), "\n")

:example cpp render
DValue value;
value = "42";
print(value.to_u64(), "\n");

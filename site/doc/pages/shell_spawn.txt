
:sig
u64 shell_spawn(DValue spec)

:params
spec : a `dval` map with `cmd` and optional `stdin`, `env`, and `timeout_ms` values

:returns
a `dval` job ID

:content
Capy `shell_spawn(spec)` starts a background shell job. Give it a `dval` with `cmd` and optional `stdin`, `env`, and `timeout_ms` values.

Use the job ID with `job_status()`, `job_await()`, `job_result()`, or `job_cancel()`.

The C++ API returns a `u64` job ID. Capy uses a `dval` job ID instead.

:errors
The shell interprets `cmd`. Do not build it from untrusted input. Start and command failures appear in the job status and result.

:see
>sys
shell_exec
job_status
shell_escape
job_result
cwd_set
job_await
:example capy render
var spec := dval({"cmd": "printf 'spawned in the background'", "timeout_ms": 1000})
var job := shell_spawn(spec)
var done := job_await(job, 3000)
print(dval_get_by_path(done, "result/stdout"), "\n")

:title
shell_spawn

:sig
u64 shell_spawn(DValue spec)

:content
Capy `shell_spawn(spec)` starts a background shell job. Give it a `dval` with `cmd` and optional `stdin`, `env`, and `timeout_ms` values.

It returns a `dval` job ID. Use that value with `job_status()`, `job_await()`, `job_result()`, or `job_cancel()`. Check the job result for command errors.

The C++ API returns a `u64` job ID. Capy uses a `dval` job ID instead.

:see
>sys

:example capy render
var spec := dval({"cmd": "printf 'spawned in the background'", "timeout_ms": 1000})
var job := shell_spawn(spec)
var done := job_await(job, 3000)
print(dval_to_string(dval_get_by_path(done, "result/stdout")), "\n")

:example cpp render
DValue spec; spec["cmd"] = "printf 'spawned in the background'"; spec["timeout_ms"] = (f64)1000;
u64 job = shell_spawn(spec);
DValue done = job_await(job, 3000);
print(done["result"]["stdout"].to_string(), "\n");

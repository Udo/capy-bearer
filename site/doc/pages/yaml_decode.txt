:sig
DValue yaml_decode(String s)

:params
s : YAML source string
return value : decoded `dval`

:see
>markup
yaml_encode

:content
In Capy, `yaml_decode(source)` accepts YAML source as a `string` and returns a `dval`.

Use it to read configuration data. The parser supports indentation-based maps and lists, quoted strings, booleans, comments, and block strings.

It does not support anchors, aliases, tags, directives, or complex inline collections. Numeric-looking values are strings. Convert them when you read them.

Malformed input raises a request-visible runtime error. C++ returns the same data as `DValue` through the signature above.

:example capy render
var value := yaml_decode("name: Ada\n")
print(dval_string(value["name"]), "\n")

:example cpp render
DValue value = yaml_decode("name: Ada\n");
print(value["name"].to_string(), "\n");

:content
`yaml_decode(source)` accepts YAML source as a `string` and returns a `dval`.

Use it to read configuration data. The parser supports indentation-based maps and lists, quoted strings, booleans, comments, and block strings.

YAML `null` and `~` become `none` in Capy and C++. Numeric-looking values are strings. Use a constructor to read a numeric value.

It does not support anchors, aliases, tags, directives, or complex inline collections. Malformed input raises a request-visible runtime error.

:example capy render
var value := yaml_decode("name: Ada\n")
print(value.name, "\n")

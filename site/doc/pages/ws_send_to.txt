:sig
function ws_send_to(connection_id : string, message : string, binary : bool) bool

:params
connection_id : client ID
message : message bytes to send
binary : `true` for a binary frame

:returns
`true` when the server queues the message.

:see
>websocket
ws_send
ws_scope
ws_opcode
ws_message
ws_is_binary
ws_connections

:content
`ws_send_to()` sends a message to one client.

:example capy ws
ws_send_to(string(request.websocket.connection_id, ""), "hello", false)

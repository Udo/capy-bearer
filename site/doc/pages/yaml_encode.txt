:sig
String yaml_encode(DValue t)

:params
t : tree to serialize as YAML
return value : YAML string

:see
>markup
yaml_decode
json_encode
xml_encode
0_DValue

:content
In Capy, `yaml_encode(value)` accepts a `dval` and returns YAML as a `string`.

Use it to write configuration data. It writes nested maps, lists, strings, booleans, and numeric `f64` values.

It does not write YAML tags, anchors, aliases, or custom schema features. The declaration has no error return.

C++ uses `DValue` and `String` values through the signature above.

:example capy render
var value := dval({"name": "Ada"})
if yaml_encode(value) != "" { print("yaml\n") } else { print("empty\n") }

:example cpp render
DValue value;
value["name"] = "Ada";
print(yaml_encode(value) != "" ? "yaml\n" : "empty\n");

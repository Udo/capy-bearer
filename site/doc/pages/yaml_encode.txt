:sig
String yaml_encode(DValue t)

:params
t : tree to serialize as YAML
return value : YAML string

:see
>markup
yaml_decode
json_encode
0_DValue

:content
In Capy, `yaml_encode(value)` accepts a `dval` and returns YAML as a `string`.

Use it to write configuration data. It writes nested maps, lists, strings, booleans, numeric f64 values, and `none`.

`none` encodes as YAML `null`. It does not write YAML tags, anchors, aliases, or custom schema features.

C++ uses `DValue` and `String` values through the signature above.

:example capy render
var value := dval({"name": "Ada", "middle": none})
print(yaml_encode(value))

:example cpp render
DValue value;
value["name"] = "Ada";
value["middle"].set_none();
print(yaml_encode(value));

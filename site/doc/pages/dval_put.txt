:sig
function dval_put(value : dval, key : string, child : as dval) dval

:params
value : the target `dval`
key : the child key to set
child : the replacement child

:returns
The same `dval` as `value`.

:content
`dval_put()` stores `child` at `value[key]` and returns `value`.

If needed, it creates a map shape before it stores the key.

:example capy render
var user := {:}
user = dval_put(user, "active", true)
print(bool(user.active), "\n")

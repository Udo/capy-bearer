:sig
String memcache_get(u64 connection, String key, String default_value = "")

:params
connection : open connection handle
key : entry key
default_value : value returned when no complete value is available

:returns
stored value or `default_value`

:see
>memcache

:content
In Capy, pass the `u64` handle from `memcache_connect()`.

This function returns the stored value for `key`. It returns `default_value` for a missing key, malformed response, truncated value body, or non-`VALUE` response.

:example capy render
var conn := memcache_connect()
if conn != 0 { memcache_set(conn, "doc_get_key", "stored value"); print(memcache_get(conn, "doc_get_key"), "\n") }
else { print("(requires a reachable memcached server)\n") }

:example cpp render
u64 conn = memcache_connect();
if(conn != 0) { memcache_set(conn, "doc_get_key", "stored value"); print(memcache_get(conn, "doc_get_key"), "\n"); }
else print("(requires a reachable memcached server)\n");

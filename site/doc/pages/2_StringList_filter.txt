:sig
DValue::filter(String predicate) (legacy `StringList` page)

:content
`filter(items, predicate)` takes a list-shaped `dval` and a string predicate. It returns a new list-shaped `dval` with the accepted strings in input order. The result uses consecutive numeric keys.

Capy has no separate `StringList` type. It uses list-shaped DValues. The function returns a new list and does not mutate `items`.

## C++ API

`DValue::filter()` provides the legacy StringList operation.

:see
0_DValue
2_DValue_filter

:example capy render
var items := split("one,two", ",")
var kept := filter(items, function(value : string) bool { return value == "two" })
print(join(kept, ","), "\n")
:example cpp render
StringList items = split("one,two", ",");
print(join(items.filter([](String value) { return value == "two"; }), ","), "\n");

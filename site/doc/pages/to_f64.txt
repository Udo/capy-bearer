:title
to_f64

:sig
f64 to_f64(String s, f64 fallback = 0)

:params
s : C++ text to parse
fallback : value for empty or invalid text

:returns
parsed C++ `f64` or `fallback`

:see
>types
2_DValue_to_f64

:capy-status cpp-specific

:content
`to_f64()` is a C++ API. It requires complete trimmed text. Empty or partial text, such as `3.5ms`, returns `fallback`.

Capy does not expose `to_f64`. Use `f64(value, fallback)`.

:example cpp render
print(to_f64("3.5"), "\n");

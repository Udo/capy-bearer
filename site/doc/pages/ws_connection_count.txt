:sig
u64 ws_connection_count(String scope = "")

:params
scope : optional scope identifier, defaults to the current WebSocket page scope
return value : number of connected WebSocket clients in that scope

:see
>websocket

:content
In Capy, `ws_connection_count()` returns the client count for the current WebSocket scope. `ws_connection_count(scope)` accepts a scope `string` and returns that scope's count as `u64`.

Use it to decide whether a scope has connected clients. The declaration has no error return.

C++ uses the optional `String` input in the signature above. Capy provides separate zero-input and one-input declarations.

:example capy render
print("connection count in this scope: ", ws_connection_count(), "\n")

:example cpp render
print("connection count in this scope: ", ws_connection_count(), "\n");

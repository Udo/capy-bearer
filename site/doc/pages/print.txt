:sig
void print(...val)

:params
...val : zero or more values to output

:content
`print(...values : as string)` constructs each non-string value as `string` and writes the values in order.

Use `print(...array)` to spread a `[string]` array. When an output buffer is active, `print()` writes to that buffer. Otherwise, it writes to the response.


:example capy render
print("hello docs\n")

:example cpp render
print("hello docs\n");

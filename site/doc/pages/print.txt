:sig
void print(...val)

:params
...val : one or more values to output

:see
>string

:content
In Capy, `print()` writes each supplied value to the current request output.

When an output buffer is active, `print()` writes to that buffer. Otherwise, it writes to the response.


:example capy render
print("hello docs\n")

:example cpp render
print("hello docs\n");

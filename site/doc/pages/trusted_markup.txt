:sig
function trusted_markup(value : string) markup

:params
value : trusted HTML text

:returns
trusted markup

:content
`trusted_markup` prevents HTML escaping for the value.

:warning
Use only HTML text that your code creates. Do not pass request, remote, or database text.

:example capy render
print(trusted_markup("<strong>safe</strong>"), "\n")

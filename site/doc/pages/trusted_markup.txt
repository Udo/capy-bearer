:sig
markup trusted_markup(string text)

:params
text : string content to mark as trusted

:returns
trusted markup value

:content
Use `trusted_markup()` when content is already trusted and must stay HTML, not escaped text.

Security warning: use `trusted_markup()` only on strings that your code builds. Do not pass request data, remote responses, or database text directly.

`<?: expression ?>` inserts trusted markup in HTML text without extra escaping.

:warning
`trusted_markup()` disables HTML escaping. Do not pass request data, remote responses, or database text to it.

:errors
Compilation fails when `trusted_markup()` receives the wrong argument count or a non-string input.

:example capy render
var safe := trusted_markup("<strong>safe</strong>")
print(safe, "\n")

:example cpp render
String safe = "<strong>safe</strong>";
print(safe, "\n");

:sig
bool file_truncate(String path, u64 size)

:params
path : path of the file to resize
size : new length in bytes

:returns
true when Capy resizes the file, otherwise false

:content
`file_truncate` sets a file length to `size` bytes. Use it to remove trailing content or extend a file. A smaller size discards trailing bytes. It returns false when Capy cannot resize the file.

:example capy render
file_put_contents("/tmp/doc-truncate.txt", "hello world")
file_truncate("/tmp/doc-truncate.txt", 5)
print(file_get_contents("/tmp/doc-truncate.txt"), "\n")

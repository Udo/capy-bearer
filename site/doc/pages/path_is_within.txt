:sig
function path_is_within(path : string, root : string) bool

:params
path : the path to test
root : the containing directory

:returns
`true` when `root` contains `path`

:content
`path_is_within()` resolves both paths and tests whether `root` contains `path`.

Both paths must exist. Resolution follows symbolic links and removes dot segments.

:example capy render
var root := "/tmp"
print(path_is_within("/tmp", root), "\n")

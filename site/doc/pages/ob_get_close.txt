:sig
String ob_get_close()

:returns
the current output buffer contents

:content
`ob_get_close()` returns the current output buffer as a `string` and closes it. Output returns to the previous buffer.

Use this to capture output before you change or print it.

:example capy render
ob_start()
print("hello ")
print("world")
var html := ob_get_close()
print("captured ", length(html), " chars: ", html, "\n")

:example cpp render
ob_start();
print("hello ");
print("world");
String html = ob_get_close();
print("captured ", html.length(), " chars: ", html, "\n");

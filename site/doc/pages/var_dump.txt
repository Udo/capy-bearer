:content
`var_dump(value)` accepts a `dval` and returns a readable `string` representation.

Use it to inspect a value while you debug. The API has no error return.

Capy supports a `dval` input only. C++ also provides the `StringMap` overload and optional prefix and postfix inputs shown above.

:example capy render
var user := dval({"name": "Ada", "role": "engineer"})
print(var_dump(user))

:example cpp render
DValue user;
user["name"] = "Ada";
user["role"] = "engineer";
print(var_dump(user));

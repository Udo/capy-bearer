:sig
String gz_uncompress(String compressed)

:params
compressed : gzip-format compressed bytes
return value : uncompressed bytes

:see
>sys
gz_compress
zip_list
zip_extract

:content
`gz_uncompress()` returns the uncompressed bytes from a gzip string. Use it to read data made by `gz_compress()` or another gzip writer.

It validates the gzip header, CRC32 footer, and uncompressed-size footer. It reports an error for unsupported or invalid gzip data.

:example capy render
var packed := gz_compress("round trip data")
print(gz_uncompress(packed), "\n")

:example cpp render
String packed = gz_compress("round trip data");
print(gz_uncompress(packed), "\n");

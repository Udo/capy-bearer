:sig
bool memcache_delete(u64 connection, String key)

:params
connection : open connection handle
key : entry key

:returns
`true` only for a `DELETED` server response

:see
>memcache
memcache_connect
memcache_get
memcache_command
memcache_get_multiple
memcache_set
memcache_escape_key
:content
Pass the `u64` handle from `memcache_connect()`.

This function deletes the entry for `key`. It returns `true` only when the trimmed server response is exactly `DELETED`.

:example capy render
var conn := memcache_connect()
if conn != 0 {
    memcache_set(conn, "doc_del_key", "v")
    memcache_delete(conn, "doc_del_key")
    print(memcache_get(conn, "doc_del_key", "gone"), "\n")
} else { print("(requires a reachable memcached server)\n") }

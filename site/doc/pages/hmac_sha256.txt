:sig
String hmac_sha256(String key, String data)

:params
key : secret string bytes
data : message string bytes
return value : raw 32-byte HMAC-SHA256 string

:content
`hmac_sha256()` returns the raw 32-byte HMAC-SHA256 for `key` and `data`. The returned string contains binary bytes.

Use it for binary protocols. Use `hmac_sha256_hex()` when you need printable text.

:example capy render
print("hex = ", hmac_sha256_hex("key", "message"), "\n")

:example cpp render
print("hex = ", hmac_sha256_hex("key", "message"), "\n");

:sig
String DValue::to_json(char quote_char = '"') const

:params
quote_char : quote character passed to string escaping
return value : JSON-ish scalar representation

:see
>types
0_DValue
json_encode

:content
`dval_to_json(value, quote)` takes a `dval` and an optional quote string. It returns this low-level JSON scalar representation. Strings are escaped and quoted. Numbers use the runtime numeric text. Booleans use `true` or `false`. Maps return `"(array)"`.

Use `json_encode` for full structured JSON. Capy cannot represent C++ pointer or reference values.

## C++ API

`DValue::to_json()` accepts a quote character. It represents pointers as `"(pointer)"` and references as `"(reference)"`.

:example capy render
var value := dval("Ada")
print(dval_to_json(value), "\n")

:example cpp render
DValue value;
value = "Ada";
print(value.to_json(), "\n");

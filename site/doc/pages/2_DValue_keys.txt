:title
Get child keys

:sig
function dval_keys(value : dval) dval

:params
value : source value

:returns
A list of child keys.

:content
`dval_keys` returns a new list of child keys. A scalar returns an empty list.

:example capy render
var user := dval({"name": "Ada", "role": "admin"})
print(join(sort(dval_keys(user)), ","), "\n")

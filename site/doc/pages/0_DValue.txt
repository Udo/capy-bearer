`dval` is Capy's structured value type. It stores scalars, maps, lists, and `none`.

A `dval` owns its data. Values that cross the Bearer boundary are copies. Capy has no DValue pointer, reference, or alias identity.

## Normal Use

Use a map-shaped `dval` for named fields. Use a list-shaped `dval` for ordered values.

- `{"name": "Ada"}` creates named fields.
- `dval(["Ada", "Lin"])` creates an ordered list.
- `value["name"]` and `value.name` read a named child.
- `value[0]` reads a list child.
- `string`, `bool`, `s32`, `s64`, `u64`, and `f64` are scalar constructors.
- `dval_has(value, key)` tests whether a key exists.
- `dval_key(value, key)` reads one named child.
- `dval_get_by_path(value, "a/b/c")` reads a nested child.
- `dval_require(value, key)` makes a strict read.

Use `T(value)` to convert a `dval`. Use `T(value, fallback)` when `none` or a failed conversion needs a fallback.

`none` is not an empty string. A child can exist and contain `none`. `dval_has` returns true for that child.

Member and index reads are safe. A missing child, unusable intermediate value, negative list index, or out-of-range list index returns `none`. These reads do not change the value.

`dval_key` returns `none` for a missing key or a scalar value. `dval_get_by_path` returns an empty string value when traversal fails. It does not return `none` for that case.

Use `dval_require` when a missing value is an error. It traps for a missing or unusable key or index.

## Updates

Capy update functions return a replacement value. Assign the result back to keep the update.

- `value = dval_put(value, key, child)` sets a named child.
- `value = dval_push(value, child)` adds a list child.
- `value = dval_pop(value)` removes the final list child.
- `value = dval_remove(value, key)` removes a named child.
- `value = dval_clear(value)` removes all children.
- `value = dval_set_array(value)` makes a list-shaped value.
- `value = dval_assign(value, source)` replaces the value.

Nested assignment updates a declared local `dval` root. It creates missing, `none`, and scalar intermediate maps.

Use `dval_map` and `dval_filter` when callbacks need each child as a `dval`. Use list functions for list-shaped string values.

## C++ API

C++ uses the `DValue` class. It supports calls such as `set`, `push`, `get_by_path`, and `to_string`.

C++ `operator[]` can create a missing child. Use `has`, `key`, or `get_by_path` when you must not create a child.

C++ `key` returns a pointer or `0`. C++ `get_by_path` returns an empty string value when traversal fails.

:example capy render
var user := {"name": "Ada", "active": true}
print(user.name, "\n")

:example cpp render
DValue user;
user["name"] = "Ada";
user["active"] = true;
print(user["name"].to_string(), "\n");

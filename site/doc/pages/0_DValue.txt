:title
Dynamic values

:sig
type dval

:see

:content
A `dval` stores scalar values, maps, lists, and `none`.

Use maps for named fields and lists for ordered values. Read children with `value.name`, `value["name"]`, or `value[0]`. A missing read returns `none` and does not change the value.

Use `dval_has` to test a key. Use `dval_require` when a missing child is an error. Use `string`, `bool`, `s32`, `s64`, `u64`, or `f64` to convert a value.

Update functions such as `dval_put`, `dval_push`, and `dval_set` change their target and return it. Pure functions such as `dval_map`, `dval_filter`, `dval_keys`, and `dval_values` return new values.

:example capy render
var user := dval({"name": "Ada", "tags": ["math"]})
print(user.name, " ", user.tags[0], "\n")

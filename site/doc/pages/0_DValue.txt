`dval` is Capy's structured value type. Use `dval(...)` to create a value from a scalar, a map, or a list.

A `dval` owns its data. Values that cross the Bearer boundary are copies. Capy has no DValue pointer, reference, or alias identity.

## Normal Use

Use a map-shaped `dval` for named fields. Use a list-shaped `dval` for ordered values.

- `dval({"name": "Ada"})` creates named fields.
- `dval(["Ada", "Lin"])` creates an ordered list.
- `value["name"]` reads a named child.
- `value[0]` reads a list child.
- The `dval_to_*` functions convert scalar values and accept optional fallbacks.
- `dval_has(value, key)` tests for a child.
- `dval_get_by_path(value, "a/b/c")` reads a nested child.
- `dval_to_json(value)` returns JSON text.

`dval_get_by_path` does not create missing path entries. Conversion functions return the fallback when conversion cannot produce the requested value.

## Updates

Capy update functions return a replacement value. Assign the result back to retain the update.

- `value = dval_put(value, key, child)` sets a named child.
- `value = dval_push(value, child)` adds a list child.
- `value = dval_pop(value)` removes the final list child.
- `value = dval_remove(value, key)` removes a named child.
- `value = dval_clear(value)` removes all children.
- `value = dval_set_array(value)` makes a list-shaped value.
- `value = dval_assign(value, source)` replaces the value.

Use `dval_map` and `dval_filter` when callbacks need each child as a `dval`. Use `map`, `filter`, `keys`, `unique`, `sort`, `some`, `every`, and `string_list_find` for list-shaped string values.

## Capy Limit

Capy does not support the C++ DValue reference APIs. It cannot preserve pointer identity, aliases, or references across a Bearer boundary.

## C++ API

C++ uses the `DValue` class. It supports method calls such as `set`, `push`, `get_by_path`, and `to_string`.

C++ `operator[]` can create a missing child. Use `has`, `key`, or `get_by_path` when you must not create a child.

## Examples


:example capy render
var user := dval({"name": "Ada", "active": true})
print(dval_to_string(user["name"]), "\n")

:example cpp render
DValue user;
user["name"] = "Ada";
user["active"] = true;
print(user["name"].to_string(), "\n");

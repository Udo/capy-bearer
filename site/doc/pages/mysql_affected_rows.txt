:sig
function mysql_affected_rows(handle : u64) u64

:params
handle : the MySQL connection handle

:returns
the number of changed rows

:content
`mysql_affected_rows()` returns the changed-row count for the latest applicable successful statement.

It returns zero when no applicable statement has run or a query fails.

:example capy render
var database := mysql_connect("localhost", "root", "", "")
if mysql_connected(database) { print(mysql_affected_rows(database), "\n") }
if database != u64(0) { mysql_disconnect(database) }

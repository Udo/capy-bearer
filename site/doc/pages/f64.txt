:sig
function f64(value : dval, fallback : f64 = 0.0) f64
function f64(value : string, fallback : f64 = 0.0) f64

:params
value : value to convert
fallback : value to return when conversion fails

:returns
An `f64` value, or `fallback`.

:content
`f64` converts a `dval` or a string to a floating-point value. The string form removes leading and trailing spaces. The value must contain a complete decimal number.

:errors
`f64` does not trap for an invalid conversion. It returns `fallback`.

:example capy render
print(f64(" 3.5 "), "\n")
print(f64("not a number", 9.0), "\n")

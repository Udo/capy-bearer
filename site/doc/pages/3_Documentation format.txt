:title
Documentation format

:content
Each page describes one Capy API. Use `:sig` for an existing Capy signature. Use `:content` for normal use. Use `:params`, `:returns`, and `:errors` for verified behavior.

Use `:example capy ENTRY` for a runnable Capy example. Put `:output` after a render example. ENTRY can be `render`, `cli`, `component`, `init`, `once`, or `ws`.

`capyc` reads Capy declarations from `src/capy/stdlib.capy`. The generator validates documented signatures and examples.

:example capy render
function RENDER(request : dval) {
    print("ok")
}

:output
ok

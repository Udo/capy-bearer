:sig
String cwd_get()

:params
return value : the current working directory

:see
>sys

:content
Returns the current working directory.

:example capy render
if cwd_get() != "" { print("have a working directory\n") } else { print("none\n") }
:example cpp render
print(cwd_get() != "" ? "have a working directory" : "none", "\n");

:sig
String cwd_get()

:returns
current working directory path

:see
>sys
file_put_contents
ls
file_mtime
mkdir
file_get_contents
path_join
:content
`cwd_get()` returns the current working directory path as a Capy string.

Use it before `cwd_set()` when you must restore the original directory.

The Capy call has the same arguments.

:example capy render
if cwd_get() != "" { print("have a working directory\n") } else { print("none\n") }

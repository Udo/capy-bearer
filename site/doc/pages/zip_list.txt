:sig
DValue zip_list(String zip_file_name)

:params
zip_file_name : path to the ZIP archive to inspect

:returns
`dval` containing archive metadata and an `entries` list

:see
>sys
zip_create
zip_read

0_DValue

:content
`zip_list(path)` accepts an archive path and returns metadata as a `dval`.

The result contains `file`, `count`, and an `entries` list. Each entry contains `name`, `index`, `size`, `compressed_size`, `is_directory`, and `method`.

Use it to inspect an archive or discover member names before `zip_read()`. The declaration has no error return.

C++ returns the same data as `DValue` through the signature above.


:example capy render
var archive := "/tmp/capy-doc-ziplist.zip"
zip_create(archive, dval({"a.txt": "alpha", "b.txt": "beta"}))
var listing := zip_list(archive)
var entries := listing["entries"]
print(s32(listing["count"]), " entries: ", entries[0]["name"], ", ", entries[1]["name"], "\n")
file_unlink(archive)

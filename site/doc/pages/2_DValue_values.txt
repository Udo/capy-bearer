:title
Get child values

:sig
function dval_values(value : dval) dval

:params
value : source value

:returns
A list of copied child values.

:content
`dval_values` returns a new list of child values. A scalar returns a one-item list.

:example capy render
var user := dval({"name": "Ada", "role": "admin"})
var values := dval_values(user)
print(dval_is_list(values), " ", length(values), "\n")

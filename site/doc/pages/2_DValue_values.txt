:sig
DValue DValue::values() const

:returns
a list-shaped `dval` containing each child value

:see
>types
0_DValue
2_DValue_each
2_DValue_push

:content
`dval_values(value)` takes a `dval` and returns a list-shaped `dval` of its child values. It copies each child. Map values use map order. List values use numeric list order.

A scalar produces a one-item list that contains the scalar. Capy returns copied values.

## C++ API

`DValue::values()` has the same result.

:example capy render
var user := dval({"name": "Ada", "role": "admin"})
var values := dval_values(user)
if dval_is_list(values) { print("list\n") } else { print("map\n") }

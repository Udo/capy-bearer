:sig
DValue split(String str, String delim)

:params
str : string to be split
delim : delimiter
return value : a list of strings

:see
>string

:content
Splits `str` into multiple strings using `delim` as the separator.

Every exact occurrence of `delim` creates a new entry in the returned list-shaped `DValue`.


:example capy render
print(join(split("a,b,c", ","), "|"), "\n")

:example cpp render
print(join(split("a,b,c", ","), "|"), "\n");

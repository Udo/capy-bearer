:sig
DValue split(String str, String delim)

:params
str : string to split
delim : exact separator string

:returns
list-shaped `dval` with string entries

:content
Capy `split(str, delim)` returns a list-shaped `dval` of strings. Give it a string and an exact separator string.

Each occurrence of `delim` starts the next entry. Empty entries remain in the result. Use it to separate text with a known delimiter.

The C++ API calls the result `DValue`. Capy uses the `dval` value type.

:example capy render
print(join(split("a,b,c", ","), "|"), "\n")

:example cpp render
print(join(split("a,b,c", ","), "|"), "\n");

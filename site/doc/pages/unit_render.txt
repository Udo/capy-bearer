:content
Call `unit_render(name)` to run another unit's `RENDER` function.

Capy has no `context` input. It uses the current request context. Use this function when the unit writes page output instead of returning a value.

A missing unit or `RENDER` function is an error. For an optional unit, call `unit_info()` before `unit_render()`.

C++ adds the `Request& context` overload in the signature above. If you omit it, C++ uses the active request context.


:example capy render
unit_render("examples/sample_unit.uce")

:example cpp render
unit_render("examples/sample_unit.uce");

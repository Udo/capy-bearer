:sig
dval call(handle : module, name : string)

:params
handle : module value returned by `unit_load()`
name : exported function name
input : optional `dval` input

:returns
exported function result

:content
`call(handle, name[, input])` calls an exported function on a loaded module and returns the function result as `dval`.
Use it after `unit_load()` when several calls should reuse the same module.
The handle is valid only for one request.

The two-argument form sends an empty `dval` when no input is needed.

A missing handle or missing export is an error.

## C++ API

C++ has no direct module-handle `call()` helper.
Use `unit_call(file_name, function_name, input)` with the same unit path and function name in C++.

:example capy render
var module := unit_load("/doc/examples/call_target.capy")
var empty := call(module, "default_input")
var echoed := call(module, "echo", {"name": "Ada"})
print(string(empty), "|", string(echoed.name, ""), "\n")

:example cpp render
DValue empty;
empty = "default";
DValue input;
input["name"] = "Ada";
DValue* echoed = unit_call("/doc/examples/call_target.capy", "echo", &input);
print(empty.to_string(), "|", (*echoed)["name"].to_string(), "\n");

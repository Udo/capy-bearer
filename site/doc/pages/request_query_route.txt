:content
`request_query_route()` is a C++ API. It reads the first keyless query-string segment and returns route metadata.

Its `raw_path` is normalized diagnostic input. Its `l_path` is the safe route, or an empty string when validation fails. Its `page` is the first `l_path` segment. Its `valid` value is true when `l_path` is safe.

Capy does not expose `request_query_route`. In a Capy `RENDER` handler, read `request.route`. Its fields are `path`, `page`, `raw_path`, and `valid`.

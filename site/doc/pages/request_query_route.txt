:content
In Capy, this function reads the current request. Do not pass a `Request` value.

It reads the first keyless query-string segment and returns route metadata:

- `raw_path` is normalized input. Treat it as diagnostic data, not a safe path.
- `l_path` is the safe full route, or an empty string when validation fails.
- `page` is the first segment of `l_path`, or an empty string when validation fails.
- `valid` is true when `l_path` is safe.

Use `l_path` below an application-controlled route root. Named query parameters can occur with the route.

:example capy render
var route := request_query_route("index")
if dval_is_array(route) { print("route\n") } else { print("empty\n") }

:example cpp render
DValue route = request_query_route(context, "index");
print(route.is_array() ? "route\n" : "empty\n");

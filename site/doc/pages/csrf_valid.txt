:sig
bool csrf_valid(String submitted_token, String session_name = "bearer-session", String token_name = "csrf_token")

:params
submitted_token : value from the request, usually `context.post["csrf_token"]`
session_name : session and cookie name
token_name : token namespace

:returns
`true` when the submitted token matches the session token

:content
`csrf_valid()` checks a submitted Capy CSRF token against the session token.

Pass the submitted value, session name, and token namespace. It returns `true` only for the active matching token. It starts the named session when necessary.

It does not create a missing token. Use it before you apply a change from a browser-submitted request.

The Capy call has the same arguments.

:example capy render
var token := csrf_token("bearer-doc-session")
if csrf_valid(token, "bearer-doc-session") { print("valid\n") } else { print("invalid\n") }
if csrf_valid("bad-token", "bearer-doc-session") { print("bad valid\n") } else { print("bad invalid\n") }

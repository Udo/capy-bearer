:sig
String sha256(String data)

:params
data : bytes to hash

:returns
raw 32-byte SHA-256 digest

:content
Use this function when another binary operation needs a SHA-256 digest.

It returns the raw 32-byte digest of `data`. Use `sha256_hex()` when you need printable text.

:example capy render
print(length(sha256("abc")), " raw bytes, hex = ", sha256_hex("abc"), "\n")

:example cpp render
print(sha256("abc").length(), " raw bytes, hex = ", sha256_hex("abc"), "\n");

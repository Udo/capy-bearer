:content
Capy does not support `reference_target`. DValues share identity inside one workspace, but Capy does not expose host pointers or C++ internal reference nodes.

## C++ API

`DValue::reference_target()` follows an internal reference chain and returns its final non-reference target pointer. It returns `0` for a non-reference, a null or self reference, or an unresolved chain.


:capy-status unsupported

Capy exposes no host DValue pointer or internal reference-node identity, so it cannot observe a C++ reference target.

:content
Capy does not support `reference_target`. Capy `dval` values are copies. They have no host pointer, alias, or reference identity.

## C++ API

`DValue::reference_target()` follows an internal reference chain and returns its final non-reference target pointer. It returns `0` for a non-reference, a null or self reference, or an unresolved chain.


:capy-status unsupported

Capy exposes no host DValue pointer or alias identity, so it cannot observe a reference target.

:example cpp render
DValue target;
target.set("data");
DValue ref;
ref.set_reference(&target);
print(ref.reference_target() == &target ? "points to target" : "elsewhere", "\n");

:sig
String trim(String raw)

:params
raw : text to trim

:returns
`raw` without leading or trailing whitespace

:see
>string
to_upper
float_val
to_lower
int_val
regex_split
html_escape
:content
Call `trim(raw)` to return a `string` without leading or trailing whitespace.

Use it to normalize text before validation or comparison. C++ uses the same input and return value.


:example capy render
print(trim("  docs  "), "\n")

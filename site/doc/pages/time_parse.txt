:sig
u64 time_parse(String time_string)

:params
time_string : text that contains a date, time, or both

:returns
the parsed Unix timestamp, or zero when Capy cannot parse the text

:see
>time
time_format_utc
time_format_relative
time_format_local

time_precise
usleep
:content
Call `time_parse(value)` with date or time text.

The function returns a `u64` Unix timestamp. It returns zero when it cannot parse `value`. Use it to convert external time text before you compare or format a timestamp.

C++ uses the legacy `time_string` parameter in the signature above. Its normal use case is the same.


:example capy render
if time_parse("1970-01-01 00:00:00") >= 0 { print("parsed\n") } else { print("bad\n") }

:sig
bool component_exists(String name)

:params
name : component path with an optional named handler

:returns
`true` when Bearer resolves the component file. Otherwise, `false`.

:see
>ob
component
component_render
component_resolve
1_COMPONENT

:content
`component_exists()` tests whether Capy can resolve a component file.

A colon and handler name do not affect this check.

Use this function before rendering an optional component. Its name resolution matches `component_resolve()`.

:example capy render
if component_exists("examples/sample_unit") { print("exists") } else { print("not found") }
print(" / ")
if component_exists("no_such_component") { print("exists\n") } else { print("not found\n") }
:example cpp render
print(component_exists("examples/sample_unit") ? "exists" : "not found", " / ", component_exists("no_such_component") ? "exists" : "not found", "\n");

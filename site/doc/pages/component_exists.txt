:sig
function component_exists(name : string) bool

:params
name : a component path with an optional named handler

:returns
`true` if Bearer resolves the component file. Otherwise, `false`.

:content
`component_exists()` checks whether Bearer can resolve a component file.

A named handler does not affect this check. Use this function before you render an optional component.

:example capy render
if component_exists("/tests/capy-request-context.capy") { print("exists\n") } else { print("missing\n") }

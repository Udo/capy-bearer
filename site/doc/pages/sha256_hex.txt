:sig
String sha256_hex(String data)

:params
data : bytes to hash

:returns
64-character lowercase hexadecimal SHA-256 digest

:content
Use this function when you need a printable SHA-256 digest.

It returns the SHA-256 digest of `data` as 64 lowercase hexadecimal characters. Use it for checksums, cache keys, and content fingerprints. Use `sha256()` when you need the raw 32-byte digest.

:example capy render
print(sha256_hex("abc"), "\n")

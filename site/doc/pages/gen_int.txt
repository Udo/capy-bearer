:sig
u64 gen_int(u64 from, u64 to, u64 index, u64 seed = 0)

:params
from : first range endpoint
to : second range endpoint
index : deterministic input position
seed : deterministic input seed, default `0`

:returns
deterministic `u64` noise value

:see
>noise

:content
`gen_int()` returns a deterministic `u64` noise value for `index` and `seed`. `from` and `to` set the output range.

Use the same inputs to reproduce procedural integer values. The C++ `.uce` call uses the declaration above.


:example capy render
var generated := gen_int(1, 1, 10)
print("int\n")

:example cpp render
print(gen_int(1, 1, 10) >= 1 ? "int\n" : "bad\n");

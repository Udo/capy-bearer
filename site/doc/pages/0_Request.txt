:title
Request snapshot

:sig
handler request : dval

:content
Each Capy handler receives `request : dval`. This value is a request snapshot.

The snapshot can contain `method`, `query`, `form`, `headers`, `cookies`, `body`, `files`, `route`, `url`, `server`, `session`, `props`, `config`, `call`, `connection`, `unit`, and `websocket`.

Use `string`, `s32`, or `bool` with a fallback to read scalar values. Use response, session, output, and WebSocket functions to change the active request.

:example capy render
print(string(request.query.name, "guest"), "\n")

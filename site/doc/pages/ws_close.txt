:sig
bool ws_close(String connection_id = "")

:params
connection_id : optional target client ID, defaults to the current WebSocket client

:returns
true if the target connection exists and was scheduled to close

:see
>websocket
ws_connection_count
ws_connection_id
ws_connections
ws_is_binary
ws_message
ws_opcode
:content
`ws_close()` closes the current WebSocket connection. `ws_close(connection_id)` accepts a connection ID and closes that connection.

The function returns `true` when it finds the target connection and queues its close. It returns `false` when the target does not exist.

Use it in a WebSocket handler when a client must disconnect. The false return is the normal missing-connection result.

C++ uses the optional `String` input in the signature above. Capy provides separate zero-input and one-input declarations.

:example capy render
if ws_close("example-connection-id") { print("close queued\n") } else { print("no such connection to close\n") }

:example cpp render
bool closed = ws_close("example-connection-id");
print(closed ? "close queued" : "no such connection to close", "\n");

:sig
void json_consume_space(String s, u32& i)

:params
s : JSON source string
i : current byte offset; advanced past JSON whitespace

:see
>string
json_encode
json_decode

:content
Advances `i` past JSON whitespace in `s`.

This helper is mainly useful when writing a parser that follows BEARER's JSON parsing rules. Most page code should call `json_decode()` instead.

Example:


:example capy render
var index := json_consume_space("   value", 0)
if index == 3 { print("advanced\n") }
else { print("not advanced\n") }

:example cpp render
u32 i = 0;
json_consume_space("   value", i);
print(i == 3 ? "advanced\n" : "not advanced\n");

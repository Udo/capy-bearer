:sig
void json_consume_space(String s, u32& i)

:params
source : JSON source text
index : byte offset where scanning starts

:returns
Capy byte offset after JSON whitespace

:see

:content
This internal helper returns the byte offset after JSON whitespace in `source`.

Use `json_decode()` for application code. Keep this helper for codec tests and parser work.

The C++ API advances its `u32&` offset argument. Both APIs scan byte positions.

:example capy render
var index := json_consume_space("   value", 0)
if index == 3 { print("advanced\n") }
else { print("not advanced\n") }

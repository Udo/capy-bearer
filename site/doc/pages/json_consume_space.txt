:sig
void json_consume_space(String s, u32& i)

:params
source : JSON source text
index : byte offset where scanning starts
return value : Capy byte offset after JSON whitespace

:see
>string
json_encode
json_decode

:content
In Capy, this function returns the byte offset after JSON whitespace in `source`.

Use it when you write a parser that must continue at a known JSON position. Most code should use `json_decode()` instead.

The C++ API advances its `u32&` offset argument. Both APIs scan byte positions.

:example capy render
var index := json_consume_space("   value", 0)
if index == 3 { print("advanced\n") }
else { print("not advanced\n") }

:example cpp render
u32 i = 0;
json_consume_space("   value", i);
print(i == 3 ? "advanced\n" : "not advanced\n");

:sig
DValue::sort() (legacy `StringList` page)

:content
`sort(items)` takes a list-shaped `dval` and returns a new list-shaped `dval` with strings in ascending order. It does not change `items`.

Capy has no separate `StringList` type. It uses copied `dval` values.

## C++ API

`DValue::sort()` provides the legacy StringList operation.

:see
0_DValue

:example capy render
var items := split("two,one", ",")
print(join(sort(items), ","), "\n")
:example cpp render
StringList items = split("two,one", ",");
print(join(items.sort(), ","), "\n");

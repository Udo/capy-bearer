:content
`request_query_path()` is a C++ API. It returns the first keyless query-string segment as a safe route path. For `/?workspace/projects&theme=dark`, it returns `workspace/projects`.

It returns `default_path` when no keyless route exists. It returns an empty string when the route is unsafe. Unsafe input includes dot segments, empty interior segments, backslashes, filename dots, and characters outside route segments.

Capy does not expose `request_query_path`. In a Capy `RENDER` handler, read `request.route.path`.

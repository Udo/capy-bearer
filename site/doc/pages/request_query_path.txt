:content
In Capy, this function reads the current request. Do not pass a `Request` value.

It returns the first keyless query-string segment as a safe route path. For `/?workspace/projects&theme=dark`, it returns `workspace/projects`.

If no keyless route exists, it returns `default_path`. If the route is unsafe, it returns an empty string. Unsafe input includes dot segments, empty interior segments, backslashes, filename dots, and characters outside ASCII letters, digits, `_`, and `-`.

`ROUTE_PATH` uses the same sanitizer.

:example capy render
if request_query_path("index") != "" { print("path\n") } else { print("empty\n") }

:example cpp render
print(request_query_path(context, "index") != "" ? "path\n" : "empty\n");

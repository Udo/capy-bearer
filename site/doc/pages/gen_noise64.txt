:sig
u64 gen_noise64(u64 index, u64 seed = 0)

:params
index : deterministic input position
seed : deterministic input seed, default `0`
return value : deterministic `u64` noise value

:see
>noise

:content
`gen_noise64()` returns a deterministic `u64` noise value for `index` and `seed`.

Use it for repeatable 64-bit integer noise. The C++ `.uce` call uses the declaration above.


:example capy render
var generated := gen_noise64(1u64, 2u64)
print("noise64\n")

:example cpp render
print(gen_noise64(1, 2) != 0 ? "noise64\n" : "zero\n");

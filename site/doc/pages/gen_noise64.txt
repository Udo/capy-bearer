:sig
u64 gen_noise64(u64 index, u64 seed = 0)

:params
index : deterministic input position
seed : deterministic input seed, default `0`

:returns
deterministic `u64` noise value

:see
>noise
gen_noise32
gen_float
gen_noise01
gen_int
draw_int
gen_sha1
:content
`gen_noise64()` returns a deterministic `u64` noise value for `index` and `seed`.

Use it for repeatable 64-bit integer noise. The Capy call uses the declaration above.


:example capy render
var generated := gen_noise64(1, 2)
print("noise64\n")

:sig
bool DValue::is_list() const

:params
return value : true when the value is an array with keys 0..n-1

:see
>types
0_DValue
2_DValue_set_array
2_DValue_push

:content
Use `dval_is_list(value)` in Capy to test whether a copied `dval` is a list. It returns `true` for a list-shaped map with keys from `0` through `size - 1`. An empty map is a list only after `dval_set_array()` or a list operation.

C++ `is_list()` applies the same rules after it dereferences the value.

:example capy render
var list := dval_push(dval([]), "Ada")
if dval_is_list(list) { print("list\n") } else { print("map\n") }

:example cpp render
DValue list;
DValue item; item = "Ada";
list.push(item);
print(list.is_list() ? "list\n" : "map\n");

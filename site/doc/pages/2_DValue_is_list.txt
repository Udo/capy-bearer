:title
Test for a list

:sig
function dval_is_list(value : dval) bool

:params
value : value to test

:returns
`true` for a list-shaped value.

:content
`dval_is_list` tests whether a value is a list. Use `dval_set_array` to make an empty list.

:example capy render
print(dval_is_list(dval(["Ada"])), "\n")

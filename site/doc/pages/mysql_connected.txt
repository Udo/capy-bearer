:sig
bool mysql_connected(MySQL* m)

:params
m : Capy MySQL handle

:returns
`true` when the handle has a live server connection

:see
>mysql

:content
In Capy, pass the opaque `u64` handle from `mysql_connect()`.

This function distinguishes a failed connection wrapper from a live server connection. It returns `false` for a failed wrapper in both Capy and C++.

:example capy render
var db := mysql_connect("localhost", "root", "", "")
if !mysql_connected(db) { print("database unavailable: ", mysql_error(db), "\n") }
else { print("database connected\n") }
if db != 0 { mysql_disconnect(db) }

:example cpp render
MySQL* db = mysql_connect();
if(!mysql_connected(db))
{
    print("database unavailable: ", mysql_error(db), "\n");
}
else print("database connected\n");
if(db != 0) mysql_disconnect(db);

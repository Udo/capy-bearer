:sig
function mysql_connected(handle : u64) bool

:params
handle : the MySQL connection handle

:returns
`true` when the handle has a live server connection

:content
`mysql_connected()` tests whether a MySQL handle has a live server connection.

Use `mysql_error()` to get the diagnostic when it returns `false`.

:example capy render
var database := mysql_connect("localhost", "root", "", "")
print(mysql_connected(database), "\n")
if database != u64(0) { mysql_disconnect(database) }

:sig
DValue DValue::filter(DValue keys) const
DValue DValue::filter(std::function<bool (const DValue& item, String key)> f) const

:params
keys : child keys to copy when using the key-list overload
f : predicate returning true for children to keep

:returns
filtered copy

:see
>types
0_DValue
2_DValue_map
2_DValue_keys

:content
Use `dval_filter(value, predicate)` in Capy to make a copied `dval` that contains matching values. The predicate receives an item and key. The function returns a new value. A list result keeps list shape and reindexes kept items. A map result keeps its keys. A scalar result is a one-item list when the predicate accepts it.

C++ also provides `filter(keys)`, which copies named children into a map. Its callback overload follows the same list, map, and scalar rules.

:example capy render
var user := dval({"name": "Ada", "email": "ada@example.test"})
var public_user := dval_filter(user, function(item : dval, key : string) bool { return key == "name" })
print(public_user["name"], "\n")

:example cpp render
DValue user;
user["name"] = "Ada";
user["email"] = "ada@example.test";
DValue public_user = user.filter({"name"});
print(public_user["name"].to_string(), "\n");

:title
Filter a dynamic value

:sig
function dval_filter(value : dval, predicate : function(value : dval, key : string) bool) dval

:params
value : source value
predicate : function that selects children

:returns
A new filtered value.

:content
`dval_filter` returns children for which `predicate` returns `true`. It keeps map keys and keeps list shape.

:example capy render
var value := dval({"name": "Ada", "role": "admin"})
var result := dval_filter(value, function(item : dval, key : string) bool { return key == "name" })
print(result.name, "\n")

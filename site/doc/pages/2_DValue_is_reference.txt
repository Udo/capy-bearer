:sig
bool DValue::is_reference() const

:params
return value : true when this node itself is a reference node

:see
0_DValue
2_DValue_reference_target
2_DValue_deref

:content
Capy has no `dval_is_reference` API. DValues share identity inside one workspace, but Capy does not expose the C++ internal reference tag. Thus, this test has no Capy equivalent.

C++ `is_reference()` tests this node's direct internal reference tag. Most C++ read methods dereference values automatically.


:capy-status unsupported

A boundary copies BRRB and does not preserve C++ internal reference tags. This predicate has no Capy equivalent.

:example cpp render
DValue target; target.set("x");
DValue ref; ref.set_reference(&target);
DValue plain; plain.set("y");
print(ref.is_reference() ? "ref" : "plain", " / ", plain.is_reference() ? "ref" : "plain", "\n");

:sig
function unit_info(path : string = "") dval

:params
path : unit path. An empty path selects the current unit

:returns
unit metadata

:see
units_list
unit_compile
type/request

:content
`unit_info` returns metadata for a unit.

:example capy render
var info := unit_info("capy-files.capy")
print(bool(info["source_exists"]), "\n")

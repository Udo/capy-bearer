:sig
DValue unit_info(String path = "")

:params
path : optional unit path. If empty, uses the current unit

:returns
unit metadata as a `dval`, or an empty value if Capy cannot resolve the unit

:see
>runtime
units_list
unit_compile
0_Request

:content
Call `unit_info()` for the current unit. Call `unit_info(path)` for another unit.

The function returns a `dval` value with available unit metadata. Fields can include paths, status, times, and exported APIs. Check that a field exists before you use it. An empty result means Capy cannot resolve the unit.

Use this function to inspect a unit before an optional call. Relative paths use the same unit path rules as unit calls. Counters describe the current runtime process.

C++ returns a `DValue` through the signature above. Use the same path and result checks.

:example capy render
var info := unit_info("examples/sample_unit.capy")
if dval_is_array(info) { print("unit_info() returns metadata for the unit\n") } else { print("empty metadata for the unit\n") }

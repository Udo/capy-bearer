:sig
String session_id_create()

:returns
new 64-character lowercase hexadecimal session ID

:see
>session
session_start
session_set
session_remove
session_destroy
response_cookie
:content
Use this function only when you need a new session ID without starting a session.

It returns a new 64-character lowercase hexadecimal ID. Use `session_start()` for the normal cookie and session-data flow.

:example capy render
if length(session_id_create()) > 0 { print("session id\n") } else { print("empty\n") }

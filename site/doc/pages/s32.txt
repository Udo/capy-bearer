:sig
function s32(value : dval, fallback : s32 = 0) s32
function s32(value : string, fallback : s32 = 0) s32

:params
value : value to convert
fallback : value for a failed conversion

:returns
A signed 32-bit integer, or `fallback`.

:content
`s32()` converts supported scalar values and integer text. It returns `fallback` when conversion fails.

:example capy render
print(s32("42", -1), "\n")

:sig
function http_request_async(request : dval) u64

:params
request : a map that describes an outbound request

:returns
A job ID.

:content
`http_request_async()` starts an outbound request and returns its job ID. Use `job_await()` or `job_result()` to get the response map.

The request map follows the `http_request()` rules.

:example capy render
var outbound := dval({"method": "GET", "url": "http://127.0.0.1/tests/capy-render.capy", "headers": {"Host": "bearer.openfu.com"}, "timeout_ms": 2000})
var job := http_request_async(outbound)
var done := job_await(dval(job), 3000)
print(s32(get_by_path(done, "result/status")), "\n")

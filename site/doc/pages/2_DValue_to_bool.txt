:title
Convert to Boolean

:sig
function bool(value : dval, fallback : bool = false) bool
function bool(value : string, fallback : bool = false) bool

:params
value : value to convert
fallback : value to return when conversion fails

:returns
The Boolean value or `fallback`.

:content
`bool(value)` converts a dynamic value to `bool`. Use `bool(value, fallback)` when conversion can fail.

:example capy render
print(bool(dval("true")), "\n")

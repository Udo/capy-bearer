return value : converted value or the fallback

:content
`bool(value)` is Capy's boolean constructor for a `dval`. `bool(value, fallback)` returns the fallback for `none` or a failed conversion.

It recognizes the string values `true`, `yes`, `on`, `1`, `false`, `no`, `off`, and `0`. It also converts booleans and finite f64 values. An empty or unrecognized string, a non-finite number, a map, and a list return the fallback.

Capy boolean text is `true` or `false`. Use `bool(value)` for a typed boolean. Do not use boolean text as a data test.

## C++ API

`DValue::to_bool()` also converts C++ pointers, references, maps, lists, and other nonempty strings. These C++ rules do not change the Capy constructor rules.

:example capy render
var value := dval("true")
print(bool(value), "\n")

:example cpp render
DValue value;
value = "true";
print(value.to_bool() ? "true\n" : "false\n");

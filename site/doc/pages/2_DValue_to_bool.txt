:content
`dval_to_bool(value, fallback)` takes a `dval` and an optional boolean fallback. It returns a boolean. Use it to read a boolean from request or structured data.

It recognizes `true`, `yes`, `on`, `1`, `false`, `no`, `off`, `0`, and `null`. A nonempty unrecognized string is true. An empty string returns the fallback. A multi-child map is true when nonempty.

## C++ API

`DValue::to_bool()` also converts C++ pointers and references.

:example capy render
var value := dval("true")
if dval_to_bool(value) { print("true\n") } else { print("false\n") }

:example cpp render
DValue value;
value = "true";
print(value.to_bool() ? "true\n" : "false\n");

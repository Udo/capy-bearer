:sig
u64 file_write(u64 h, String data)

:params
h : `u64` handle from `file_open()` in a writable mode
data : string bytes to write at the current offset
return value : `u64` number of bytes written

:content
`file_write()` writes string bytes at a file handle's current offset. It returns the `u64` number of bytes written and advances the offset.

Pass a handle from `file_open()` in `"w"`, `"a"`, or `"r+"` mode. Strings can contain NUL bytes and other binary data.

It returns zero for an invalid, closed, or non-writable handle. Use it for sequential file output.

:example capy render
var handle := file_open("/tmp/doc-write.txt", "w")
var count := file_write(handle, "hello world")
var count_text := "0"
if count == 11 { count_text = "11" }
file_close(handle)
print(count_text, " bytes -> ", file_get_contents("/tmp/doc-write.txt"), "\n")

:example cpp render
u64 h = file_open("/tmp/doc-write.txt", "w");
u64 n = file_write(h, "hello world");
file_close(h);
print(n, " bytes -> ", file_get_contents("/tmp/doc-write.txt"), "\n");

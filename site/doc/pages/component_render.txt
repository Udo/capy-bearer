:content
`component_render()` runs a Capy component and writes its output to the current response.

Pass a component name and optional `dval` props. The component receives props through the request context. Use this function when you do not need the component output as a string.

Bearer accepts the same names as `component()`. A colon selects a named handler. A name that starts with a colon selects a handler in the current file.

A missing component or handler causes a server error with status 500. Call `component_exists()` first when the component is optional.

`component()` captures output in a string. In C++ `.uce`, pass `context` as the optional final argument when needed.

:example capy render
component_render("examples/sample_unit")
print("\n")
:example cpp render
component_render("examples/sample_unit");
print("\n");

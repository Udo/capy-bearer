:sig
function component_render(name : string)
function component_render(name : string, props : as dval)

:params
name : a component name or named handler
props : optional input for `request.props`

:content
`component_render()` writes component output to the current response.

Use `component()` or `component_capture()` when you need the output as a string. Bearer accepts a component path with or without `.capy`.

A colon selects a named handler. A leading colon selects a handler in the current file. Use `component_exists()` before an optional component.

:example capy render
component_render("/tests/capy-request-context.capy", {name: "Capy"})

:see
component
component_capture

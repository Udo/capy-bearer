:sig
String request_base_url(Request& context)

:see
>uri
request_script_url
request_query_route

:content
In Capy, this function reads the current request. Do not pass a `Request` value.

It returns the canonical directory URL for the current script. Use it to create links to sibling assets or query-routed pages.

:example capy render
if request_base_url() != "" { print("base url\n") } else { print("empty\n") }

:example cpp render
print(request_base_url(context) != "" ? "base url\n" : "empty\n");

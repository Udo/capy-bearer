:sig
String ascii_safe_name(String raw)

:params
raw : arbitrary input string

:returns
an ASCII-only sanitized name

:content
Capy's `ascii_safe_name(raw)` returns an ASCII-only `string` name. Pass any input string.

The function transliterates or removes non-ASCII characters. Use it when a file name, header, or protocol requires ASCII. The function does not report errors.

The C++ `String` function has the same input and result.

:example capy render
print(ascii_safe_name("Cafe Munchen 2024"), "\n")
:example cpp render
print(ascii_safe_name("Cafe Munchen 2024"), "\n");

:sig
String session_start(String session_name = "bearer-session")

:params
session_name : optional session cookie name. The default is `bearer-session`.
return value : current session ID

:see
>session

:content
In Capy, use this function to start the named session or restore its existing session data.

If a valid session cookie and server-side file exist, it restores that session. Otherwise, it creates a new ID and cookie. The cookie has `Path=/`, `HttpOnly`, and `SameSite=Lax`. It also has `Secure` when `SESSION_COOKIE_SECURE=1`.

After the call, `request_context()["session_id"]` contains the ID. The `session_name` and `session` fields contain the cookie name and copied session data. Bearer saves session changes after the request.

:example capy render
var id := session_start("bearer-doc-example")
if id != "" { print("started\n") } else { print("empty\n") }

:example cpp render
String id = session_start("bearer-doc-example");
print(id != "" ? "started\n" : "empty\n");

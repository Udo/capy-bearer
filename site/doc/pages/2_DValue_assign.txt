:title
Assign a dynamic value

:sig
function dval_assign(value : dval, source : as dval) dval

:params
value : target value
source : replacement value

:returns
The target value.

:content
`dval_assign(value, source)` replaces the content of `value`. It changes `value` and returns the same value.

:example capy render
var value := dval("old")
value = dval_assign(value, "new")
print(value, "\n")

:title
DValue::operator=

:sig
void DValue::operator=(String v)
void DValue::operator=(f64 v)
void DValue::operator=(void* v)
void DValue::operator=(DValue v)
void DValue::operator=(StringMap v)

:params
v : assigned value
return value : none

:see
0_DValue
2_DValue_set
2_DValue_set_bool

:content
Use `dval_assign(value, source)` in Capy to replace a copied `dval` value. Pass the current value and a `dval` source. It returns the replacement value, so write `value = dval_assign(value, source)`. The call does not change another `dval` value.

C++ `operator=` calls the matching `set(...)` overload. It assigns strings, numbers, pointers, `DValue` values, and `StringMap` values. Use `set_bool()` for C++ Boolean values.


:example capy render
var row := dval({"name": "Ada", "role": "engineer"})
print(row["name"], " / ", row["role"], "\n")

:example cpp render
DValue row;
row["name"] = "Ada";
row["role"] = "engineer";
print(row["name"].to_string(), " / ", row["role"].to_string(), "\n");

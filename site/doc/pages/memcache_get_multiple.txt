:sig
function memcache_get_multiple(connection : u64, keys : dval) dval

:params
connection : the connection handle
keys : the entry keys

:returns
a map of returned entries

:content
`memcache_get_multiple()` reads several keys through one connection.

Missing keys do not occur in the returned map.

:example capy render
var connection := memcache_connect()
if connection != u64(0) { print(memcache_get_multiple(connection, dval(["first", "second"]))["first"], "\n") }

:see
>memcache
memcache_get
memcache_set

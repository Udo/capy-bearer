:sig
function session_set(key : string, value : string) dval

:params
key : session field name
value : value to store

:returns
The updated session state.

:content
Call `session_start()` before you store a session field.

:example capy render
var session := session_start("docs-session")
session = session_set("theme", "dark")
print(string(session.values.theme, ""), "\n")

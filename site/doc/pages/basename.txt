:sig
String basename(String fn)

:params
fn : a path
return value : the final path component

:content
Capy's `basename(path)` returns the final path component as a `string`. Pass a path string.

Use it to get a file or directory name without its parent directories. The function does not access the file system. It does not report errors.

The C++ `String` function has the same input and result.

:example capy render
print(basename("/var/www/site/index.uce"), "\n")
:example cpp render
print(basename("/var/www/site/index.uce"), "\n");

:sig
function path_real(path : string) string

:params
path : the path to resolve

:returns
the canonical absolute path, or an empty string on failure

:content
`path_real()` returns the canonical absolute path for an existing path.

It follows symbolic links and removes dot segments. It returns an empty string when it cannot resolve the path.

:example capy render
print(path_real("/tmp"), "\n")

:see
path_is_within
path_join

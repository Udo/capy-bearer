:sig
String path_real(String path)

:params
path : the path to resolve

:returns
the canonical absolute path, or `""` if resolution fails

:content
In Capy, `path_real()` returns the canonical absolute path as a `string`. It follows symbolic links and removes `.` and `..` segments.

It returns `""` if it cannot resolve the path.

Use `path_is_within()` after this call to check a user-supplied path against an allowed root.

:example capy render
var path := "/tmp/doc-real.txt"
file_put_contents(path, "x")
print(path_real(path), "\n")
file_unlink(path)

:example cpp render
file_put_contents("/tmp/doc-real.txt", "x");
print(path_real("/tmp/../tmp/./doc-real.txt"), "\n");

:see

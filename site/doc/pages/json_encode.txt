:content
In Capy, this function encodes a `string` or `dval` value as JSON text.

Use it to send structured data in a response or store it as text. List-shaped `dval` values encode as JSON arrays.

The C++ API also accepts an optional quote character. Capy has no quote-character argument.

:example capy render
var value := dval({name: "Ada"})
print(json_encode(value), "\n")

:example cpp render
DValue value;
value["name"] = "Ada";
print(json_encode(value), "\n");

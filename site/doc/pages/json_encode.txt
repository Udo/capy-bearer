:content
In Capy, this function encodes a `string` or `dval` value as JSON text.

Use it to send structured data in a response or store it as text. List-shaped `dval` values encode as JSON arrays. `none` encodes as JSON `null`.

The C++ API also accepts an optional quote character. Capy has no quote-character argument.

:example capy render
var value := dval({"name": "Ada", "middle": none})
print(json_encode(value), "\n")

:example cpp render
DValue value;
value["name"] = "Ada";
value["middle"].set_none();
print(json_encode(value), "\n");

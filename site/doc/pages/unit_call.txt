:sig
DValue* unit_call(String file_name, String function_name, DValue* call_param = null)

:params
file_name : unit path
function_name : exported function name
call_param : optional function input

:returns
the function result

:see
>ob
unit_load
unit_render
unit_info
1_RENDER
1_COMPONENT

:content
Call `unit_call(file_name, function_name[, props])` to call an exported unit function.

The input and result are `dval` values. The two-input form supplies an empty `dval` value. Use `unit_call()` for one direct call that returns data.

For repeated calls, `unit_load(path).call(name[, input])` gives a module value. A Capy unit declares callable functions with `EXPORTS`. For example, `EXPORTS echo` exposes `echo(input : dval) dval`.

A missing unit or export is an error. `unit_call()` also accepts `RENDER`, `RENDER:NAME`, `COMPONENT`, `COMPONENT:NAME`, `ONCE`, and `INIT`.

C++ does not use the Capy `module` value. Use the `DValue*` API in the signature above. C++ exports use `EXPORT DValue* name(DValue*)`.


:example capy render
var result := unit_call("examples/sample_unit.uce", "doc_greet")

:example cpp render
unit_call("examples/sample_unit.uce", "doc_greet");

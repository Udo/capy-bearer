function unit_call(file_name : string, function_name : string, props : as dval) dval

:params

:returns

:content
`unit_call` calls an exported function in a unit.

:example capy render
var result := unit_call("/tests/capy-module-target.capy", "echo", "hello")
print(result, "\n")

:sig
DValue::every(String predicate) (legacy `StringList` page)

:content
`every(items, predicate)` takes a list-shaped `dval` and a string predicate. It returns true only if every item satisfies the predicate. An empty list returns true.

Use it with a list from `split` or `dval([...])`. Capy has no separate `StringList` type. It uses list-shaped DValues. This function does not mutate `items`.

## C++ API

`DValue::every()` provides the legacy StringList operation.

:see
0_DValue

:example capy render
var items := split("one,two", ",")
if every(items, function(value : string) bool { return value != "" }) { print("all\n") } else { print("not all\n") }
:example cpp render
StringList items = split("one,two", ",");
print(items.every([](String value) { return value != ""; }) ? "all\n" : "not all\n");

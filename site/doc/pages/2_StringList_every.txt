:sig
DValue::every(String predicate) (legacy `StringList` page)

:content
Removed as a separate StringList API. List-shaped `DValue::every()` returns true only when every string satisfies the predicate.

:see
0_DValue

:example capy render
var items := split("one,two", ",")
if every(items, function(value : string) bool { return value != "" }) { print("all\n") } else { print("not all\n") }
:example cpp render
StringList items = split("one,two", ",");
print(items.every([](String value) { return value != ""; }) ? "all\n" : "not all\n");

:sig
u64(value : dval, fallback : u64 = 0) u64
u64(value : string, fallback : u64 = 0) u64

:params
value : source value to convert
fallback : value returned when conversion fails

:returns
converted `u64`, or `fallback`

:content
Use `u64` to convert input to a 64-bit unsigned integer.

`u64(dval, fallback)` accepts scalar `bool`, finite `f64`, and exact decimal text. Decimal strings may use a leading `+`.

`u64(string, fallback)` trims spaces and then applies the same rules. Negative strings, overflow, and fractions return `fallback`.

:errors
`u64` does not throw. It returns `fallback` for invalid text, `none`, maps, lists, negative numbers, or out-of-range values.

:example capy render u64() parses unsigned text and numbers
print(u64("12"), "\n")
print(u64(dval(12.9), 0), "\n")

:example capy render u64() returns the fallback for empty text
print(u64("", 99), "\n")

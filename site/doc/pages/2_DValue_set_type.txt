:title
Set a dynamic value type

:sig
function dval_set_type(value : dval, type : string) dval

:params
value : target value
type : type code

:returns
The changed target value.

:content
`dval_set_type` changes the internal type of `value`. Use `dval_set`, `dval_set_bool`, or `dval_set_array` for normal code.

:example capy render
var value := dval_set_type(dval(""), "M")
print(dval_get_type_name(value), "\n")

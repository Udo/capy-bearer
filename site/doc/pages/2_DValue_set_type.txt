:sig
void DValue::set_type(char t)

:params
t : internal type tag such as S, F, B, M, P, or R

:returns
none

:see
0_DValue
2_DValue_set
2_DValue_set_array

:content
`dval_set_type(value, type)` changes the target to the specified internal type. It mutates `value` and returns that same identity. All workspace aliases observe the mutation. Assigning the result back remains valid.

Use `dval_set`, `dval_set_bool`, or `dval_set_array` for normal Capy code. Setting map type clears children and resets list state and the next numeric index.

## C++ API

`DValue::set_type()` changes the object in place and can follow an internal reference.


:example capy render
var value := dval_set_type(dval(""), "M")
value = dval_push(value, "x")
print("type after set_array: ", dval_get_type_name(value), "\n")

:sig
void DValue::set_type(char t)

:params
t : internal type tag such as S, F, B, M, P, or R
return value : none

:see
0_DValue
2_DValue_set
2_DValue_set_array

:content
`dval_set_type(value, type)` takes a `dval` and a type-tag string. It returns a replacement with that internal type. Assign the result back to retain the update.

Use `dval_set`, `dval_set_bool`, or `dval_set_array` for normal Capy code. Setting map type clears children and resets list state and the next numeric index.

## C++ API

`DValue::set_type()` changes the object in place and can follow an internal reference.


:example capy render
var value := dval_set_type(dval(""), "M")
value = dval_push(value, dval("x"))
print("type after set_array: ", dval_get_type_name(value), "\n")

:example cpp render
DValue v;
v.set_array();
DValue item; item.set("x"); v.push(item);
print("type after set_array: ", v.get_type_name(), "\n");

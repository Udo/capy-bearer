:sig
f64 gen_float(f64 from, f64 to, u64 index, u64 seed = 0, f64 decimal_precision = 0.000000000001)

:params
from : first range endpoint
to : second range endpoint
index : deterministic input position
seed : deterministic input seed, default `0`

:returns
deterministic `f64` noise value

:see
>noise
gen_noise64
gen_int
gen_noise32
gen_sha1
gen_noise01
sha256
:content
`gen_float()` returns a deterministic `f64` noise value for `index` and `seed`. `from` and `to` set the output range.

Use the same inputs to reproduce procedural values. Capy calls the optional fifth input `precision`.


:example capy render
var generated := gen_float(1.0, 0.0, 1)
print("float\n")

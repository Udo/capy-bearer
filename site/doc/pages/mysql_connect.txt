:sig
MySQL* mysql_connect(String host = "localhost", String username = "root", String password = "", String database = "")

:params
host : MySQL server host
username : MySQL user name
password : MySQL password
database : initial database name
return value : opaque request-local MySQL handle

:see
>mysql

:content
In Capy, this function returns an opaque request-local `u64` handle. Pass all four arguments.

Use `mysql_connected()` before work that needs a live server connection. A failed connection can still return a nonzero handle. Use `mysql_error()` to read its diagnostic.

Each call creates a lease. `mysql_disconnect()` releases that lease. Bearer can retain the server connection in its worker pool instead of closing it immediately.

The C++ API returns `MySQL*` instead.

:example capy render
var db := mysql_connect("localhost", "root", "", "")
if mysql_connected(db) { print("connected to MySQL\n") } else { print("no MySQL server reachable with these credentials\n") }
if db != 0 { mysql_disconnect(db) }

:example cpp render
MySQL* db = mysql_connect();
print(mysql_connected(db) ? "connected to MySQL" : "no MySQL server reachable with these credentials", "\n");
if(db != 0) mysql_disconnect(db);

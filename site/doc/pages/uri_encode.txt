:sig
String uri_encode(String s)

:params
s : string that should be encoded
return value : an URI-encoded version of 's'

:see
>uri

:content
In Capy, `uri_encode(value)` accepts a `string` and returns its URI-encoded `string` form.

Use it before you place text in a URI component. The API has no error return.

C++ uses the signature above. Its `String` input and return value correspond to Capy `string` values.


:example capy render
print(uri_encode("Ada Lovelace"), "\n")

:example cpp render
print(uri_encode("Ada Lovelace"), "\n");

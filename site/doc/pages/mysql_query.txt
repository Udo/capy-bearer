:sig
DValue mysql_query(MySQL* m, String q, StringMap params)

:params
m : an active MySQL connection. Capy uses a `u64` handle. C++ uses a pointer.
q : the MySQL query text
params : optional named parameter values
return value : the query result rows

:see
>mysql
mysql_affected_rows

:content
In Capy, `mysql_query()` runs a MySQL query and returns its rows as a `dval`.

Pass parameter values as a `dval` map. Use named `:name` placeholders. The API rejects positional `?` placeholders.

Ordinary placeholders become quoted SQL strings. For an unquoted non-negative integer, such as `LIMIT` or `OFFSET`, add `!` to the placeholder: `:limit!`. Its value must contain one or more decimal digits. It cannot contain signs, whitespace, expressions, identifiers, or SQL fragments.

After an insert, update, or delete, call `mysql_affected_rows()`.

:example capy cli
var db := mysql_connect("localhost", "root", "", "")
if db != 0u64 {
    var rows := mysql_query(db, "select 'ada@example.test' as email, 1 + 1 as total limit :limit!", dval({limit: "1"}))
    print(dval_string(rows[0]["email"]), " / total=", dval_string(rows[0]["total"]), "\n")
    mysql_disconnect(db)
} else { print("(requires a reachable MySQL server)\n") }

:example cpp cli
MySQL* db = mysql_connect();
if(db != 0)
{
    StringMap params; params["limit"] = "1";
    DValue rows = mysql_query(db, "select 'ada@example.test' as email, 1 + 1 as total limit :limit!", params);
    String email = "none"; String total = "?";
    rows.each([&](DValue r, String key) { email = r["email"].to_string(); total = r["total"].to_string(); });
    print(email, " / total=", total, "\n");
    mysql_disconnect(db);
}
else print("(requires a reachable MySQL server)\n");

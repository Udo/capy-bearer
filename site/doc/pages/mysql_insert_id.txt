:sig
function mysql_insert_id(handle : u64) u64

:params
handle : the MySQL connection handle

:returns
the last automatic row ID for this connection

:content
`mysql_insert_id()` returns the last automatic row ID for a connection.

Call it after an insert into a table with an automatic ID column.

:example capy render
var database := mysql_connect("localhost", "root", "", "")
if mysql_connected(database) { print(mysql_insert_id(database), "\n") }
if database != u64(0) { mysql_disconnect(database) }

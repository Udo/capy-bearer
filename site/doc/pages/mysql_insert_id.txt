:sig
u64 mysql_insert_id(MySQL* m)

:params
m : an active MySQL connection. Capy uses a `u64` handle. C++ uses a pointer.
return value : the last automatic row ID for this connection

:see
>mysql

:content
In Capy, `mysql_insert_id()` returns the last automatic row ID as `u64`.

Call this after an `INSERT` into a table with an `AUTO_INCREMENT` column.

:example capy render
var db := mysql_connect("localhost", "root", "", "")
if db != 0 {
    mysql_query(db, "select last_insert_id() as id")
    print("mysql_insert_id() returns the last AUTO_INCREMENT id for this connection (currently ", mysql_insert_id(db), ")\n")
    mysql_disconnect(db)
} else { print("(requires a reachable MySQL server)\n") }

:sig
bool password_needs_rehash(String encoded)

:params
encoded : the stored password credential

:returns
`true` if the encoding is malformed or uses older Bearer parameters

:content
In Capy, `password_needs_rehash()` returns `true` when a stored Bearer password encoding needs replacement.

Call this only after `password_verify()` succeeds. Hash the known password again. Then replace the stored credential as one operation.

Other credential formats return `true`. Your application must verify them before it upgrades them.

:example capy render
var old := "$bearer$scrypt$16384$8$1$00112233445566778899aabbccddeeff$29fdfb3d991961e926a19c1136a07e252afa5fdb8d3a0fb74cdcfa5016956f34"
if password_verify("legacy password", old) && password_needs_rehash(old) { print("upgrade\n") } else { print("keep\n") }

:example cpp render
String old = "$bearer$scrypt$16384$8$1$00112233445566778899aabbccddeeff$29fdfb3d991961e926a19c1136a07e252afa5fdb8d3a0fb74cdcfa5016956f34";
print(password_verify("legacy password", old) && password_needs_rehash(old) ? "upgrade" : "keep", "\n");

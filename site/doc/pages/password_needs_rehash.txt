:sig
function password_needs_rehash(encoded : string) bool

:params
encoded : the stored password encoding

:returns
`true` when the encoding needs replacement

:content
`password_needs_rehash()` returns `true` for malformed encodings and older Bearer password parameters.

Call it after `password_verify()` succeeds. Hash the known password again and replace the stored encoding.

:example capy render
var encoded := password_hash("correct horse battery staple")
if password_verify("correct horse battery staple", encoded) { print(password_needs_rehash(encoded), "\n") }

:see
>sys
password_hash
password_verify

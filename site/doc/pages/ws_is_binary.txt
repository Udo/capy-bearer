:sig
bool ws_is_binary()

:params
return value : true if the current WebSocket message is binary

:see
>websocket

:content
In Capy, `ws_is_binary()` takes no inputs and returns `true` for the current binary WebSocket message.

Use it before you parse `ws_message()`. It returns `false` for a text message and outside a WebSocket handler.

The `false` value is the normal nonbinary result. C++ returns the same value as `bool`.

:example capy render
if ws_is_binary() { print("binary frame\n") } else { print("text frame (default outside a WS handler)\n") }

:example cpp render
print(ws_is_binary() ? "binary frame" : "text frame (default outside a WS handler)", "\n");

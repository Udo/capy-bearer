:content
`ws_is_binary()` is a C++ API. It returns true for the current binary WebSocket message. It returns false for a text message and outside a WebSocket handler.

Use it before you parse `ws_message()`.

Capy does not expose `ws_is_binary`. In a Capy `WS` handler, read `request.websocket.binary`.

:example cpp render
print(ws_is_binary() ? "binary frame" : "text frame (default outside a WS handler)", "\n");

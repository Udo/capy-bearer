:title
Test for a child

:sig
dval_has(value : dval, key : string) bool

:params
value : value to test
key : child key

:returns
`true` when the key exists.

:content
`dval_has` tests for a child without creating it. It returns `false` for a missing key or a scalar.

:example capy render
var user := dval({"name": "Ada"})
print(dval_has(user, "name"), " ", dval_has(user, "age"), "\n")

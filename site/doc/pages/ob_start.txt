:sig
void ob_start()

:returns
no value

:content
`ob_start()` starts a new output buffer. Later `print()` calls write to this buffer instead of the response.

Call `ob_get_close()` to get the contents. Call `ob_close()` to discard them. Buffers can nest.

:example capy render
ob_start()
print("buffered text")
var captured := ob_get_close()
print("captured: ", captured, "\n")

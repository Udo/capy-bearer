:sig
function file_fsync(handle : u64) bool

:params
handle : writable handle returned by `file_open`

:returns
`true` when Capy flushes the handle. Otherwise, it returns `false`.

:content
`file_fsync` flushes pending writes for a handle. Call it before `file_close` when the file system must receive the writes first.

:example capy render
var handle := file_open("/tmp/doc-fsync.txt", "w")
file_write(handle, "durable")
print(file_fsync(handle), "\n")
file_close(handle)

:see
file_write
file_close
file_open

:sig
bool file_fsync(u64 h)

:params
h : writable handle from `file_open()`

:returns
true when Capy flushes the handle, otherwise false

:content
`file_fsync` flushes writes for a handle. Use it before `file_close()` when durable storage matters. It returns false when the flush fails. Capy uses the same handle and Boolean result.

:example capy render
var handle := file_open("/tmp/doc-fsync.txt", "w")
file_write(handle, "durable")
var result := "fsync failed"
if file_fsync(handle) { result = "flushed to disk" }
print(result, "\n")
file_close(handle)

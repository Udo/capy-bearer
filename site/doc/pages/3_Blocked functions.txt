:title
Blocked functions

:capy-status cpp-specific

:content
Capy has no API for this setting. This Bearer server setting applies only to C++ units.

A server operator can block selected operating-system functions. A C++ unit that calls a blocked function fails for that request. The error page names the blocked function.

## Configuration

Set `BEARER_HOSTCALL_BLOCKLIST` in `/etc/bearer/settings.cfg`. Use a comma-separated list of function names. You can use `shell_exec` or `bearer_host_shell_exec`. An empty value blocks nothing.

Restart Bearer after you change this setting. The setting does not reload while Bearer runs.

## When a function is blocked

Bearer stops the request when its C++ unit calls a blocked function. The error has type `policy_blocked`. The worker continues to serve other requests. C++ code cannot catch this error.

## Scope

You can block operating-system capability calls, such as file access, shell commands, HTTP requests, databases, sockets, and crypto calls. You cannot block normal library functions such as string operations or `DValue` methods.

Bearer ignores `component_resolve` in this list. Bearer needs that function to render components and units.

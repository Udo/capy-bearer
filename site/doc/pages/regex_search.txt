:sig
DValue regex_search(String pattern, String subject)
DValue regex_search(String pattern, String subject, String flags)

:params
pattern : PCRE2 regular expression pattern
subject : text to search
flags : optional PCRE2 flags
return value : first-match data as a `dval`

:see
>string
>regex

0_DValue

:content
In Capy, use this function to find the first match in a string. It returns a DValue, not a Boolean.

The result has these fields:

- `matched` is true when a match exists.
- `pattern` and `flags` contain the supplied values. `flags` is `default` when none were supplied.
- `match` is the complete matched text.
- `start` and `end` are byte offsets in `subject`.
- `captures` contains capture data. Capture `0` is the complete match.
- `named` maps each named capture to its text.
- `named_offsets` maps each named capture to `index`, `start`, and `end`.

When no match exists, `matched` is false. The result omits match-specific fields.

:example capy render
var match := regex_search("docs", "bearer docs")
print(match["match"], "\n")

:example cpp render
DValue match = regex_search("docs", "bearer docs");
print(match["match"].to_string(), "\n");

:sig
function regex_search(pattern : string, subject : string, flags : string = "") dval

:params
pattern : regular expression
subject : text to search
flags : regular expression flags

:returns
Data for the first match.

:content
The result contains `matched`. A matching result also contains `match`, `start`, `end`, `captures`, and `named`.

:example capy render
var match := regex_search("[a-z]+", "123 capy")
print(string(match.match, ""), "\n")

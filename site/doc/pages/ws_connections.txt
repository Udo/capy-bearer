
:sig
DValue ws_connections(String scope = "")

:params
scope : optional C++ WebSocket scope identifier

:returns
C++ list of connection IDs in that scope

:see

>0_Request

:capy-status cpp-specific

:content
`ws_connections()` is a C++ API. It returns the IDs connected to the selected scope. An omitted scope selects the current WebSocket page scope.

Capy does not expose `ws_connections`. In a Capy `WS` handler, read `request.websocket.connections` for IDs in the current scope.

:example cpp render
DValue ids = ws_connections();
print("active connections in this scope: ", ids.size(), "\n");

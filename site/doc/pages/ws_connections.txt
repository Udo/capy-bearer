:sig
DValue ws_connections(String scope = "")

:params
scope : optional scope identifier, defaults to the current WebSocket page scope
return value : list of connection IDs currently connected to that scope

:see
>websocket

:content
In Capy, `ws_connections()` returns a `dval` list of IDs in the current WebSocket scope. `ws_connections(scope)` accepts a scope `string` and returns that scope's list.

Use it to inspect or select connected clients. The declaration has no error return.

C++ uses the optional `String` input in the signature above. Capy provides separate zero-input and one-input declarations.

:example capy render
var count := 0
for id = ws_connections() { count = count + 1 }
print("active connections in this scope: ", count, "\n")

:example cpp render
DValue ids = ws_connections();
print("active connections in this scope: ", ids.size(), "\n");

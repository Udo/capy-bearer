:sig
String DValue::to_string(String default_value = "") const

:params
String : fallback returned when conversion is not possible
return value : converted value or the fallback

:see
>types
0_DValue
2_DValue_get_by_path

:content
`dval_to_string(value, fallback)` takes a `dval` and an optional string fallback. It returns stored text or converted f64 and boolean text. Boolean text is `(true)` or `(false)`.

An empty string, a map, or an unsupported value returns the fallback. Use it for normal Capy reads.

## C++ API

`DValue::to_string()` also converts pointers. It returns the fallback for an unresolved reference or an unknown type.

:example capy render
var value := dval(true)
print(dval_to_string(value), "\n")

:example cpp render
DValue value;
value.set_bool(true);
print(value.to_string(), "\n");

:sig
String DValue::to_string(String default_value = "") const

:params
String : fallback returned when conversion is not possible

:returns
converted value or the fallback

:see
>types
0_DValue
2_DValue_to_bool
2_DValue_require

:content
`string(value)` is Capy's string constructor for a `dval`. `string(value, fallback)` returns the fallback for `none` or a failed conversion.

It returns stored text, f64 text, and boolean text. Capy boolean text is `true` or `false`.

An empty string, a map, or an unsupported value returns the fallback. Ordinary `print(value.member)` uses `as string` and has the same conversion.

## C++ API

`DValue::to_string()` also converts pointers. It returns the fallback for an unresolved reference or an unknown type.

C++ `DValue::to_string()` returns `(true)` or `(false)` for boolean values. This differs from Capy boolean text.

:example capy render
var user := {"name": "Ada"}
print(user.name, "\n")

:example cpp render
DValue user;
user["name"] = "Ada";
print(user["name"].to_string(), "\n");

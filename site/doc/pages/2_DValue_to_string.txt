:title
Convert to string

:sig
function string(value : dval, fallback : string = "") string

:params
value : value to convert
fallback : value to return when conversion fails

:returns
The string value or `fallback`.

:content
`string(value)` converts a dynamic value to `string`. Use the optional fallback for values that cannot convert.

:example capy render
print(string(dval("Ada")), "\n")

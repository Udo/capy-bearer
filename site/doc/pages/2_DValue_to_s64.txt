:title
Convert to a signed integer

:sig
function s32(value : dval, fallback : s32 = 0) s32
function s32(value : string, fallback : s32 = 0) s32
function s64(value : dval, fallback : s64 = 0) s64
function s64(value : string, fallback : s64 = 0) s64

:params
value : value to convert
fallback : value to return when conversion fails

:returns
The integer value or `fallback`.

:content
`s32(value)` and `s64(value)` convert a dynamic value to a signed integer. Use the optional fallback for invalid input.

:example capy render
print(s64(dval("-42")), "\n")

:sig
s64 DValue::to_s64(s64 default_value = 0) const

:params
s64 : fallback returned when conversion is not possible
return value : converted value or the fallback

:see
>types
0_DValue
2_DValue_to_string
2_DValue_require

:content
`s64(value)` is Capy's signed integer constructor for a `dval`. `s64(value, fallback)` returns the fallback for `none` or a failed conversion. `s32(value)` uses the same rules with the s32 range and a default fallback of `0`.

Exact decimal strings, in-range finite f64 values, and booleans can convert. An f64 conversion truncates toward zero. Empty or invalid strings, overflow, maps, and lists return the fallback.

## C++ API

`DValue::to_s64()` also converts C++ pointers, resolved references, and one-child maps. It can clamp values outside its range. These C++ rules do not change the Capy constructor rules.

:example capy render
var value := dval("-42")
print(s64(value), "\n")

:example cpp render
DValue value;
value = "-42";
print(value.to_s64(), "\n");

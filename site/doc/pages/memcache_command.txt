:sig
String memcache_command(u64 connection, String command)

:params
connection : open connection handle
command : Memcache command text
return value : one bounded server response read

:see
>memcache

:content
In Capy, pass the `u64` handle from `memcache_connect()`.

This function appends CRLF to `command` and sends it to the server. It makes one bounded read for the response. It does not guarantee a complete multi-chunk response.

Use a dedicated helper when it supports the operation.

:example capy render
var conn := memcache_connect()
if conn != 0u64 { if memcache_command(conn, "stats") != "" { print("stats command returned data\n") } else { print("no data\n") } }
else { print("(requires a reachable memcached server)\n") }

:example cpp render
u64 conn = memcache_connect();
if(conn != 0) print(memcache_command(conn, "stats") != "" ? "stats command returned data" : "no data", "\n");
else print("(requires a reachable memcached server)\n");

:sig
function memcache_command(connection : u64, command : string) string

:params
connection : the connection handle
command : the Memcache command text

:returns
one server response read

:content
`memcache_command()` sends `command` to the server and returns one bounded response read.

Use a dedicated Memcache function when one is available. This function does not guarantee a complete multi-part response.

:example capy render
var connection := memcache_connect()
if connection != u64(0) { print(memcache_command(connection, "version"), "\n") }

:see
>memcache
memcache_connect

:sig
DValue filter(DValue items, function<bool (String)> f)
DValue::filter(function<bool (String)> f)

:params
items : `dval` list whose values are read as strings
f : Capy function that returns `bool` for each string

:returns
new `dval` list of selected string values

:see

:content
`filter()` reads each `dval` list value as a string. It returns a new `dval` list with values where `f` returns `true`.

Use it to select string values without changing `items`. In C++ `.uce`, use `DValue` and a lambda that accepts `String`.


:example capy render
var names := split("ada,bob,amy", ",")
var a_names := filter(names, function(item : string) bool { return str_starts_with(item, "a") })
print(join(a_names, ","), "\n")

:example cpp render
DValue names = split("ada,bob,amy", ",");
DValue a_names = filter(names, [](String item) { return(str_starts_with(item, "a")); });
print(join(a_names, ","), "\n");

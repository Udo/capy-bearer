:sig
function filter(items : dval, predicate : function(value : string) bool) dval

:params
items : list of values
predicate : function that selects a value

:returns
A new list of selected values.

:content
`filter` calls `predicate` for each value. It keeps values for which the predicate returns `true`.

:example capy render
var names := split("ada,bob,amy", ",")
var selected := filter(names, function(value : string) bool { return str_starts_with(value, "a") })
print(join(selected, ","), "\n")

:title
String list

:sig
type dval (list of strings)

:content
Use a list-shaped `dval` for an ordered string list. Create one with `dval([...])` or `split`.

Use `join`, `map`, `filter`, `keys`, `unique`, `sort`, `some`, and `every` for list work. These functions return a new value unless stated otherwise.

Capy has no separate `StringList` type. Use a list-shaped `dval` instead.

:example capy render
var labels := map(unique(split("a,b,a", ",")), function(item : string) string { return upper(item) })
print(join(labels, ","), "\n")

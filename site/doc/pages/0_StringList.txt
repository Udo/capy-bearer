:sig
DValue list (legacy `StringList` spelling)

:content
Use a list-shaped `dval` for an ordered string list in Capy. Create one with `dval([...])` or use a result from `split`, `split_utf8`, `regex_split`, `ls`, `units_list`, or `request.websocket.connections` in a `WS` handler.

List functions take a list-shaped `dval` and return a `dval`, a `string`, or a `bool`. Use `join`, `map`, `filter`, `keys`, `unique`, `sort`, `some`, `every`, and `string_list_find` for normal list work.

`dval_push` and `dval_pop` mutate the target list and return that same identity. Assigning the result back remains valid.

## Capy Limit

Capy has no separate `StringList` type or representation. It uses mutable DValue reference values inside a workspace. A C++ boundary copies BRRB and does not expose a container alias.

## C++ API

`StringList` is a C++ name for a list-shaped `DValue`. Capy uses a list-shaped `dval` instead.

:example capy render
var labels := map(unique(split("a,b,a", ",")), function(item : string) string { return upper(item) })
print(join(labels, ","), "\n")

:example cpp render
DValue labels = split("a,b,a", ",").unique().map([](String item) { return(to_upper(item)); });
print(join(labels, ","), "\n");

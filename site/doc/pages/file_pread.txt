:sig
String file_pread(u64 h, u64 offset, u64 len)

:params
h : readable handle from `file_open()`
offset : absolute byte offset
len : maximum number of bytes to read

:returns
a Capy `string` with up to `len` bytes

:content
`file_pread()` reads from an absolute byte offset and returns a `string`. It does not change the handle position.

Use it for random reads between sequential reads. An invalid handle returns an empty string.

:example capy render
var writer := file_open("/tmp/doc-pread.txt", "w")
file_write(writer, "hello world")
file_close(writer)
var reader := file_open("/tmp/doc-pread.txt", "r")
print(file_pread(reader, 6, 5), "\n")
file_close(reader)

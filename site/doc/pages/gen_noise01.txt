:sig
f64 gen_noise01(u64 index, u64 seed = 0)

:params
index : deterministic input position
seed : deterministic input seed, default `0`

:returns
deterministic `f64` noise value from `0` to `1`

:see

:content
`gen_noise01()` returns a deterministic `f64` noise value from `0` to `1`. `index` and `seed` select the value.

Use it for repeatable normalized noise. The C++ `.uce` call uses the declaration above.


:example capy render
var generated := gen_noise01(1, 2)
print("noise\n")

:example cpp render
print(gen_noise01(1, 2) >= 0 ? "noise\n" : "bad\n");

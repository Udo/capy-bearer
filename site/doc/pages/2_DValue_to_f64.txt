:sig
f64 DValue::to_f64(f64 default_value = 0) const

:params
f64 : fallback returned when conversion is not possible

:returns
converted value or the fallback

:see
>types
0_DValue
2_DValue_to_string
2_DValue_require

:content
`f64(value)` is Capy's f64 constructor for a `dval`. `f64(value, fallback)` returns the fallback for `none` or a failed conversion.

Exact numeric strings, finite f64 values, and booleans can convert. Empty, invalid, and non-finite strings return the fallback. Maps and lists also return the fallback.

## C++ API

`DValue::to_f64()` also converts C++ pointers, resolved references, and one-child maps. These C++ rules do not change the Capy constructor rules.

:example capy render
var value := dval("12.5")
print(f64(value), "\n")

:example cpp render
DValue value;
value = "12.5";
print(value.to_f64(), "\n");

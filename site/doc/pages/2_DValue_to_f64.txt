:title
Convert to f64

:sig
function f64(value : dval, fallback : f64 = 0.0) f64
function f64(value : string, fallback : f64 = 0.0) f64

:params
value : value to convert
fallback : value to return when conversion fails

:returns
The `f64` value or `fallback`.

:content
`f64(value)` converts a dynamic value to `f64`. Use the optional fallback for invalid input.

:example capy render
print(f64(dval("12.5")), "\n")

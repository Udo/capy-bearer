:content
Capy `split_space(str)` returns a list-shaped `dval` of strings. Give it text with whitespace-separated values.

It treats each run of spaces, tabs, or line breaks as one separator. It does not create empty entries for repeated whitespace. Use it to parse simple whitespace-separated input.

The C++ API calls the result `DValue`. Capy uses the `dval` value type.

:example capy render
print(join(split_space("one  two\tthree"), ","), "\n")

:example cpp render
print(join(split_space("one  two\tthree"), ","), "\n");

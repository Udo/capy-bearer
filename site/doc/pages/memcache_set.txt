:sig
bool memcache_set(u64 connection, String key, String value, u64 expires_in = 60*60)

:params
connection : open connection handle
key : entry key
value : value text
expire : lifetime in seconds
return value : `true` only for a `STORED` server response

:see
>memcache

:content
In Capy, pass the `u64` handle from `memcache_connect()`.

This function stores `value` under `key`. It sends the value length in bytes. It returns `true` only when the trimmed server response is exactly `STORED`.

:example capy render
var conn := memcache_connect()
if conn != 0 { if memcache_set(conn, "doc_set_key", "value") { print("stored\n") } else { print("store failed\n") } }
else { print("(requires a reachable memcached server)\n") }

:example cpp render
u64 conn = memcache_connect();
if(conn != 0) print(memcache_set(conn, "doc_set_key", "value") ? "stored" : "store failed", "\n");
else print("(requires a reachable memcached server)\n");

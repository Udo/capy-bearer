:sig
String zip_read(String zip_file_name, String entry_name)

:params
zip_file_name : path to the ZIP archive
entry_name : member name to read from the archive

:returns
uncompressed entry contents

:see
>sys
zip_create
zip_list
zip_extract

:content
`zip_read(path, entry)` accepts an archive path and member name. It returns the uncompressed member bytes as a `string`.

Use `zip_list()` to discover member names before you read them. Member names cannot be empty, absolute, drive-qualified, or contain `..` path segments.

The call rejects invalid member names. The declaration has no separate error return.

C++ returns the same data as `String` through the signature above.

:example capy render
var archive := "/tmp/capy-doc-zipread.zip"
zip_create(archive, dval({"greeting.txt": "hello world"}))
print(zip_read(archive, "greeting.txt"), "\n")
file_unlink(archive)

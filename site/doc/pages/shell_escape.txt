:sig
String shell_escape(String raw)

:params
raw : string value to use as one shell word

:returns
a single-quoted shell word that represents `raw`

:see
>sys
cwd_set
shell_exec
path_join
shell_spawn
mkdir
job_status
:content
Capy `shell_escape(raw)` returns `raw` as one shell word. Give it one value that will become an argument in a command string.

Use it before `shell_exec()` when a command contains input from outside the program. It does not make a complete command safe. Do not use it for shell syntax.

:example capy render
print(shell_escape("rm -rf /; echo pwned"), "\n")

:example cpp render
print(shell_escape("rm -rf /; echo pwned"), "\n");

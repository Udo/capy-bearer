:sig
function memcache_escape_key(key : string) string

:params
key : the key text

:returns
the key with whitespace replaced by underscores

:content
`memcache_escape_key()` replaces whitespace characters in a key with underscores.

It does not validate every Memcache protocol byte.

:example capy render
print(memcache_escape_key("a key"), "\n")

:see
>memcache
memcache_escape_keys

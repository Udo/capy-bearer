:sig
String memcache_escape_key(String key)

:params
key : key text

:returns
key with whitespace characters replaced by underscores

:see
>sys
>memcache_escape_keys

:content
In Capy, use this function to replace whitespace in a Memcache key with underscores.

It replaces only characters for which C++ `isspace()` returns true. It does not reject or escape every invalid Memcache protocol byte.

:example capy render
print(memcache_escape_key("a key with spaces"), "\n")

:example cpp render
print(memcache_escape_key("a key with spaces"), "\n");

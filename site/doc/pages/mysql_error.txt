:sig
String mysql_error(MySQL* m)

:params
m : Capy MySQL handle

:returns
diagnostic text for the connection attempt or latest operation

:see
>mysql

:content
In Capy, pass the opaque `u64` handle from `mysql_connect()`.

This function returns diagnostic text for a failed connection or the latest MySQL operation. Use it after `mysql_connected()` returns `false` or an operation fails.

The C++ API accepts `MySQL*` instead.

:example capy render
var db := mysql_connect("localhost", "root", "", "")
if db != 0 {
    mysql_query(db, "select * from no_such_table_xyz")
    if mysql_error(db) != "" { print("error reported\n") } else { print("no error\n") }
    mysql_disconnect(db)
} else { print("(requires a reachable MySQL server)\n") }

:example cpp render
MySQL* db = mysql_connect();
if(db != 0)
{
    mysql_query(db, "select * from no_such_table_xyz");
    print(mysql_error(db) != "" ? "error reported" : "no error", "\n");
    mysql_disconnect(db);
}
else print("(requires a reachable MySQL server)\n");

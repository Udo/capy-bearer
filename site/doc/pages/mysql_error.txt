:sig
function mysql_error(handle : u64) string

:params
handle : the MySQL connection handle

:returns
the latest diagnostic text

:content
`mysql_error()` returns diagnostic text for a failed connection or the latest database operation.

Read it after `mysql_connected()` returns `false` or a query fails.

:example capy render
var database := mysql_connect("localhost", "root", "", "")
if !mysql_connected(database) { print(mysql_error(database), "\n") }
if database != u64(0) { mysql_disconnect(database) }

:see

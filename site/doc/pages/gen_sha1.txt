:sig
String gen_sha1(String s, bool as_binary = false)

:params
s : string bytes to hash
as_binary : `false` for hexadecimal text, `true` for raw bytes

:returns
SHA-1 digest string

:see
>noise

:content
`gen_sha1()` returns the SHA-1 digest of string bytes. It returns hexadecimal text by default, or raw digest bytes when `as_binary` is `true`.

Use it only where SHA-1 compatibility is required. Use a current hash for new security-sensitive designs.


:example capy render
var digest := gen_sha1("hello")
print("sha1\n")

:example cpp render
print(gen_sha1("hello") != "" ? "sha1\n" : "empty\n");

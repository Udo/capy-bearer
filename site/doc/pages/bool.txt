:sig
bool(value : dval, fallback : bool = false) bool
bool(value : string, fallback : bool = false) bool

:params
value : source value to convert
fallback : value returned when conversion fails

:returns
converted boolean, or `fallback`

:content
Use `bool` to read scalar data as a Boolean value.

`bool(dval, fallback)` reads `none`, scalar `string`, scalar `bool`, and scalar `f64` values. It returns `fallback` for maps, lists, and failed conversions.

`bool(string, fallback)` trims spaces and then applies the same rules. Accepted text tokens are case-insensitive: `true`, `false`, `1`, `0`, `yes`, `no`, `on`, and `off`.

:errors
`bool` does not throw. It returns `fallback` when conversion fails.

:example capy render bool() parses recognized text
print(bool("true"), "\n")
print(bool("OFF"), "\n")

:example cpp render bool() parses recognized text
DValue yes;
yes = "true";
DValue no;
no = "OFF";
print(yes.to_bool() ? "true\n" : "false\n");
print(no.to_bool() ? "true\n" : "false\n");

:example capy render bool() returns the fallback for empty text
print(bool("", true), "\n")

:example cpp render bool() returns the fallback for empty text
DValue value;
value = "";
print(value.to_bool(true) ? "true\n" : "false\n");

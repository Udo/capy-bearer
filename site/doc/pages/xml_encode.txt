:sig
String xml_encode(DValue t)
String xml_encode(DValue t, String root_name)

:params
t : tree to serialize as XML
root_name : optional element name to use when `t` is not already an element-shaped tree, defaults to `root`

:returns
XML string

:see
>markup
xml_decode
json_encode
0_DValue
html_escape

:content
`xml_encode(value)` accepts a `dval` and returns XML as a `string`. `xml_encode(value, root_name)` uses the supplied root name.

Use it to write application data as simple XML. It escapes text and attribute values. List values use repeated `item` elements.

The function does not validate schema, DTD, or namespace rules. The declaration has no error return.

C++ uses `DValue` and `String` values through the signatures above.

:example capy render
var value := dval({"name": "Ada"})
if xml_encode(value) != "" { print("xml\n") } else { print("empty\n") }

:sig
String to_upper(String s)

:params
s : text to convert
return value : `s` with lowercase characters changed to uppercase

:see
>string

:content
In Capy, call `to_upper(value)` to return an uppercase `string` value.

Use it to normalize ASCII text before comparison. Capy does not convert Unicode case.

C++ uses the legacy `s` parameter in the signature above. C++ also does not provide Unicode case conversion through this function.


:example capy render
print(to_upper("bearer"), "\n")

:example cpp render
print(to_upper("bearer"), "\n");

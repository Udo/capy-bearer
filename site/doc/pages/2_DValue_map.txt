:title
Map a dynamic value

:sig
function dval_map(value : dval, mapper : function(value : dval, key : string) dval) dval

:params
value : source value
mapper : function that replaces each child

:returns
A new mapped value.

:content
`dval_map` calls `mapper` for each child. It keeps map keys and list shape.

:example capy render
var names := dval(["ada", "grace"])
var result := dval_map(names, function(item : dval, key : string) dval { return dval(upper(string(item))) })
print(result[0], ",", result[1], "\n")

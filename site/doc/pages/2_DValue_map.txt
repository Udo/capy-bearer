:sig
DValue DValue::map(std::function<DValue (const DValue& item, String key)> f) const

:params
f : mapper called for each iterated item

:returns
mapped copy

:see
>types
0_DValue
2_DValue_each
2_DValue_filter

:content
`dval_map(value, mapper)` takes a `dval` and a callback. The callback receives each child and its key. It returns a new `dval` with each child replaced by the callback result.

A list stays a list and uses consecutive numeric keys. A map keeps its keys. A scalar calls the mapper once with an empty key and returns a one-item list. The callback items and returned DValue are copies.

## C++ API

`DValue::map()` uses a C++ callback and returns a new `DValue`.

:example capy render
var names := dval(["ada", "grace"])
var upper := dval_map(names, function(item : dval, key : string) dval { return dval(upper(string(item))) })
print(upper[0], ",", upper[1], "\n")

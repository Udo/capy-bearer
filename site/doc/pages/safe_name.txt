:sig
String safe_name(String raw)

:params
raw : source text

:returns
text that contains only letters, digits, and `_`

:content
Use this function to remove unsafe characters from a name.

The result keeps only letters, digits, and `_`. It removes whitespace, separators, punctuation, and other characters. The result can be empty. Use `runtime_safe_key()` when you need a stable non-empty runtime key.

:example capy render
print(safe_name("My Report: 2024/Q1!"), "\n")

:example cpp render
print(safe_name("My Report: 2024/Q1!"), "\n");

:sig
DValue regex_search_all(String pattern, String subject)
DValue regex_search_all(String pattern, String subject, String flags)

:params
pattern : PCRE2 regular expression pattern
subject : text to search
flags : optional regex flags

:returns
`dval` match data

:see
>string
>regex

0_DValue

:content
Use this function to find all non-overlapping matches in text.

It returns `dval` match data. Each result has `matched`, `count`, `matches`, `pattern`, and `flags` fields. `matches` contains entries with the same shape as `regex_search()`.

The function advances after a zero-length match. This prevents an infinite search.

:example capy render
var matches := regex_search_all("[a-z]+", "bearer docs")
if dval_is_list(matches) { print("matches\n") } else { print("none\n") }

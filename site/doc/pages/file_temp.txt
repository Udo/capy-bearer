:sig
String file_temp(String prefix)

:params
prefix : path prefix for the temporary file

:returns
path of a new empty temporary file, or `""` on failure

:content
`file_temp()` creates an empty temporary file and returns its path as a `string`. It adds a unique suffix to `prefix`.

Use it for scratch files or before `file_rename()`. It returns `""` when Capy cannot create a file.

:example capy render
var path := file_temp("/tmp/doc-temp-")
file_put_contents(path, "scratch")
var result := path
if str_starts_with(path, "/tmp/doc-temp-") { result = "created a temp file" }
print(result, "\n")
file_unlink(path)

:params

:returns
decoded parameters as a map-shaped `dval`. C++ returns `StringMap`

:content
`parse_query()` decodes query text such as `a=b&c=d` into a map-shaped `dval`.

- `&` separates pairs.
- The first raw `=` separates a key and value.
- The API URL-decodes keys and values.
- A key without `=` has an empty value.
- Empty pairs, including a final `&`, are ignored.
- The last value replaces an earlier value for the same key.

Use this API for query text outside normal request parsing.


:example capy render parse_query() decodes a value
var query := parse_query("name=Ada&role=admin")
print(query["name"], "\n")

:example capy render parse_query() handles keys without values
var query := parse_query("enabled&name=Ada")
print(length(string(query["enabled"], "")), "\n")

:example capy render parse_query() keeps the last repeated value
var query := parse_query("name=Ada&name=Grace")
print(query["name"], "\n")

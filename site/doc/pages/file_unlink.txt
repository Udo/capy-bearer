:sig
void file_unlink(String file_name)

:params
file_name : path of the file to delete

:returns
none

:content
`file_unlink` deletes a file at `file_name`. Use it to remove a temporary file or before you recreate a file. A missing path does not cause an error. The Capy API does not return an error value.

:example capy render
file_put_contents("/tmp/doc-unlink.txt", "x")
file_unlink("/tmp/doc-unlink.txt")
var result := "gone"
if file_exists("/tmp/doc-unlink.txt") { result = "exists" }
print(result, "\n")

:example cpp render
file_put_contents("/tmp/doc-unlink.txt", "x");
file_unlink("/tmp/doc-unlink.txt");
print(file_exists("/tmp/doc-unlink.txt") ? "exists" : "gone", "\n");

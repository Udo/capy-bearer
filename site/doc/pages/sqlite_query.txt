:sig
DValue sqlite_query(SQLite* db, String q)
DValue sqlite_query(SQLite* db, String q, StringMap params)

:params
db : Capy SQLite connection value
q : one SQL statement
params : optional Capy `dval` map of named parameter values
return value : Capy `dval` value that contains the result rows

:see
>sqlite
sqlite_connect
sqlite_error
sqlite_insert_id
sqlite_affected_rows
0_DValue

:content
Use `sqlite_query` to run one SQL statement on a Capy SQLite connection. Pass the SQL string. You can also pass a `dval` map for named values. The function returns result rows as a `dval` value.

Use `:name` placeholders with the parameter map. The API rejects positional `?`, `@name`, and `$name` placeholders. It also rejects SQL strings with more than one statement. Use `sqlite_error` to read a SQLite error. Check `sqlite_affected_rows` or `sqlite_insert_id` after a statement that does not return rows.

Rows use column names as keys. SQLite integers, floats, text, blobs, and null values convert to `dval` values. Blob values return as byte strings.

Capy uses a connection value and a `dval` map. C++ `.uce` uses an `SQLite*`, `String`, and `StringMap`, as the signatures show.

:example capy render
var db := sqlite_connect(":memory:")
sqlite_query(db, "create table users(id integer primary key, email text)")
sqlite_query(db, "insert into users(email) values(:email)", dval({"email": "ada@example.test"}))
var rows := sqlite_query(db, "select email from users")
print(rows[0]["email"], "\n")
sqlite_disconnect(db)

:example cpp render
SQLite* db = sqlite_connect("/tmp/doc-sqlite-query.db");
sqlite_query(db, "drop table if exists users");
sqlite_query(db, "create table users(id integer primary key, email text)");
StringMap params; params["email"] = "ada@example.test";
sqlite_query(db, "insert into users(email) values(:email)", params);
DValue rows = sqlite_query(db, "select email from users");
String first = "none";
rows.each([&](DValue row, String key) { first = row["email"].to_string(); });
print(first, "\n");
sqlite_disconnect(db);

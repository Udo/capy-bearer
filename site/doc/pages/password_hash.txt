:sig
String password_hash(String password)

:params
password : the password bytes to hash
return value : a self-contained scrypt encoding, or an empty string on failure

:content
In Capy, `password_hash()` returns a password credential as a `string`. It uses a random salt and Bearer's current scrypt parameters.

Store the returned encoding exactly as received. If the result is empty, do not store it. Report the failure.

:example capy render
var encoded := password_hash("correct horse battery staple")
if encoded != "" && password_verify("correct horse battery staple", encoded) { print("valid\n") } else { print("failed\n") }

:example cpp render
String encoded = password_hash("correct horse battery staple");
print(encoded != "" && password_verify("correct horse battery staple", encoded) ? "valid" : "failed", "\n");

:sig
String password_hash(String password)

:params
password : the password bytes to hash

:returns
a self-contained scrypt encoding, or an empty string on failure

:content
`password_hash()` returns a password credential as a `string`. It uses a random salt and Bearer's current scrypt parameters.

Store the returned encoding exactly as received. If the result is empty, do not store it. Report the failure.

:errors
Returns an empty string when the runtime cannot create the hash.

:note
Use a database column that can store at least 255 characters. Use `password_needs_rehash()` when you read an old hash.

:example capy render password_hash() creates a verifiable hash
var encoded := password_hash("correct horse battery staple")
if encoded != "" && password_verify("correct horse battery staple", encoded) { print("valid\n") } else { print("failed\n") }

:title
Set the response status

:sig
function response_status(code : s32, reason : string = "")

:params
code : The HTTP status code.
reason : An optional reason phrase.

:returns
This function returns no value.

:content
`response_status` sets the status for the active response.

If `reason` is empty, Bearer uses the standard phrase for common HTTP status codes. Set the status before you write response output.

:example capy render
response_status(200, "OK")
print("200\n")

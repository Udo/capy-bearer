:content
In Capy, this function renders Markdown text as HTML.

Use it to render trusted Markdown in a response. When `allow_html` is true, it outputs stored raw HTML without escaping it.

Component hooks need an active request context. Without one, the function uses default HTML. Capy cannot pass a previously returned AST to this function.

The C++ API has the same source-text rendering model.

:example capy render
print(markdown_to_html("**bold**"), "\n")

:example cpp render
print(markdown_to_html("**bold**"), "\n");

:sig
String brb_encode(DValue value)

:see

:content
`brb_encode()` converts a Capy `dval` into a BRRB1 byte string.

Pass a `dval` that you will later decode with `brb_decode()`. The returned string can contain any byte, including NUL. BRRB1 keeps scalar bytes, nested maps, lists, and empty lists.

Use this function for Bearer DValue data. Use JSON, YAML, or XML functions for text formats that people read.

:example capy render
var original := dval({"msg": "hello"})
var packed := brb_encode(original)
print("encoded ", length(packed), " bytes; round-trips to: ", dval_string(brb_decode(packed)["msg"]), "\n")
:example cpp render
DValue original;
original["msg"] = "hello";
String packed = brb_encode(original);
print("encoded ", packed.length(), " bytes; round-trips to: ", brb_decode(packed)["msg"].to_string(), "\n");

void DValue::set_reference(DValue* target)

:params
target : target node pointer

:returns
none

:see
0_DValue

:content
Capy does not support `set_reference`. DValues share identity inside a workspace, but they cannot hold a C++ `DValue*` target.

## C++ API

`DValue::set_reference()` stores an internal reference to another `DValue`. Normal C++ reads and writes usually follow an existing reference.


:capy-status unsupported

Capy cannot create a C++ internal reference node.

:example cpp render
DValue target;
target.set("original");
DValue ref;
ref.set_reference(&target);
print(ref.deref().to_string(), "\n");

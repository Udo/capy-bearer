:sig
DValue ls(String path)

:params
directory : directory to list

:returns
copied `dval` list of names

:content
In Capy, this function returns a copied `dval` list of directory entry names.

Use it when you need to inspect a directory. Handle an empty result when the directory has no entries or cannot be listed.

The C++ API returns a native `DValue`.

:example capy render
var root := file_temp("/tmp/doc-ls-")
file_unlink(root)
mkdir(root)
file_put_contents(path_join(root, "one.txt"), "1")
file_put_contents(path_join(root, "two.txt"), "2")
print(join(sort(ls(root)), ","), "\n")
dir_remove(root, true)

:example cpp render
mkdir("/tmp/doc-ls");
file_put_contents("/tmp/doc-ls/one.txt", "1");
file_put_contents("/tmp/doc-ls/two.txt", "2");
print(join(ls("/tmp/doc-ls").sort(), ","), "\n");
dir_remove("/tmp/doc-ls", true);

:title
WS

:sig
function WS(request : dval)

:content
`WS` defines the WebSocket message handler.

The handler has one parameter named `request` with type `dval`. Read the message from `request.body`. Read connection data from `request.websocket`.

Use `ws_send`, `ws_send_to`, or `ws_close` to affect the connection.

:example capy ws
ws_send("echo: " + string(request.body, ""), false)

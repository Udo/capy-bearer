:sig
StringMap split_kv(String s, char separator = '=', bool trim_whitespace = true, bool uppercase_keys = false)

:params
s : text with one key and value per line
separator : separator string. Capy uses its first character
trim_whitespace : trim keys and values when true
uppercase_keys : convert keys to uppercase when true
return value : map-shaped `dval` of keys and values

:see
>string
split
split_http_headers

:content
Capy `split_kv(s, separator, trim_whitespace, uppercase_keys)` returns a map-shaped `dval`. Give it line-based text and a separator.

It ignores empty lines and lines that start with `#`. It splits each other line at the first separator. A line without a separator has an empty value.

Use it for small configuration files, metadata blocks, and tests.

The C++ API accepts a `char` separator and returns `StringMap`. Capy accepts a string separator and returns a map-shaped `dval`.

:example capy render
var values := split_kv("name=Ada\nrole=admin")
print(values["name"], "\n")

:example cpp render
StringMap values = split_kv("name=Ada\nrole=admin");
print(values["name"], "\n");

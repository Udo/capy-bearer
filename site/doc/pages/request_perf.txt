:title
request_perf

:sig
DValue request_perf()

:params
return value : performance data for the active C++ request workspace

:see
>sys
>time_precise
>runtime_perf

:capy-status cpp-specific

:content
`request_perf()` is a C++ API. It returns diagnostic data for an active Wasm request workspace. Outside that workspace, it returns an invalid DValue.

The result can include request, transport, workspace, guest, hostcall, unit-load, component, and connector timing data. Available fields depend on the enabled profiling options and completed work. `hostcall_cpu_profiled` and `thread_runtime_profiled` show whether optional counters are available.

Capy does not expose `request_perf`. Use `runtime_perf()` in a Capy handler.

:example cpp render
DValue perf = request_perf();
print(perf.get_type_name() != "invalid" ? "captured a timing snapshot" : "no data", "\n");

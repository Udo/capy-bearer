:sig
DValue request_perf()

:params
return value : performance data for the active Capy request workspace

:see
>sys
>time_precise

:content
In Capy, this function returns data only for an active Wasm request workspace. Outside that context, it returns an invalid DValue.

Use this diagnostic snapshot to locate request time. It includes request, transport, workspace, guest execution, hostcall, unit-load, component, and connector timing data. The available fields depend on the enabled profiling options and the work done by the request.

Check that the result is valid before you read fields. `hostcall_cpu_profiled` and `thread_runtime_profiled` show whether their optional counters are available. The profiling hostcall does not add itself to the reported totals.

:example capy render
var perf := request_perf()
if dval_get_type_name(perf) != "invalid" { print("captured a timing snapshot\n") } else { print("no data\n") }

:example cpp render
DValue perf = request_perf();
print(perf.get_type_name() != "invalid" ? "captured a timing snapshot" : "no data", "\n");

:sig
function int_val(raw : string) u64
function int_val(raw : string, base : s32) u64

:params
raw : text that can contain an integer
base : number base

:returns
A parsed unsigned integer, or `0` when no usable number exists.

:content
`int_val()` extracts an unsigned integer from text. The one-argument form uses base 10.

:example capy render
print(int_val("42"), " / ", int_val("ff", 16), "\n")

:see
trim

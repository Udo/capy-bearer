:sig
u64 int_val(String s, u32 base = 10)

:params
s : string that can contain an integer
base : number base, default `10`
return value : parsed `u64`, or `0` when no usable number exists

:see
>string
float_val
0_String

:content
`int_val()` extracts an unsigned integer from a string. It returns `0` when it cannot identify a usable number.

`base` selects the number base and defaults to `10`. Use it for numeric input text. In C++ `.uce`, the same call returns `u64`.

:example capy render
var decimal := "0"
if int_val("42") == 42 { decimal = "42" }
var hexadecimal := "0"
if int_val("ff", 16) == 255 { hexadecimal = "255" }
print(decimal, " / ", hexadecimal, "\n")

:example cpp render
print(int_val("42"), " / ", int_val("ff", 16), "\n");

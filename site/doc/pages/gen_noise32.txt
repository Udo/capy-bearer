:sig
u32 gen_noise32(u32 index, u32 seed = 0)

:params
index : deterministic input position
seed : deterministic input seed, default `0`

:returns
deterministic noise value

:see

:content
`gen_noise32()` returns a deterministic unsigned noise value for `index` and `seed`. Capy represents the result as `u64`.

Use it for repeatable integer noise. Capy returns the `u32` value shown above.


:example capy render
var generated := gen_noise32(1, 2)
print("noise32\n")

:sig
String signal_name(s32 sig)

:params
sig : POSIX signal number

:returns
signal name, or an empty string for an unknown number

:see
>runtime
backtrace_capture
backtrace_get_frames
error_pages
unit_info
units_list
unit_compile
:content
Capy `signal_name(sig)` returns the POSIX name for a signal number. Give it a numeric signal value.

It returns names such as `SIGSEGV`. It returns an empty string when the number is unknown. Use it to add a signal name to an error message or diagnostic output.

:example capy render
print(signal_name(11), " / ", signal_name(6), "\n")

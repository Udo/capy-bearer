:sig
String first(String... args)

:params
args : zero or more strings, in selection order
return value : first nonblank string, or an empty string

:see
>string

:content
`first()` returns the first nonblank string. It returns an empty string when no argument is nonblank.

It ignores leading and trailing whitespace when it tests each argument. Use it to select a fallback string.


:example capy render
print(first("", "fallback", "other"), "\n")

:example cpp render
print(first("", "fallback", "other"), "\n");

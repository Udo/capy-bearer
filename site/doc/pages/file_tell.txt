:sig
s64 file_tell(u64 h)

:params
h : handle from `file_open()`

:returns
current absolute byte offset

:content
`file_tell` returns the current byte offset for a handle. Use it to record the position after `file_read()`, `file_write()`, or `file_seek()`. Capy uses the same numeric result.

:example capy render
var handle := file_open("/tmp/doc-tell.txt", "w")
file_write(handle, "hello")
print("offset is ", file_tell(handle), "\n")
file_close(handle)

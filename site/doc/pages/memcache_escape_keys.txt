:sig
DValue memcache_escape_keys(DValue keys)

:params
keys : input `dval` values

:returns
new `dval` list of escaped keys

:see
>sys
>memcache_escape_key
basename
dirname
expand_path
file_append
file_exists
file_get_contents
:content
This function converts each input item to a string and returns a new `dval` list.

It applies `memcache_escape_key()` to every item. The C++ API uses the same `DValue` input and result model.

:example capy render
var keys := dval(["a b", "c\td"])
print(join(memcache_escape_keys(keys), ", "), "\n")

:example cpp render
DValue keys;
keys.push_back("a b");
keys.push_back("c\td");
print(join(memcache_escape_keys(keys), ", "), "\n");

:sig
function memcache_escape_keys(keys : dval) dval

:params
keys : the input values

:returns
a list of escaped keys

:content
`memcache_escape_keys()` converts each input item to a string and escapes it as a Memcache key.

:example capy render
var keys := memcache_escape_keys(dval(["a key", "b\tkey"]))
print(join(keys, ","), "\n")

:sig
String hmac_sha256_hex(String key, String data)

:params
key : secret string bytes
data : message string bytes

:returns
64-character lowercase hexadecimal HMAC-SHA256 string

:content
`hmac_sha256_hex()` returns the HMAC-SHA256 for `key` and `data` as lowercase hexadecimal text.

Use it when you need a printable signature. Compare received signatures with `crypto_equal()`.

:example capy render
print(hmac_sha256_hex("key", "The quick brown fox jumps over the lazy dog"), "\n")

:see

hmac_sha256

:title
INIT

:sig
INIT(Request& context)

:see

:content
`function INIT` defines the Capy worker-load hook.

Use `function INIT { ... }` for the normal form. You can also declare `function INIT(request : request) { ... }`. The optional input is an opaque Capy request value.

The hook accepts no other inputs and returns no value. It runs once when a worker loads this unit instance. Use it to prepare worker-local state, caches, or static lookup data.

Do not use `INIT` for state that must reset for each request. Use `ONCE` for that state. Bearer can load a unit during a request, so the optional request value is valid for that load.

The compiler rejects other parameter forms, a return type, and handler overloads. A trap in `INIT` stops the load invocation.

## C++ API

C++ declares `INIT(Request& context)`. It receives the live request context when Bearer loads the unit during a request.

Capy does not expose C++ `Request&` or its mutable fields. Use the opaque `request` value and Capy request functions. Capy cannot use C++ references or direct C++ object access.

:content
`function INIT(request : dval)` defines the Capy unit materialization hook.

Every Capy Bearer handler has exactly one parameter. The parameter name is `request`. Its type is `dval`. The value is a copied request snapshot. Bearer runs this hook before dispatch in a request workspace.

Read input from the request fields. Use response, session, output, and WebSocket functions for effects. The compiler rejects zero parameters, other parameter types, extra parameters, return types, and handler overloads.

C++ declares `INIT(Request& context)`. It receives the live request context after Bearer materializes the unit in that request workspace.

:example capy render
print(string(request.method, ""), "\n")

:example cpp render
print(context.params["REQUEST_METHOD"], "\n");

:title
ws_message

:sig
String ws_message()

:returns
payload of the current WebSocket message

:see
>websocket
>0_Request

:capy-status cpp-specific

:content
`ws_message()` is a C++ API. It returns the current WebSocket message payload. Text messages return text. Binary messages return raw bytes in the `String` value. Outside a WebSocket handler, it returns an empty string.

Use `ws_is_binary()` or `ws_opcode()` before you parse the payload.

Capy does not expose `ws_message`. In a Capy `WS` handler, read `request.body`.

:example cpp render
print("payload length in this non-WS context: ", ws_message().length(), "\n");

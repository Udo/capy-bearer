:sig
String ws_message()

:params
return value : payload of the current WebSocket message

:see
>websocket

:content
In Capy, `ws_message()` takes no inputs and returns the current WebSocket message payload as a `string`.

Text messages return text. Binary messages return raw bytes in the `string` value.

Use `ws_is_binary()` or `ws_opcode()` before you parse the payload. Outside a WebSocket handler, the result is an empty string.

The empty string is the normal no-message result. C++ returns the same value as `String`.

:example capy render
print("payload length in this non-WS context: ", length(ws_message()), "\n")

:example cpp render
// Inside a WS message handler ws_message() returns the current frame payload.
print("payload length in this non-WS context: ", ws_message().length(), "\n");

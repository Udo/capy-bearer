:sig
u64 draw_int(u64 from, u64 to)

:params
from : first range value
to : second range value
return value : `u64` noise value between `from` and `to`

:see
>noise

:content
`draw_int()` returns a Capy `u64` noise value between two values.

Pass the range values. Bearer uses the request random seed and advances its random index after each call.

Use it when one request needs repeatable integer noise values from its random sequence.

The C++ `.uce` call has the same arguments.

:example capy render
if draw_int(1, 10) >= 1 { print("int\n") } else { print("bad\n") }
:example cpp render
print(draw_int(1, 10) >= 1 ? "int\n" : "bad\n");

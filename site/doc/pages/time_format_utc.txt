:sig
String time_format_utc(String format = "", u64 timestamp = 0)

:params
format : optional Capy format string
timestamp : optional Unix timestamp. Omit it to use the current time.

:returns
formatted UTC string

:content
Use `time_format_utc` to format a Unix timestamp in UTC. Pass a format string and, if needed, a timestamp. The function returns a Capy `string`. Omit the timestamp to format the current time.

The formatter supports core Linux `date` format tokens and the relative-time delta tokens. Pass `RFC1123` to use the built-in RFC 1123 UTC format.

Padding and case flags may follow `%`:


Capy uses `string` and `u64` values. C++ `.uce` uses `String` and `u64`, as the signature shows.

:example capy render
print(time_format_utc("%Y-%m-%d", 0), "\n")

:example cpp render
print(time_format_utc("%Y-%m-%d", 0), "\n");

:sig
String replace(String s, String search, String replace_with)

:params
s : source text
search : literal text to replace
replace_with : replacement text

:returns
source text with every literal match replaced

:see
>string

:content
In Capy, use this function to replace every literal occurrence of `search` in `s`.

The function returns the changed text. It does not change `s`. Use `regex_replace()` when the search pattern is a regular expression.

:example capy render
print(replace("hello docs", "docs", "BEARER"), "\n")

:example cpp render
print(replace("hello docs", "docs", "BEARER"), "\n");

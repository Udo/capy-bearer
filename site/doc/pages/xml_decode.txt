:sig
DValue xml_decode(String s)

:params
s : XML source string

:returns
element-shaped `dval`

:see
>markup
xml_encode

:content
`xml_decode(source)` accepts XML source as a `string` and returns a structured `dval`.

Use it to read XML data into the element shape that `xml_encode()` accepts. It reads the first root element.

The parser supports elements, quoted attributes, text, CDATA, comments, processing instructions, and XML entities. It does not validate schemas, DTDs, namespaces, or document types.

Malformed XML raises a request-visible runtime error. C++ returns the same data as `DValue` through the signature above.

:example capy render
var node := xml_decode("<root><name>Ada</name></root>")
if dval_is_array(node) { print("xml\n") } else { print("empty\n") }

:example cpp render
DValue node = xml_decode("<root><name>Ada</name></root>");
print(node.is_array() ? "xml\n" : "empty\n");

:title
Store a Boolean value

:sig
function dval_set_bool(value : dval, flag : bool) dval

:params
value : target value
flag : Boolean value to store

:returns
The changed target value.

:content
`dval_set_bool` stores `flag` in `value`. It changes and returns the target value.

:example capy render
var flag := dval_set_bool(dval(""), true)
print(bool(flag), "\n")

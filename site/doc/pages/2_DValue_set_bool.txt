:sig
void DValue::set_bool(bool b)

:params
b : boolean value to store
return value : none

:see
0_DValue
2_DValue_to_bool

:content
`dval_set_bool(value, flag)` takes a `dval` and a boolean. It returns a replacement that stores `flag`. Assign the result back to retain the update.

## C++ API

`DValue::set_bool()` changes the object in place and can follow an internal reference.

:example capy render
var flag := dval_set_bool(dval(""), true)
if bool(flag) { print("true\n") } else { print("false\n") }

:example cpp render
DValue flag;
flag.set_bool(true);
print(flag.to_bool() ? "true" : "false", "\n");

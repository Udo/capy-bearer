:sig
void DValue::set_bool(bool b)

:params
b : boolean value to store

:returns
none

:see
0_DValue
2_DValue_to_bool

:content
`dval_set_bool(value, flag)` stores the Boolean in the target. It mutates `value` and returns that same identity. All workspace aliases observe the mutation. Assigning the result back remains valid.

## C++ API

`DValue::set_bool()` changes the object in place and can follow an internal reference.

:example capy render
var flag := dval_set_bool(dval(""), true)
if bool(flag) { print("true\n") } else { print("false\n") }

:sig
function sqlite_info(handle : u64, key : string) dval

:params
handle : the SQLite connection handle
key : `error`, `insert_id`, or `affected_rows`

:returns
The value for `key`.

:errors
The function stops with an error for an unknown key. The error lists the valid keys.

:content
`sqlite_info()` reads the latest error text, the last inserted row ID, or the changed-row count.

Use a converter with a fallback because the values have different types.

:example capy render
var db := sqlite_connect(":memory:")
sqlite_query(db, "create table t(id integer primary key)")
sqlite_query(db, "insert into t values(1)")
var message := string(sqlite_info(db, "error"), "")
var id := u64(sqlite_info(db, "insert_id"), 0)
var rows := u64(sqlite_info(db, "affected_rows"), 0)
print(message, " ", id, " ", rows, "\n")
sqlite_disconnect(db)

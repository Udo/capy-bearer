:sig
function sqlite_affected_rows(handle : u64) u64

:returns
Rows changed by the latest statement.

:content
Use `sqlite_affected_rows` after an insert, update, or delete.

:example capy render
var db := sqlite_connect(":memory:")
sqlite_query(db, "create table t(id integer)")
sqlite_query(db, "insert into t values(1)")
print(sqlite_affected_rows(db), "\n")
sqlite_disconnect(db)

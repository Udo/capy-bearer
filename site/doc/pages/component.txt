:sig
function component(name : string) string
function component(name : string, props : as dval) string

:params
name : a component name or named handler
props : optional input for `request.props`

:returns
The component output.

:content
`component()` renders a component and returns its output as a string.

Use it when a larger result needs a component fragment. `component_render()` writes output directly.

Bearer accepts a component path with or without the `.capy` suffix. A colon selects a named handler. A leading colon selects a handler in the current file.

Use `component_exists()` before an optional component.

:example capy render
var props := {name: "Capy"}
print(component("/tests/capy-request-context.capy", props), "\n")

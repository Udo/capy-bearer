:content
Capy's `brb_decode(encoded)` returns the decoded `dval` value. Pass BRRB1 bytes from `brb_encode()`.

Invalid input returns an empty `dval`. Capy has no error-output form. Use the returned value with Capy's value semantics. It does not modify another value.

The C++ one-argument `DValue` form has the same result. Its three-argument form also returns a success flag and an error string.


:example capy render
var original := dval({"n": "7"})
var restored := brb_decode(brb_encode(original))
print(dval_string(restored["n"]), "\n")
:example cpp render
DValue original; original["n"] = "7";
DValue restored = brb_decode(brb_encode(original));
print(restored["n"].to_string(), "\n");

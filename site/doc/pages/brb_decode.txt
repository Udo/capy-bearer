:content
Capy's `brb_decode(encoded)` returns the decoded `dval` value. Pass BRRB2 bytes from `brb_encode()`.

Invalid input returns an empty string value. Capy has no error-output form. It does not modify another value.

BRRB preserves the distinct `N` tag for `none`. A decoded `N` value remains `none` in Capy and C++.

The C++ one-argument `DValue` form has the same result. Its three-argument form also returns a success flag and an error string.

:example capy render
var original := dval({"n": "7", "missing": none})
var restored := brb_decode(brb_encode(original))
print(restored.n, " / ", restored.missing?, "\n")

:example cpp render
DValue original;
original["n"] = "7";
original["missing"].set_none();
DValue restored = brb_decode(brb_encode(original));
print(restored["n"].to_string(), " / ", restored["missing"].is_none() ? "false" : "true", "\n");

:sig
function brb_decode(encoded : string) dval

:params
encoded : BRRB data

:returns
a decoded `dval` value

:content
`brb_decode` decodes BRRB data into a `dval` value.

Use it to read data from `brb_encode`.

:example capy render
var value := brb_decode(brb_encode(dval({"name": "Ada"})))
print(value["name"], "\n")

:see
brb_encode
json_decode

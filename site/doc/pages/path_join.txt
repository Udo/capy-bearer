:sig
String path_join(String base, String child)

:params
base : the base path
child : the path to append

:returns
the joined path

:content
`path_join()` returns a `string` that joins `base` and `child` with one `/` when needed.

If `child` starts with `/`, it replaces `base`. If either value is empty, the API returns the other value.

This API does not resolve `.` or `..` segments. Use `path_real()` when you need a canonical existing path.

:example capy render
print(path_join("/var/www", "site/index.capy"), "\n")

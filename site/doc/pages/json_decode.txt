:content
In Capy, this function decodes JSON text into `dval` data.

JSON objects become map-shaped values. JSON arrays become list-shaped values. JSON booleans become `bool` values. JSON strings become `string` values. JSON numbers become string values, so use a typed conversion to read them.

JSON `null` becomes an empty string value. Malformed JSON returns empty or partial data without an error. Use `dval` accessors to read the result.

:example capy render
var data := json_decode("{\"name\": \"Ada\", \"tags\": [\"x\", \"y\"]}")
print(dval_string(data["name"]), " has 2 tags\n")

:example cpp render
DValue data = json_decode("{\"name\": \"Ada\", \"tags\": [\"x\", \"y\"]}");
print(data["name"].to_string(), " has ", data["tags"].keys().size(), " tags\n");

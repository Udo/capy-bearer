:sig
DValue json_decode(String s)

:params
s : text that contains JSON data

:returns
decoded `dval` data

:content
In Capy, this function decodes JSON text into `dval` data.

JSON objects become map-shaped values. JSON arrays become list-shaped values. JSON booleans become bool values. JSON strings and numbers become string values.

JSON `null` becomes `none` in Capy and C++. Use a constructor fallback when you read it as a scalar.

Malformed JSON returns empty or partial data without an error. Use safe reads or constructors to read the result.

:example capy render
var data := json_decode("{\"name\": \"Ada\", \"tags\": [\"x\", \"y\"]}")
print(data.name, " has 2 tags\n")

:example cpp render
DValue data = json_decode("{\"name\": \"Ada\", \"tags\": [\"x\", \"y\"]}");
print(data["name"].to_string(), " has ", data["tags"].keys().size(), " tags\n");

:sig
void redirect(String url, s32 code = 302)

:params
url : the redirect target URL
code : the optional HTTP redirect status. The default is `302`.

:see
>uri
2_Request_set_status
0_Request

:content
In Capy, `redirect()` sets the response `Location` header and status code.

Call `redirect(url)` for status `302`. Use the two-argument form for another status.

Use this API instead of setting the response header and status separately.


:example capy cli
redirect("/next")
print("redirect(\"/next\") sends an HTTP redirect.\n")

:example cpp cli
redirect("/next");
print("redirect(\"/next\") sends an HTTP redirect.\n");

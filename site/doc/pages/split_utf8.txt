:sig
DValue split_utf8(String str, bool compound_characters = false)


:params
str : UTF-8 string to split
compound_characters : when true, combine selected multi-code-point characters

:returns
list-shaped `dval` with UTF-8 string entries

:see
>string
split_space
replace
split_kv
regex_match
split_http_headers
regex_search
:content
Capy `split_utf8(str, compound_characters)` returns a list-shaped `dval` of UTF-8 strings. Give it UTF-8 text.

By default, it returns one entry for each code point. When `compound_characters` is true, it also joins characters linked by a Zero-Width Joiner. It joins two Regional Indicator Symbol Letters and attaches Variation Selectors to the previous entry.

Use it when byte or ASCII splitting would break Unicode text. The C++ API calls the result `DValue`. Capy uses the `dval` value type.

:example capy render
var chars := split_utf8("Hi")
print(join(chars, ","), "\n")

:sig
String ob_get()

:returns
the current output buffer contents

:content
In Capy, `ob_get()` returns the current output buffer as a `string`. The buffer stays active, so later `print()` calls add more output.

Use `ob_get_close()` to get the contents and close the buffer.

:example capy render
ob_start()
print("partial")
var snapshot := ob_get()
ob_close()
print("snapshot was: ", snapshot, "\n")

:example cpp render
ob_start();
print("partial");
String snapshot = ob_get();
ob_close();
print("snapshot was: ", snapshot, "\n");

:see

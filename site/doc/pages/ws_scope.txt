:title
ws_scope

:sig
String ws_scope()

:params
return value : scope identifier of the current WebSocket endpoint

:see
>websocket
>ws_connections
>0_Request

:capy-status cpp-specific

:content
`ws_scope()` is a C++ API. It returns the current WebSocket scope. Outside a WebSocket handler, it returns an empty string.

Use this value with `ws_send()`, `ws_connections()`, or `ws_connection_count()` when C++ code needs an explicit scope. Capy keeps `ws_send()` for effects.

Capy does not expose `ws_scope`. In a Capy `WS` handler, read `request.websocket.scope`.

:example cpp render
String scope = ws_scope();
print(scope == "" ? "(no WS scope in this context)" : scope, "\n");

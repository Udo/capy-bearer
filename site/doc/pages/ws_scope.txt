:sig
String ws_scope()

:params
return value : scope identifier of the current WebSocket endpoint

:see
>websocket

:content
In Capy, `ws_scope()` takes no inputs and returns the current WebSocket scope as a `string`.

Use this value with `ws_send()`, `ws_connections()`, or `ws_connection_count()` when you need an explicit scope. Outside a WebSocket handler, it returns an empty string.

The empty string is the normal no-scope result. C++ returns the same value as `String`.

:example capy render
var scope := ws_scope()
if scope == "" { scope = "(no WS scope in this context)" }
print(scope, "\n")

:example cpp render
String scope = ws_scope();
print(scope == "" ? "(no WS scope in this context)" : scope, "\n");

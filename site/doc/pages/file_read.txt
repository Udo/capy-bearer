:sig
String file_read(u64 h, u64 len)

:params
h : readable handle from `file_open()`
len : maximum number of bytes to read
return value : a Capy `string` with up to `len` bytes from the current position

:content
In Capy, `file_read()` returns a `string` from the current handle position. It advances the position by the bytes read.

End of file can return fewer bytes or `""`. Use `file_pread()` to read an absolute offset without moving the position.

:example capy render
var writer := file_open("/tmp/doc-read.txt", "w")
file_write(writer, "hello world")
file_close(writer)
var reader := file_open("/tmp/doc-read.txt", "r")
print(file_read(reader, 5u64), "\n")
file_close(reader)

:example cpp render
u64 w = file_open("/tmp/doc-read.txt", "w");
file_write(w, "hello world");
file_close(w);
u64 r = file_open("/tmp/doc-read.txt", "r");
print(file_read(r, 5), "\n");
file_close(r);

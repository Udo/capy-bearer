`cli_input()` is a C++ API. It returns a map that merges query parameters, form parameters, and JSON object fields. Later sources replace earlier fields with the same name.

A JSON scalar or list is stored at `input["_"]`. Use this API when C++ code needs several input values or DValue values.

Capy does not expose `cli_input`. In a Capy `CLI` handler, read `request.query`, `request.form`, and `request.body` directly. A Capy handler receives exactly one copied `request : dval`.

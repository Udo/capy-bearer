:content
`cli_input()` returns CLI request values as one Capy `dval` map.

It merges query parameters, form parameters, and JSON object fields. Later sources replace earlier values with the same key.

A JSON scalar or list is stored at `input["_"]`. Use this function when a command needs several values or DValue types.

In C++ `.uce`, pass `context` as the first argument. Capy gets the request data without that argument.

:example capy render
var input := cli_input()
var count := 0
for key, value = input { count = count + 1 }
print("parsed ", count, " CLI arguments\n")
:example cpp render
DValue input = cli_input(context);
print("parsed ", input.keys().size(), " CLI arguments\n");

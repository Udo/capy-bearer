:sig
s32 usleep(u32 usec)

:params
usec : microseconds to sleep

:returns
`0` after sleeping

:see

time_precise

:content
`usleep(usec)` accepts a microsecond count and returns `0` after the wait.

Use it for a short wait in a local test, polling loop, or task. Long waits hold a worker for the wait duration.

Use `sleep()` for whole-second waits. The API has no error return.

C++ uses the signature above. Its input type differs from the Capy `s32` declaration.

:example capy render
usleep(1000)
print("slept\n")

:example cpp render
usleep(1000);
print("slept\n");

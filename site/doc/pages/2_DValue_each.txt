:title
Iterate dynamic values

:sig
for value, key := input { ... }

:params
input : value to iterate

:content
Use `for value, key := input` to iterate a dynamic value. `value` is a copied child and `key` is a string.

Lists use numeric keys in order. Maps use key order. A scalar runs the loop once with an empty key.

:example capy render
var value := dval({"name": "Ada", "role": "admin"})
for item, key := value {
    print(key, "=", item, "\n")
}

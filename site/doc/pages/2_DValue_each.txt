:sig
void DValue::each(std::function<void (const DValue& item, String key)> f) const

:params
f : callback invoked for each child, or once for a scalar value

:returns
none

:see
>types
0_DValue
2_DValue_map
2_DValue_filter
2_DValue_is_list

:content
Use `for item, key := value` in Capy. The item comes first and is a copied DValue. The key has type `string`. Lists use decimal index strings in order. Maps use string-key order. A scalar runs the loop once with an empty key.

The loop uses a live view and rechecks the current count. A loop that keeps growing `value` can continue.

C++ `each(f)` does not modify the `DValue`. Its callback receives the child and key. It dereferences references before it iterates.

:example capy render
var user := dval({"name": "Ada", "role": "admin"})
var keys := dval([])
for item, key := user { keys = dval_push(keys, key) }
print(join(sort(keys), ","), "\n")

:example cpp render
DValue user;
user["name"] = "Ada";
user["role"] = "admin";
StringList keys;
user.each([&](const DValue& item, String key) { keys.push_back(key); });
print(join(keys.sort(), ","), "\n");

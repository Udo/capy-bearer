:sig
void session_destroy(String session_name = "bearer-session")

:params
session_name : session cookie name

:see
>session
session_remove
response_cookie
session_set
session_start
session_id_create
:content
Use this function to end the named session.

It expires the cookie and removes the matching server-side session file. In Capy, `session_destroy` returns `{id, name, values}` for the resulting state. The fields are empty for the destroyed session. C++ keeps its documented `void` behavior.

:example capy render
var session := session_start("bearer-doc-example-destroy")
session = session_destroy("bearer-doc-example-destroy")
if string(session.id, "") == "" { print("destroyed\n") } else { print("active\n") }

:sig
void session_destroy(String session_name = "bearer-session")

:params
session_name : session cookie name

:see
>session

:content
In Capy, use this function to end the named session.

It expires the cookie and removes the matching server-side session file. For the active session, a later `request_context()` snapshot has empty `session_id`, `session_name`, and `session` fields.

:example capy render
var id := session_start("bearer-doc-example-destroy")
session_destroy("bearer-doc-example-destroy")
if id != "" { print("destroyed\n") } else { print("empty\n") }

:example cpp render
String id = session_start("bearer-doc-example-destroy");
session_destroy("bearer-doc-example-destroy");
print(id != "" ? "destroyed\n" : "empty\n");

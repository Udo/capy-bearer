:sig
void Request::ob_start()

:returns
none

:see
0_Request
ob_start

:content
`ob_start()` starts a new output buffer for the active request. It returns no value. Output after the call goes to this buffer until `ob_get`, `ob_get_close`, or `ob_close` uses it.

Use `ob_start`, `ob_get`, `ob_get_close`, and `ob_close` for normal Capy output capture. Capy does not expose `context.ob`.

## C++ API

`Request::ob_start()` creates the active `context.ob` buffer.


:example capy render
ob_start()
print("fragment")
var captured := ob_get_close()
print("captured: ", captured, "\n")

:example cpp render
context.ob_start();
print("fragment");
String captured = ob_get_close();
print("captured: ", captured, "\n");

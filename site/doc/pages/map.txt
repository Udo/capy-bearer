:sig
DValue map(DValue items, function<String (String)> f)
DValue::map(function<String (String)> f)

:params
items : list of items to transform
f : a function that returns the transformed value for each item
return value : a new list containing the transformed values

:see
>string
filter
0_DValue

:content
Returns a new list by calling `f` for each item in `items`.


Use `filter()` when you want to keep only matching items, and `map()` when you want to transform each item.


:example capy render
var names := split("ada,grace", ",")
var upper := map(names, function(item : string) string { return to_upper(item) })
print(join(upper, ","), "\n")

:example cpp render
DValue names = split("ada,grace", ",");
DValue upper = map(names, [](String item) { return(to_upper(item)); });
print(join(upper, ","), "\n");

:sig
DValue map(DValue items, function<String (String)> f)
DValue::map(function<String (String)> f)

:params
items : list of string items to transform
f : function that returns one string for each item
return value : new list of transformed strings

:see
>string
filter
0_DValue

:content
In Capy, this function calls `f` for each list item and returns a new list.

Use it to transform each string in a list. Capy converts each input item with `string()` before it calls `f`.

Use `filter()` when you want to keep matching items instead.

:example capy render
var names := split("ada,grace", ",")
var upper := map(names, function(item : string) string { return to_upper(item) })
print(join(upper, ","), "\n")

:example cpp render
DValue names = split("ada,grace", ",");
DValue upper = map(names, [](String item) { return(to_upper(item)); });
print(join(upper, ","), "\n");

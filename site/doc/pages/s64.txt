:sig
s64(value : dval, fallback : s64 = 0) s64
s64(value : string, fallback : s64 = 0) s64

:params
value : source value to convert
fallback : value returned when conversion fails

:returns
converted `s64`, or `fallback`

:content
Use `s64` to convert input to a 64-bit signed integer.

`s64(dval, fallback)` accepts scalar `bool`, finite `f64`, and exact decimal text. Decimal text must contain a whole number.

`s64(string, fallback)` trims spaces and then applies the same rules. A float input truncates toward zero.

:errors
`s64` does not throw. It returns `fallback` for invalid text, `none`, maps, lists, or out-of-range values.

:example capy render s64() parses integer text and numbers
print(s64("64"), "\n")
print(s64(dval(-12.8), -1), "\n")

:example cpp render s64() parses integer text and numbers
DValue text;
text = "64";
DValue number;
number = -12.8;
print(text.to_s64(), "\n");
print(number.to_s64(-1), "\n");

:example capy render s64() returns the fallback for empty text
print(s64("", -1), "\n")

:example cpp render s64() returns the fallback for empty text
DValue value;
value = "";
print(value.to_s64(-1), "\n");

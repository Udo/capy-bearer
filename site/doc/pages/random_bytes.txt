:sig
String random_bytes(u64 n)

:params
n : the number of random bytes to request

:returns
cryptographically random bytes

:content
`random_bytes()` returns cryptographically secure bytes as a `string`. The API returns no more than 1 MiB. It can return fewer bytes, including an empty string, if the random source fails.

Use these bytes for session IDs, tokens, and salts. The result can contain binary bytes. Use `base64_encode()` or `sha256_hex()` when you need printable text.

:example capy render
var token := base64_encode(random_bytes(16))
print(length(random_bytes(16)), " raw bytes; as base64 token: ", length(token), " chars\n")

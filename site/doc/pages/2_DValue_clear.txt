:sig
void DValue::clear()

:params
return value : none

:see
0_DValue
2_DValue_set_array

:content
Use `dval_clear(value)` in Capy to remove all children and make the target an empty map. It mutates `value` and returns that same identity. All workspace aliases observe the mutation. Assigning the result back remains valid. Use `dval_set_array()` for an empty list.

C++ `clear()` empties this `DValue` and resets its array index. It does not set list mode.


:example capy render
var user := dval({"a": "1", "b": "2"})
user = dval_clear(user)
if dval_has(user, "a") { print("after clear, has a: yes\n") } else { print("after clear, has a: no\n") }

:example cpp render
DValue u;
u["a"] = "1"; u["b"] = "2";
u.clear();
print("after clear, has a: ", u.has("a") ? "yes" : "no", "\n");

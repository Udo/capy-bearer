:title
Clear a dynamic value

:sig
function dval_clear(value : dval) dval

:params
value : target value

:returns
The cleared target value.

:content
`dval_clear(value)` removes all children and makes `value` an empty map. Use `dval_set_array` for an empty list.

:example capy render
var value := dval({"name": "Ada"})
value = dval_clear(value)
print(dval_has(value, "name"), "\n")

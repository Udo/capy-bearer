:sig
void csrf_rotate(String session_name = "bearer-session", String token_name = "csrf_token")

:params
session_name : session and cookie name
token_name : token namespace to clear

:content
`csrf_rotate()` removes the active Capy CSRF token from a token namespace.

Pass the session name and token namespace. It starts the named session when necessary. The next `csrf_token()` call creates a replacement token.

Use it after a sensitive successful change when the same submitted form must not work again.

The C++ `.uce` call has the same arguments.

:example capy render
var old_token := csrf_token()
csrf_rotate()
var new_token := csrf_token()
if old_token != new_token { print("rotated\n") } else { print("unchanged\n") }
:example cpp render
String old_token = csrf_token();
csrf_rotate();
String new_token = csrf_token();
print(old_token != new_token ? "rotated\n" : "unchanged\n");

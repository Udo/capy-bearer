:sig
void DValue::set_array()

:params
return value : none

:see
0_DValue
2_DValue_push
2_DValue_is_list

:content
`dval_set_array(value)` takes a `dval` and returns an empty list-shaped replacement. Assign the result back to retain the update. Later `dval_push` calls use numeric keys from `0`.

## C++ API

`DValue::set_array()` changes the object in place.

:example capy render
var list := dval_push(dval_set_array(dval("")), dval("first"))
if dval_is_list(list) { print("is_list=yes") } else { print("is_list=no") }
if dval_has(list, "0") { print(" count=1\n") } else { print(" count=0\n") }

:example cpp render
DValue list;
list.set_array();
DValue item; item.set("first");
list.push(item);
print("is_list=", list.is_list() ? "yes" : "no", " count=", list.keys().size(), "\n");

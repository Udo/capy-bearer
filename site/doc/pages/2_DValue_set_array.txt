:title
Make an empty list

:sig
function dval_set_array(value : dval) dval

:params
value : target value

:returns
The changed target value.

:content
`dval_set_array` makes `value` an empty list. Later `dval_push` calls start at index `0`.

:example capy render
var list := dval_set_array(dval(""))
list = dval_push(list, "first")
print(dval_is_list(list), " ", list[0], "\n")

:sig
String csrf_field(String session_name = "bearer-session", String token_name = "csrf_token", String field_name = "")

:params
session_name : session and cookie name
token_name : token namespace
field_name : submitted form field name. The default is `token_name`.

:returns
HTML hidden input with the active CSRF token

:content
`csrf_field()` returns an HTML hidden input with the active Capy CSRF token.

Pass the session name, token namespace, and optional form field name. It starts the named session when necessary. It HTML-escapes the field name and token value.

Use it in server-rendered forms that change state. Validate the submitted field with `csrf_valid()` before you change state.

The C++ `.uce` call has the same arguments.

:example capy render
var field := csrf_field("bearer-doc-session", "profile_form", "csrf_token")
print(strpos(field, "type=\"hidden\"") >= 0, "\n")
:example cpp render
String field = csrf_field("bearer-doc-session", "profile_form", "csrf_token");
print(field.find("type=\"hidden\"") != String::npos ? "true\n" : "false\n");

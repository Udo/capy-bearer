:sig
DValue::map(String mapper) (legacy `StringList` page)

:content
`map(items, mapper)` takes a list-shaped `dval` and a string mapper. It returns a new list-shaped `dval` of mapped strings in input order.

Capy has no separate `StringList` type. It uses list-shaped DValues. The function returns a new list and does not mutate `items`.

## C++ API

`DValue::map()` provides the legacy StringList operation.

:see
0_DValue
2_DValue_map

:example capy render
var items := split("one,two", ",")
var upper := map(items, function(value : string) string { return upper(value) })
print(join(upper, ","), "\n")

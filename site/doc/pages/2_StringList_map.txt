:title
Map strings

:sig
function map(items : dval, mapper : function(value : string) string) dval

:returns
This function returns a new list-shaped `dval`.

:content
`map` calls `mapper` for each string in a list-shaped `dval`.

The result keeps input order. This function does not change `items`.

:example capy render
var items := split("one,two", ",")
var names := map(items, function(value : string) string { return upper(value) })
print(join(names, ","), "\n")

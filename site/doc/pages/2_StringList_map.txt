:sig
DValue::map(String mapper) (legacy `StringList` page)

:content
`map(items, mapper)` takes a list-shaped `dval` and a string mapper. It returns a new list-shaped `dval` of mapped strings in input order.

Capy has no separate `StringList` type. It uses copied `dval` values.

## C++ API

`DValue::map()` provides the legacy StringList operation.

:see
0_DValue
2_DValue_map

:example capy render
var items := split("one,two", ",")
var upper := map(items, function(value : string) string { return to_upper(value) })
print(join(upper, ","), "\n")
:example cpp render
StringList items = split("one,two", ",");
print(join(items.map([](String value) { return to_upper(value); }), ","), "\n");

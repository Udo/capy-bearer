:sig
StringMap DValue::to_stringmap() const

:params
return value : map-shaped `dval` in Capy. C++ returns a `StringMap` copy

:see
>types
0_DValue
0_StringMap
2_DValue_to_string

:content
`dval_to_stringmap(value)` takes a `dval` and returns a map-shaped `dval` of strings. Map children become entries after string conversion. A nonempty string becomes a `value` entry. An f64 or boolean also becomes a `value` entry.

An empty string returns an empty map. Capy has no separate `StringMap` type. Use the returned `dval` as a map.

## C++ API

`DValue::to_stringmap()` returns a `StringMap`. It also converts pointers and returns an empty map for an unresolved reference.

:example capy render
var user := dval({"name": "Ada"})
var fields := dval_to_stringmap(user)
print(fields["name"], "\n")

:example cpp render
DValue user;
user["name"] = "Ada";
StringMap fields = user.to_stringmap();
print(fields["name"], "\n");

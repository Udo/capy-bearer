DValue to_stringmap

:content
`DValue::to_stringmap()` is a C++ API. It converts map children to string entries. A nonempty string, f64, or boolean becomes a `value` entry. An empty string returns an empty map.

It also converts C++ pointers. It returns an empty map for an unresolved reference. Capy does not expose `dval_to_stringmap`. Use a `dval` map directly.

:example cpp render
DValue user;
user["name"] = "Ada";
StringMap fields = user.to_stringmap();
print(fields["name"], "\n");

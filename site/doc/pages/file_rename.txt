:sig
bool file_rename(String from, String to)

:params
from : current path of the file
to : new path of the file

:returns
true when Capy renames the file, otherwise false

:content
`file_rename` moves a file from one path to another. Use it after writing a temporary file. A successful call removes the source path. It returns false when Capy cannot rename the file. Capy uses the same paths and Boolean result.

:example capy render
file_put_contents("/tmp/doc-rename-a.txt", "moved")
file_rename("/tmp/doc-rename-a.txt", "/tmp/doc-rename-b.txt")
var source_status := "gone"
if file_exists("/tmp/doc-rename-a.txt") { source_status = "exists" }
print(file_get_contents("/tmp/doc-rename-b.txt"), " / source ", source_status, "\n")

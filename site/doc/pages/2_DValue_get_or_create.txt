:sig
DValue* DValue::get_or_create(String s)

:params
s : child key to create or return

:returns
pointer to the child node

:see
0_DValue
2_DValue_key
2_DValue_has

:content
Use `dval_get_or_create(value, key)` in Capy to create an empty child when needed. It mutates `value` and returns that same target identity, not a child alias. All workspace aliases observe the mutation. Assigning the result back remains valid. A nonnumeric key changes a list into a map.

C++ `get_or_create(key)` returns a pointer to the child. It creates the child when needed.


:example capy render
var config := dval_get_or_create(dval({:}), "host")
config = dval_put(config, "host", "localhost")
if dval_has(config, "host") { print(config["host"], "\n") } else { print("missing\n") }

:example cpp render
DValue config;
config.get_or_create("host")->set("localhost");
print(config.has("host") ? config["host"].to_string() : "missing", "\n");

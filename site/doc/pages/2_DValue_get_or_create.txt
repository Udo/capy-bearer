:sig
DValue* DValue::get_or_create(String s)

:params
s : child key to create or return
return value : pointer to the child node

:see
0_DValue
2_DValue_key
2_DValue_has

:content
Use `dval_get_or_create(value, key)` in Capy to make sure a copied `dval` map has `key`. It returns the replacement map value, not a child alias. Assign the result back before you add the child value. It creates an empty child when needed. A nonnumeric key changes a list into a map.

C++ `get_or_create(key)` returns a pointer to the child. It creates the child when needed.


:example capy render
var config := dval_get_or_create(dval({:}), "host")
config = dval_put(config, "host", "localhost")
if dval_has(config, "host") { print(config["host"], "\n") } else { print("missing\n") }

:example cpp render
DValue config;
config.get_or_create("host")->set("localhost");
print(config.has("host") ? config["host"].to_string() : "missing", "\n");

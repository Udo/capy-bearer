:title
Get or create a child

:sig
function dval_get_or_create(value : dval, key : string) dval

:params
value : target value
key : child key

:returns
The target value.

:content
`dval_get_or_create` creates an empty child when `key` is missing. It changes and returns `value`.

:example capy render
var config := dval({:})
config = dval_get_or_create(config, "host")
config = dval_put(config, "host", "localhost")
print(config.host, "\n")

:sig
bool file_chmod(String path, u32 mode)

:params
path : path of the file or directory
mode : permission bits, such as 0644 or 0600

:returns
true when Capy changes the mode, otherwise false

:content
`file_chmod` sets permission bits on a path. Use it to restrict or grant file access. Capy receives `mode` as a number. The Capy example can use an octal literal such as `0600`.

:example capy render
file_put_contents("/tmp/doc-chmod.txt", "secret")
var result := "failed"
if file_chmod("/tmp/doc-chmod.txt", 384) { result = "mode set" }
print(result, "\n")

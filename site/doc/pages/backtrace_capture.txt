:sig
String backtrace_capture(u32 max_frames = 32, u32 skip_frames = 0)

:params
max_frames : maximum number of frames to capture
skip_frames : number of newest frames to omit

:returns
formatted backtrace string

:see
>runtime
backtrace_get_frames
signal_name
error_pages
trap
unit_info
units_list
:content
Capy's `backtrace_capture()` returns a formatted `string` for the current call stack. Use it for diagnostic output.

The zero-argument form captures up to 32 frames and skips none. The two-argument form accepts `max_frames` and `skip_frames`. The function returns an empty string when no trace is available. It does not report errors.

C++ uses the same operation with `u32` arguments. Native runtime error paths also use it.


:example capy render
var captured := backtrace_capture()
if captured == "" { print("(empty in the wasm sandbox; populated by the native crash handler)\n") }
else { print(captured, "\n") }
:example cpp render
String trace = backtrace_capture();
print(trace == "" ? "(empty in the wasm sandbox; populated by the native crash handler)" : trace, "\n");

:sig
String mysql_escape(String raw, char quote_char)

:params
raw : the string to escape
quote_char : the character that wraps the result. Pass `NULL` for no wrapper.

:returns
the escaped form of `raw`

:see
>mysql
mysql_error
mysql_insert_id
mysql_disconnect
mysql_affected_rows
mysql_connected
mysql_query
:content
`mysql_escape(raw)` escapes `raw` and wraps it in single quotes. Use the two-argument form to select one wrapper character.

Use an empty Capy string for no wrapper. In C++, pass `NULL` for no wrapper.

Use query parameters with `mysql_query()` when possible. Escape values only when you must build SQL text.

:example capy render
print(mysql_escape("O'Brien; DROP TABLE users", "'"), "\n")

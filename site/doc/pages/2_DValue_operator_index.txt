:title
Read a child by index

:sig
value[key]

:params
key : child key or list index

:returns
The copied child, or `none`.

:content
Use `value[key]` or `value[index]` to read a child. A missing child returns `none` and does not change the value.

Use `dval_put` to set a named child.

:example capy render
var value := dval({"site": {"title": "Bearer"}})
print(value["site"]["title"], "\n")

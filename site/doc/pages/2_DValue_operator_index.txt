:title
DValue::operator[]

:sig
DValue& DValue::operator[](String s)

:params
s : child key to return or create
return value : reference to the child node

:see
0_DValue
2_DValue_get_or_create
2_DValue_key
2_DValue_has

:content
In Capy, use `value[key]` or `value[index]` to read a child from a `dval`. The result is a copied `dval`, not a mutable alias. Use `dval_put` to set a named child and assign its returned replacement value.

A missing child does not give Capy a writable child reference. Use `dval_has` or `dval_get_by_path` when you need to test a read.

## C++ API

`DValue::operator[]` returns a mutable child reference. It creates a missing child and follows an internal reference. Use `has`, `key`, or `get_by_path` for a C++ read that must not create a child.


:example capy render
var value := dval({"a": {"b": "nested"}})
print(dval_to_string(value["a"]["b"]), "\n")

:example cpp render
DValue m;
m["a"]["b"] = "nested";
print(m["a"]["b"].to_string(), "\n");

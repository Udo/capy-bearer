:sig
void socket_close(u64 sockfd)

:params
sockfd : socket handle from `socket_connect()`

:see
>socket
http_request_async
socket_connect
http_request
socket_read
socket_write
:content
Capy `socket_close(sockfd)` closes a socket handle from `socket_connect()`. It does not return a value.

Call it after you finish reading or writing the socket. Do not use the handle after you close it.

:example capy render
var fd := socket_connect("127.0.0.1", 80)
if fd != 0 { print("opened a socket") } else { print("open failed") }
print(", now closing it\n")
socket_close(fd)

:example cpp render
u64 fd = socket_connect("127.0.0.1", 80);
print(fd != 0 ? "opened a socket" : "open failed", ", now closing it\n");
socket_close(fd);

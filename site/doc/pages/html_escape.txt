:sig
String html_escape(String s)

:params
s : string to encode for HTML text
return value : string with HTML-sensitive characters replaced by entities

:see
>string
json_encode
print
component

:content
`html_escape()` returns a string that is safe to insert as HTML text. Use it for text from users or other untrusted sources.

It escapes ampersands, angle brackets, and double quotes.

:example capy render
print(html_escape("<b>Tom & Jerry</b>"), "\n")

:example cpp render
print(html_escape("<b>Tom & Jerry</b>"), "\n");

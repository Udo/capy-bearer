:content
Capy's `array_merge(left, right)` returns a new `dval`. It does not change either input value.

Pass two `dval` maps, lists, or scalar values. String keys in `right` replace matching keys in `left`. List values append. They use consecutive numeric keys. The function does not report errors.

Use it to combine request, configuration, or JSON-shaped values. The C++ API also accepts `StringMap` values. Its `DValue` form has the same merge rules.

:example capy render
var merged := array_merge(dval({"name": "Ada"}), dval({"role": "admin"}))
print(dval_string(merged["name"]), " ", dval_string(merged["role"]), "\n")
:example cpp render
StringMap left;
left["name"] = "Ada";
StringMap right;
right["role"] = "admin";
StringMap merged = array_merge(left, right);
print(merged["name"], " ", merged["role"], "\n");

:sig
function mysql_info(handle : u64, key : string) dval

:params
handle : the MySQL connection handle
key : `connection`, `error`, `insert_id`, or `affected_rows`

:returns
The value for `key`.

:errors
The function stops with an error for an unknown key. The error lists the valid keys.

:content
`mysql_info()` reads connection state, the latest error text, the last automatic row ID, or the changed-row count.

Use a converter with a fallback because the values have different types.

:example capy render
var database := mysql_connect("localhost", "root", "", "")
var live := bool(mysql_info(database, "connection"), false)
var message := string(mysql_info(database, "error"), "")
var id := u64(mysql_info(database, "insert_id"), 0)
var rows := u64(mysql_info(database, "affected_rows"), 0)
print(live, " ", message, " ", id, " ", rows, "\n")
if database != u64(0) { mysql_disconnect(database) }

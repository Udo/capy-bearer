:title
RENDER

:sig
function RENDER(request : dval)
function RENDER:NAME(request : dval)

:content
`RENDER` defines the HTTP page entrypoint.

The handler has one parameter named `request` with type `dval`. Read request data from the snapshot. Use `print` to write the response.

:example capy render
print(string(request.method, ""), "\n")

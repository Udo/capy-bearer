:sig
function expand_path(path : string, relative_to_path : string = "") string

:params
path : path to expand
relative_to_path : base directory for a relative path

:returns
expanded path

:content
`expand_path()` returns an expanded path string.

Pass a path and an optional base directory. It resolves a relative path against the base directory.

Without a base directory, it uses the current unit directory.

Use the returned path with file APIs.

:example capy render
print(expand_path("sub/page.capy", "/var/www/site"), "\n")

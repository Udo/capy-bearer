:sig
bool password_verify(String password, String encoded)

:params
password : the candidate password bytes
encoded : a self-contained `$bearer$scrypt$...` credential

:returns
`true` only if the password matches a valid bounded encoding

:content
In Capy, `password_verify()` returns `true` only when `password` matches `encoded`. It compares the derived value in constant time.

The API rejects malformed encodings. It also rejects parameters above the Bearer memory and work limits.

Set password length limits and rate limits for public sign-in endpoints.

:example capy render
var encoded := password_hash("correct horse battery staple")
if password_verify("correct horse battery staple", encoded) { print("valid / ") } else { print("invalid / ") }
if password_verify("wrong password", encoded) { print("valid\n") } else { print("invalid\n") }

:example cpp render
String encoded = password_hash("correct horse battery staple");
print(password_verify("correct horse battery staple", encoded) ? "valid" : "invalid", " / ");
print(password_verify("wrong password", encoded) ? "valid" : "invalid", "\n");

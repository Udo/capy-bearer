:sig
s64 strpos(String haystack, String needle, s64 offset = 0)

:params
haystack : Capy string to search
needle : Capy string to find
offset : optional start position. Negative values count from the end.

:returns
zero-based first match position, or `-1` when no match exists

:see
>string

:content
Use `strpos` to find the first `needle` in a Capy string. Pass the string, the text to find, and an optional start position. The function returns a zero-based position or `-1`.

An empty `needle` returns the normalized start position. This differs from PHP `strpos`, which returns `false` when no match exists.

Capy uses `string` values. C++ `.uce` uses `String` and `s64`, as the signature shows.

:example capy render
print(strpos("bearer docs", "docs"), "\n")

:example cpp render
print(strpos("bearer docs", "docs"), "\n");

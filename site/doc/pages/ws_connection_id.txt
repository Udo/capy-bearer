:sig
String ws_connection_id()

:params
return value : connection ID of the current WebSocket client

:see
>websocket

:content
In Capy, `ws_connection_id()` takes no inputs and returns the current client's connection ID as a `string`.

Use the ID with `ws_send_to()` or `ws_close()` to select one client. Outside a WebSocket handler, it returns an empty string.

The empty string is the normal no-connection result. C++ returns the same value as `String`.

:example capy render
var id := ws_connection_id()
if id == "" { id = "(empty outside a WS handler)" }
print(id, "\n")

:example cpp render
String id = ws_connection_id();
print(id == "" ? "(empty outside a WS handler)" : id, "\n");

:title
ws_connection_id

:sig
String ws_connection_id()

:params
return value : connection ID of the current WebSocket client

:see
>websocket
>0_Request

:capy-status cpp-specific

:content
`ws_connection_id()` is a C++ API. It returns the current WebSocket client connection ID. Outside a WebSocket handler, it returns an empty string.

Use the ID with `ws_send_to()` or `ws_close()` to select one client.

Capy does not expose `ws_connection_id`. In a Capy `WS` handler, read `request.websocket.connection_id`.

:example cpp render
String id = ws_connection_id();
print(id == "" ? "(empty outside a WS handler)" : id, "\n");

:sig
u64 file_pwrite(u64 h, u64 offset, String data)

:params
h : writable handle from `file_open()`
offset : absolute byte offset
data : Capy `string` data to write
return value : number of bytes written

:content
In Capy, `file_pwrite()` writes `string` bytes at an absolute offset without changing the handle position.

Use a writable handle, such as one opened with `"r+"`, for an in-place edit. It returns zero for an invalid, closed, or non-writable handle.

:example capy render
var handle := file_open("/tmp/doc-pwrite.txt", "w")
file_write(handle, "hello world")
file_close(handle)
var editor := file_open("/tmp/doc-pwrite.txt", "r+")
file_pwrite(editor, 6, "earth")
file_close(editor)
print(file_get_contents("/tmp/doc-pwrite.txt"), "\n")

:example cpp render
u64 h = file_open("/tmp/doc-pwrite.txt", "w");
file_write(h, "hello world");
file_close(h);
u64 e = file_open("/tmp/doc-pwrite.txt", "r+");
file_pwrite(e, 6, "earth");
file_close(e);
print(file_get_contents("/tmp/doc-pwrite.txt"), "\n");

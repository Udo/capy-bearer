:sig
function component_resolve(name : string) string

:params
name : a component path with an optional named handler

:returns
The resolved component source path.

:content
`component_resolve()` resolves a component name to its source path.

A name without a suffix resolves to its `.capy` file. A named handler does not affect the returned path.

:example capy render
print(component_resolve("/tests/capy-request-context"), "\n")

:see
component
component_exists
component_render

:content
`function COMPONENT(request : dval)` defines the Capy component entrypoint.

Every Capy Bearer handler has exactly one parameter. The parameter name is `request`. Its type is `dval`. The value is a copied request snapshot. Use `COMPONENT:NAME` for a named component.

Read input from the request fields. Use response, session, output, and WebSocket functions for effects. The compiler rejects zero parameters, other parameter types, extra parameters, return types, and handler overloads.

C++ declares `COMPONENT(Request& context)` or `COMPONENT:NAME(Request& context)`. C++ reads live component props from `context.props` and passes the live context to component helpers.

:example capy render
print(string(request.method, ""), "\n")

:example cpp render
print(context.params["REQUEST_METHOD"], "\n");

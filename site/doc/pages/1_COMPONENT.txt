:title
COMPONENT

:sig
function COMPONENT(request : dval)
function COMPONENT:NAME(request : dval)

:content
`COMPONENT` defines a component entrypoint. Use `COMPONENT:NAME` for a named component.

The handler has one parameter named `request` with type `dval`. Read component properties from `request.props`. Use `print` to write component output.

:example capy component
print(string(request.props.name, "guest"))

:sig
String uri_decode(String s)

:params
s : string containing URI encoded data

:returns
a string that contains the decoded version of 's'

:content
`uri_decode(value)` accepts a URI-encoded `string` and returns the decoded `string`.

Use it to read URI data such as a query value. The API has no error return.

C++ uses the signature above. Its `String` input and return value correspond to Capy `string` values.


:example capy render
print(uri_decode("Ada%20Lovelace"), "\n")

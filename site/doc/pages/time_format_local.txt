:sig
String time_format_local(String format = "", u64 timestamp = 0)

:params
format : optional Capy format string
timestamp : optional Unix timestamp. Omit it to use the current time.

:returns
formatted local-time string

:see

>time_format_relative

:content
Use `time_format_local` to format a Unix timestamp in the server local time zone. Pass a format string and, if needed, a timestamp. The function returns a Capy `string`. Omit the timestamp to format the current time.

The formatter supports core Linux `date` format tokens and the relative-time delta tokens.

Supported format sequences:


Padding and case flags may follow `%`:


The `RFC1123` special format applies only to `time_format_utc`. Use that function for RFC 1123 output.

C++ `.uce` uses `String` and `u64`, as the signature shows.

:example capy render
if time_format_local("%Y-%m-%d", 0) != "" { print("formatted\n") } else { print("empty\n") }

:example cpp render
print(time_format_local("%Y-%m-%d", 0) != "" ? "formatted\n" : "empty\n");

:content
`function CLI(request : dval)` defines the Capy local command entrypoint.

Every Capy Bearer handler has exactly one parameter. The parameter name is `request`. Its type is `dval`. The value is a copied request snapshot. Bearer calls this handler through its local CLI socket.

Read input from the request fields. Use response, session, output, and WebSocket functions for effects. The compiler rejects zero parameters, other parameter types, extra parameters, return types, and handler overloads.

C++ declares `CLI(Request& context)`. Its live `context` provides query, POST, body, parameter, header, and response access. C++ can test `context.params["BEARER_CLI"]` and read `context.params["SCRIPT_FILENAME"]`.

:example capy render
print(string(request.method, ""), "\n")

:example cpp render
print(context.params["REQUEST_METHOD"], "\n");

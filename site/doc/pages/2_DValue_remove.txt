:sig
void DValue::remove(String s)

:params
s : child key to erase

:returns
none

:see
0_DValue
2_DValue_clear
2_DValue_has

:content
`dval_remove(value, key)` removes the string key from `value`. It mutates `value` and returns that same identity. All workspace aliases observe the mutation. Assigning the result back remains valid.

The operation makes a scalar map-shaped. A missing key causes no other change. Removing the last child resets the next numeric index to zero.

## C++ API

`DValue::remove()` changes the object in place.

:example capy render
var user := dval_remove(dval({"a": "1", "b": "2"}), "a")
if dval_has(user, "a") { print("has a: yes") } else { print("has a: no") }
if dval_has(user, "b") { print(", has b: yes\n") } else { print(", has b: no\n") }

:example cpp render
DValue u;
u["a"] = "1"; u["b"] = "2";
u.remove("a");
print("has a: ", u.has("a") ? "yes" : "no", ", has b: ", u.has("b") ? "yes" : "no", "\n");

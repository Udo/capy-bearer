:title
Remove a child

:sig
function dval_remove(value : dval, key : string) dval

:params
value : target value
key : child key

:returns
The changed target value.

:content
`dval_remove` removes `key` from `value`. A missing key leaves the value unchanged.

:example capy render
var user := dval({"name": "Ada", "role": "admin"})
user = dval_remove(user, "role")
print(dval_has(user, "role"), "\n")

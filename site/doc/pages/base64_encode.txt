:sig
String base64_encode(String raw)

:params
raw : binary-safe source bytes

:returns
the Base64-encoded text

:content
Capy's `base64_encode(raw)` returns Base64 text as a `string`. Capy strings can contain NUL and other binary bytes.

Pass source bytes, such as `random_bytes()` or a `sha256()` digest. Use the result in a text field, header, cookie, or JSON value. The function does not report errors.

The C++ `String` function has the same input and result.

:example capy render
print(base64_encode("hello"), "\n")

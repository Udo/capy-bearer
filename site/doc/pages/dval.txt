dval(value : bool) dval
dval(value : dval) dval

:params
value : scalar value, map or list literal, or existing `dval`

:returns
new `dval` value

:content
Use `dval()` to build a dynamic value from scalar values or a literal structure.

It converts `string`, integer, float, and `bool` scalars into typed `dval` entries. It keeps existing `dval` input as `dval`.

Use it for request and task payloads, JSON-like in-memory data, and nested maps and lists.

:errors
Compilation fails when `dval()` receives an unsupported input type. The compiler rejects map literals with duplicate keys.

:example capy render
var profile := dval({"name": "Ada", "scores": [1, 2, 3]})
print(profile.name, " ", length(profile.scores), "\n")

:example cpp render
DValue profile;
profile["name"] = "Ada";
profile["scores"].set_array();
profile["scores"].push_back("1");
profile["scores"].push_back("2");
profile["scores"].push_back("3");
print(profile["name"].to_string(), " ", profile["scores"].size(), "\n");

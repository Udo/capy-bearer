:sig
void response_header(string name, string value)

:params
name : response header name
value : response header value

:returns
none

:content
Use `response_header` to set one response header.
Header names must use letters, digits, hyphen, or underscore only.
If `name` fails validation, execution traps.
The runtime removes raw carriage return and newline characters from `value`.
Capy updates the context header map. C++ code uses `context.header[name] = value`.

:example capy render
response_header("X-Demo", "ok")
print("header set\n")

:example cpp render
context.header["X-Demo"] = "ok";
print("header set\n");

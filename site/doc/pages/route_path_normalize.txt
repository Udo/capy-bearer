:content
Use this function only to prepare route text for display or diagnostics.

It removes outer whitespace and leading and trailing `/`. It does not validate the result.

Before you compose a file path, use `route_path_sanitize()` or `ROUTE_PATH`.

:example capy render
print(route_path_normalize("/docs/index/"), "\n")

:example cpp render
print(route_path_normalize("/docs/index/"), "\n");

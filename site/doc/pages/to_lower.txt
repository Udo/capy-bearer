:sig
String to_lower(String s)

:params
s : text to convert
return value : `s` with uppercase characters changed to lowercase

:see
>string

:content
In Capy, call `to_lower(value)` to return a lowercase `string` value.

Use it to normalize ASCII text before comparison. Capy does not convert Unicode case.

C++ uses the legacy `s` parameter in the signature above. C++ also does not provide Unicode case conversion through this function.


:example capy render
print(to_lower("BEARER"), "\n")

:example cpp render
print(to_lower("BEARER"), "\n");

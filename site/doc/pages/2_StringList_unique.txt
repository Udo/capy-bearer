:sig
DValue::unique() (legacy `StringList` page)

:content
`unique(items)` takes a list-shaped `dval` and returns a new list-shaped `dval`. It keeps the first instance of each string and keeps input order.

Capy has no separate `StringList` type. It uses list-shaped DValues. This pure transformation returns a new list.

## C++ API

`DValue::unique()` provides the legacy StringList operation.

:see
0_DValue

:example capy render
var items := split("one,two,one", ",")
print(join(unique(items), ","), "\n")

:title
Test for a container

:sig
function dval_is_array(value : dval) bool

:params
value : value to test

:returns
`true` for a map or list.

:content
`dval_is_array` returns `true` when a value has map shape. It returns `true` for both maps and lists.

:example capy render
print(dval_is_array(dval({"name": "Ada"})), "\n")

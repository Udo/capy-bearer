:sig
bool DValue::is_array() const

:params
return value : true when the dereferenced value is map-shaped

:see
>types
0_DValue
2_DValue_is_list

:content
Use `dval_is_array(value)` in Capy to test whether a DValue is map-shaped. It returns `true` for both maps and lists. It does not require numeric or contiguous keys. Use `dval_is_list()` to test for a list.

C++ `is_array()` tests the dereferenced value's `M` container type.

:example capy render
var user := dval({"name": "Ada"})
if dval_is_array(user) { print("array\n") } else { print("scalar\n") }

:example cpp render
DValue user;
user["name"] = "Ada";
print(user.is_array() ? "array\n" : "scalar\n");

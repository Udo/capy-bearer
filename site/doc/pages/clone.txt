:sig
function clone(value : string) string

:params
value : a source string

:returns
A separate string copy.

:content
`clone()` copies a string.

Most Capy code does not need an explicit copy. Use `clone()` when a fresh string value is required.

:example capy render
var source := "token"
var copy := clone(source)
print(length(source), " ", length(copy), "\n")

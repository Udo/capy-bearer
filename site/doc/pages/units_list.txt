:sig
DValue units_list()

:returns
a `dval` list of known unit paths

:see
>runtime
unit_info
unit_compile
unit_load

:content
Call `units_list()` to inspect the units that the current runtime can load.

The list includes known `.uce` units and units already loaded by the current runtime process.

C++ returns a `DValue` list through the signature above. Use the same normal use case.

:example capy render
var count := 0
for item := units_list() { count = count + 1 }
print("unit list available\n")

:example cpp render
DValue units = units_list();
print("unit list available\n");

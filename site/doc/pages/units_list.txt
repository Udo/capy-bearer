:sig
DValue units_list()

:see
>runtime
unit_info
unit_compile
unit_load

:content
In Capy, call `units_list()` to get a `dval` list of known unit paths.

Use this list to inspect units that the current runtime can load. The list includes known `.uce` units and units already loaded by the current runtime process.

C++ returns a `DValue` list through the signature above. Use the same normal use case.

:example capy cli
var count := 0
for item = units_list() { count = count + 1 }
print("the runtime knows ", count, " compiled units\n")

:example cpp cli
print("the runtime knows ", units_list().size(), " compiled units\n");

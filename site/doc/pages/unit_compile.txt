:sig
bool unit_compile(String path = "")

:params
path : optional unit path. If empty, recompiles the current unit

:returns
`true` if the compiler compiles the unit

:see
>runtime
unit_info
units_list
unit_call

:content
In Capy, call `unit_compile()` for the current unit. Call `unit_compile(path)` for another unit.

The function returns `true` when compilation succeeds. It returns `false` when compilation fails. Use it when an operator must compile a unit explicitly.

Relative paths use the unit path rules. Capy does not return a C++ unit object.

C++ uses the optional `path` value in the signature above. It has the same success result.

:example capy render
if unit_compile("examples/sample_unit.uce") { print("compiled the sample unit\n") } else { print("compile failed\n") }

:example cpp render
print(unit_compile("examples/sample_unit.uce") ? "compiled the sample unit" : "compile failed", "\n");

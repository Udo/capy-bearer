:sig
DValue* DValue::key(String s)
const DValue* DValue::key(String s) const

:params
key or index : required child selector
return value : copied child in Capy, or a child pointer in C++

:see
0_DValue
2_DValue_key
2_DValue_get_by_path

:content
Use `dval_require(value, key)` or `dval_require(value, index)` for a strict Capy read.

Capy traps when the child is missing or the value cannot use the selector. C++ `key` returns a null pointer for a missing key. Check the pointer before use.

The documentation renderer cannot safely run a trap example. The example uses a present key.

:example capy render
var user := dval({"name": "Ada"})
print(dval_require(user, "name"), "\n")

:example cpp render
DValue user;
user["name"] = "Ada";
const DValue* name = user.key("name");
print(name ? name->to_string() : "missing", "\n");

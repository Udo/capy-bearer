:title
Require a child

:sig
function dval_require(value : dval, key : string) dval
function dval_require(value : dval, index : s32) dval

:params
value : source value
key : required child key
index : required list index

:returns
The copied child.

:errors
The program traps when the child is missing or the selector is unusable.

:content
`dval_require` reads a required child. Use it when a missing child is an error.

:example capy render
var user := dval({"name": "Ada"})
print(dval_require(user, "name"), "\n")

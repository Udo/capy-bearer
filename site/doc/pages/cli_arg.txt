:content
`cli_arg()` returns one string value from Capy `cli_input()` data.

Pass the input key and an optional fallback value. It returns the fallback when the key is absent or its resolved value is empty.

Use `cli_arg()` for one simple command value. Use `cli_input()` once when you need several values or DValue types.

In C++ `.uce`, pass `context` as the first argument. Capy gets the request data without that argument.

:example capy render
var name := cli_arg("name", "world")
print("hello ", name, "\n")
:example cpp render
String name = cli_arg(context, "name", "world");
print("hello ", name, "\n");

:sig
String file_get_contents(String file_name)

:params
file_name : path of the file to read
return value : file content as a Capy `string`, or `""` when Capy cannot read it

:content
In Capy, `file_get_contents()` reads a complete file into a `string`. Use it for a small file that you need as one value. An unreadable file returns `""`.

Use `file_open()` and `file_read()` for streamed reads. C++ `.uce` returns the same data as `String`.

:example capy render
file_put_contents("/tmp/doc-get.txt", "hello")
print(file_get_contents("/tmp/doc-get.txt"), "\n")

:example cpp render
file_put_contents("/tmp/doc-get.txt", "hello");
print(file_get_contents("/tmp/doc-get.txt"), "\n");

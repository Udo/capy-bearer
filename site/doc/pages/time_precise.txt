:sig
f64 time_precise()

:params
return value : current Unix timestamp as an `f64`

:see
>time

:content
In Capy, call `time_precise()` to get the current Unix timestamp as an `f64`.

Use this value to measure elapsed time within an operation. C++ uses the same no-input call and return value.


:example capy render
if time_precise() > 0.0 { print("timer\n") } else { print("no timer\n") }

:example cpp render
print(time_precise() > 0 ? "timer\n" : "no timer\n");

:sig
function component_capture(name : string) string
function component_capture(name : string, props : as dval) string

:params
name : a component path, optionally followed by `:HANDLER`
props : optional input, readable inside the component as `request.props`

:returns
Everything the component printed, as a string.

:content
`component_capture()` renders a component into a capture buffer and returns the collected output.

It is the same function as `component()` — that is the shorter name for exactly this behaviour, and most code uses it. `component_capture()` is the explicit spelling, worth preferring in code where the buffering is the point you want a reader to notice, such as next to a call that measures or post-processes the result.

Capture it when the string is the goal:

- wrapping the fragment in surrounding markup
- checking whether the component produced anything before emitting a container
- storing the fragment in a `dval` alongside other values
- rendering the same fragment more than once from one call

Print it directly with `component_render()` when none of those apply — that skips the buffer.

Name resolution, `:HANDLER` suffixes, props scoping, and `ONCE` behaviour are identical to `component()`; that page documents the rules in full.

:errors
An unresolvable component does not raise an error. Bearer sets the response status to `500` and the returned string contains a banner element describing the failure. A returned string is therefore never proof that the component resolved — use `component_exists()` when that distinction matters.

:example capy render
var body := component_capture("/doc/examples/card.capy:CARD", {title: "Ada"})
print(body, "\n")

:example capy render only emit a container when the fragment has content
var body := component_capture("/doc/examples/card.capy:CARD", {title: "Grace"})
if length(body) > 0 {
    print("<aside>", body, "</aside>", "\n")
}

:example capy render reuse one captured fragment twice
var badge := component_capture("/doc/examples/card.capy:CARD", {title: "Beta"})
print("<header>", badge, "</header><footer>", badge, "</footer>", "\n")

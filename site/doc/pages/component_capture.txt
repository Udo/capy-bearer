:sig
function component_capture(name : string) string
function component_capture(name : string, props : as dval) string

:params
name : a component name or named handler
props : optional input for `request.props`

:returns
The captured component output.

:content
`component_capture()` renders a component and returns its output as a string.

Use it when a larger result needs a component fragment. The function uses normal component resolution rules.

:example capy render
var output := component_capture("/tests/capy-request-context.capy", {name: "Capy"})
print(output, "\n")

:sig
String encode_query(StringMap map)

:params
map : `dval` map of URL parameters in Capy
return value : encoded query string

:see
>uri

:content
`encode_query()` converts a Capy `dval` map into an encoded URL query string.

Pass the parameter map. It returns one string that you can append after a URL `?`. Use it to make query parameters from structured values.

C++ `.uce` uses a `StringMap` instead of a Capy `dval` map.

:example capy render
var query := dval({"name": "Ada Lovelace"})
print(encode_query(query), "\n")
:example cpp render
StringMap q;
q["name"] = "Ada Lovelace";
print(encode_query(q), "\n");

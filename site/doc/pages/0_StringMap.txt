:title
String map

:sig
type dval (map of strings)

:content
Use a map-shaped `dval` for string-keyed values. Create one with `dval({"key": "value"})`.

Use `value["key"]` to read a child. Use `dval_has` to test for a key. Use `dval_put` to change a map.

`parse_query` returns a map-shaped `dval`. `encode_query` creates a query string from a map.

Capy has no separate `StringMap` type. Use a map-shaped `dval` instead.

:example capy render
var params := dval({"page": "docs"})
print(params["page"], "\n")

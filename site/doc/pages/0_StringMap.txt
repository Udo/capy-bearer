:content
Use a map-shaped `dval` for string-keyed values in Capy. Create one with `dval({"key": "value"})`.

Use `value["key"]` to read a child. Use `dval_has(value, "key")` to test for a child. Use `dval_put(value, "key", "value")` to return a map with a set child.

`parse_query(query)` returns a map-shaped `dval`. `encode_query(map)` returns a query string. `array_merge(left, right)` returns a merged `dval`.

## Capy Limit

Capy has no `StringMap` type. A Capy map holds `dval` children and uses copied value semantics. It does not expose C++ map references or mutation through `operator[]`.

## C++ API

C++ `StringMap` is `std::map<String, String>`. C++ `map["key"]` creates an empty entry when the key is missing.

:example capy render
var params := dval({"page": "docs"})
print(params["page"], "\n")

:example cpp render
StringMap params;
params["page"] = "docs";
print(params["page"], "\n");

:content
Use this function to test whether route text is safe after normalization.

A safe route has non-empty segments. Each segment can contain ASCII letters, digits, `_`, and `-`. The function rejects `.` and `..` segments.

For handler routes, use `request.route` or `ROUTE_PATH`. These APIs parse and sanitize request input.

:example capy render
if route_path_is_safe("docs/index") { print("safe\n") } else { print("unsafe\n") }

:example cpp render
print(route_path_is_safe("docs/index") ? "safe\n" : "unsafe\n");

:sig
String join(DValue l, String delim = "\n")

:params
l : `dval` list whose values are read as strings
delim : separator string, default newline

:returns
string with all list values separated by `delim`

:see
>string
first
json_consume_space
filter
json_encode
contains
map
:content
`join()` reads every `dval` list value as a string and returns one string. It inserts `delim` between values.

It uses a newline when `delim` is omitted. Use it to make text from a list. In Capy, use `DValue`.


:example capy render
var parts := split("a,b,c", ",")
print(join(parts, "-"), "\n")

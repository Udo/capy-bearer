:sig
String join(DValue l, String delim = "\n")

:params
l : `dval` list whose values are read as strings
delim : separator string, default newline
return value : string with all list values separated by `delim`

:see
>string

:content
`join()` reads every `dval` list value as a string and returns one string. It inserts `delim` between values.

It uses a newline when `delim` is omitted. Use it to make text from a list. In C++ `.uce`, use `DValue`.


:example capy render
var parts := split("a,b,c", ",")
print(join(parts, "-"), "\n")

:example cpp render
DValue parts = split("a,b,c", ",");
print(join(parts, "-"), "\n");

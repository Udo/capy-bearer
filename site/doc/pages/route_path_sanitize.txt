:sig
function route_path_sanitize(path : string, fallback : string = "index") string

:params
path : route text to validate
fallback : route for empty input

:returns
A safe route, or an empty string.

:content
The function normalizes the path. It uses `fallback` for empty input. It returns an empty string for unsafe input.

:example capy render
print(route_path_sanitize("../private"), "\n")

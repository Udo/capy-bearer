:title
Get a named child

:sig
function dval_key(value : dval, key : string) dval

:params
value : source value
key : child key

:returns
The copied child, or `none`.

:content
`dval_key` reads a named child without creating it. It returns `none` for a missing key or a scalar.

:example capy render
var user := dval({"email": "ada@example.test"})
print(dval_key(user, "email"), "\n")

:sig
DValue* DValue::key(String s)
const DValue* DValue::key(String s) const

:params
s : child key to find
return value : pointer to an existing child, or 0

:see
0_DValue
2_DValue_require
2_DValue_get_by_path

:content
Use `dval_key(value, key)` in Capy to get a copied named child. It does not create a child.

Capy returns `none` for a scalar value or a missing key. Use a constructor fallback when you need a scalar fallback.

C++ `key(key)` returns a pointer to an existing child or `0`. Its non-const overload follows internal references.

:example capy render
var user := dval({"email": "ada@example.test"})
print(dval_key(user, "email"), " / ", string(dval_key(user, "phone"), "absent"), "\n")

:example cpp render
DValue user;
user["email"] = "ada@example.test";
const DValue* found = user.key("email");
const DValue* missing = user.key("phone");
print(found ? found->to_string() : "none", " / ", missing ? "present" : "absent", "\n");

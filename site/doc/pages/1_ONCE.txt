ONCE

:content
`function ONCE` defines the Capy request-local hook for one unit.

Use `function ONCE { ... }` for the normal form. You can also declare `function ONCE(request : request) { ... }`. The optional input is an opaque Capy request value.

The hook accepts no other inputs and returns no value. Bearer runs it before the first render or component call for this resolved unit and request. Later component calls to the same unit in that request do not run it again.

Use `ONCE` to prepare request-local derived data that several component calls need. Do not use it for worker-local state. Capy unit hooks do not provide persistent worker-local state.

The compiler rejects other parameter forms, a return type, and handler overloads. A trap in `ONCE` stops that invocation.

## C++ API

C++ declares `ONCE(Request& context)`. C++ can store request-local data in the live context.

Capy does not expose C++ `Request&`, `context.call`, or mutable `DValue` aliases. Use Capy request functions and copied `dval` values. Capy cannot use C++ references or direct C++ object access.

:title
ONCE

ONCE(Request& context)

:see

>1_RENDER

:content
`function ONCE(request : dval)` defines the Capy request-local unit hook.

Every Capy Bearer handler has exactly one parameter. The parameter name is `request`. Its type is `dval`. The value is a copied request snapshot. Bearer runs this hook before the first unit entry or component call.

Read input from the request fields. Use response, session, output, and WebSocket functions for effects. The compiler rejects zero parameters, other parameter types, extra parameters, return types, and handler overloads.

C++ declares `ONCE(Request& context)`. C++ can store request-local data in the live context.

:example capy render
print(string(request.method, ""), "\n")

:example cpp render
print(context.params["REQUEST_METHOD"], "\n");

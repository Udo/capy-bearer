:sig
void mysql_disconnect(MySQL* m)

:params
m : Capy MySQL handle

:see
>mysql

:content
In Capy, pass the opaque `u64` handle from `mysql_connect()`.

This function releases the connection lease. It does not necessarily close a pooled server connection immediately. Do not use the handle after this call.

The C++ API accepts `MySQL*` instead.

:example capy render
var db := mysql_connect("localhost", "root", "", "")
if db != 0u64 { mysql_disconnect(db); print("connection closed\n") }
else { print("(requires a reachable MySQL server)\n") }

:example cpp render
MySQL* db = mysql_connect();
if(db != 0) { mysql_disconnect(db); print("connection closed\n"); }
else print("(requires a reachable MySQL server)\n");

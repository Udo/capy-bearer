:sig
bool contains(String haystack, String needle)

:params
haystack : string to search
needle : substring to find

:returns
`true` when `needle` occurs in `haystack`, otherwise `false`

:see
>string

:content
`contains()` checks whether one Capy string contains another string.

Pass the string to search and the substring to find. It returns `true` for an empty substring.

Use this function for a simple substring check.

:example capy render
if contains("bearer docs", "docs") { print("yes\n") } else { print("no\n") }
:example cpp render
print(contains("bearer docs", "docs") ? "yes\n" : "no\n");

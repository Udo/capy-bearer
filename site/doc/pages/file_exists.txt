:sig
bool file_exists(String path)

:params
path : path to check

:returns
true when a regular file exists, otherwise false

:content
`file_exists` tests whether a regular file exists at `path`. Use it before a file read or after a file write. It returns false for a directory. Use `file_stat()` and its `is_dir` field to test a directory.

:example capy render
file_put_contents("/tmp/doc-exists.txt", "x")
var first_status := "missing"
if file_exists("/tmp/doc-exists.txt") { first_status = "exists" }
var second_status := "missing"
if file_exists("/tmp/doc-not-here-xyz.txt") { second_status = "exists" }
print(first_status, " / ", second_status, "\n")

:example cpp render
file_put_contents("/tmp/doc-exists.txt", "x");
print(file_exists("/tmp/doc-exists.txt") ? "exists" : "missing", " / ");
print(file_exists("/tmp/doc-not-here-xyz.txt") ? "exists" : "missing", "\n");


:sig
bool job_cancel(u64 job_id)

:params
job : the Capy `dval` job ID. Capy uses a `u64` ID.

:returns
`true` when Bearer cancels an active job. Otherwise, `false`.

:content
`job_cancel()` requests cancellation of a job.

Use it to stop a job that no longer has a useful result. Its status then reports `cancelled`.

In Capy, pass the job ID as `dval`. In Capy, pass the `u64` job ID shown above.

:see

:example capy render
var spec := dval({"cmd": "sleep 5", "timeout_ms": 10000})
var job := shell_spawn(spec)
var result := "could not cancel"
if job_cancel(job) { result = "job cancelled" }
print(result, "\n")

:sig
String dirname(String fn)

:params
fn : path to inspect

:returns
directory part of the path

:content
`dirname()` returns the directory part of a Capy path string.

Pass a path with a final component. The returned string omits that final component. Use it to get a containing directory.

The Capy call has the same arguments.

:example capy render
print(dirname("/var/www/site/index.capy"), "\n")

:sig
String nibble(String& haystack, String delim)

:params
haystack : the string to change
delim : the delimiter

:returns
the text before the first `delim`

:see
>string
map
print
json_encode
strpos
json_consume_space
str_ends_with
:capy-status unsupported

:content
Capy does not support this API. Capy passes strings by value and cannot change the caller's string through a reference parameter.

C++ returns the text before the first `delim`. It removes that text and the delimiter from `haystack`.

If `delim` does not occur, it returns all of `haystack` and clears `haystack`.


:example cpp render
String path = "docs/index";
print(nibble(path, "/"), " ", path, "\n");

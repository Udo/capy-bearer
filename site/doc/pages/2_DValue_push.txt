:title
Append a child

:sig
function dval_push(value : dval, child : as dval) dval

:params
value : target value
child : value to append

:returns
The changed target value.

:content
`dval_push` appends `child` with the next numeric key. It changes and returns `value`.

:example capy render
var list := dval([])
list = dval_push(list, "Ada")
print(list[0], "\n")

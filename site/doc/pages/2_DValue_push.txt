:sig
void DValue::push(const DValue& child)

:params
child : value to append/copy

:returns
none

:see
0_DValue
2_DValue_pop
2_DValue_set_array

:content
`dval_push(value, child)` appends `child` at the next numeric key. It mutates `value` and returns that same identity. All workspace aliases observe the mutation. Assigning the result back remains valid.

An empty value becomes a list. A contiguous list adds the child after its last item. A non-list map uses its next unused numeric key and remains a map.

## C++ API

`DValue::push()` changes the object in place.

:example capy render
var list := dval_push(dval_push(dval([]), "x"), "y")
if dval_has(list, "1") { print("count: 2\n") } else { print("count: 1\n") }

:example cpp render
DValue list;
list.set_array();
DValue a; a.set("x"); list.push(a);
DValue b; b.set("y"); list.push(b);
print("count: ", list.keys().size(), "\n");

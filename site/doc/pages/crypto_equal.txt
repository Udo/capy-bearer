:sig
bool crypto_equal(String a, String b)

:params
a : first byte string
b : second byte string

:returns
`true` when both byte strings are equal

:content
`crypto_equal()` compares two Capy byte strings in constant time.

Pass the expected secret and the submitted secret. It returns `true` when their bytes are equal. Use it for HMACs, tokens, and password hashes.

Do not use `==` to compare secrets. Its time can reveal how many bytes matched.

:example capy render
var expected := hmac_sha256_hex("key", "payload")
if crypto_equal(expected, hmac_sha256_hex("key", "payload")) { print("valid / ") } else { print("invalid / ") }
if crypto_equal(expected, "tampered") { print("valid\n") } else { print("invalid\n") }
:example cpp render
String expected = hmac_sha256_hex("key", "payload");
print(crypto_equal(expected, hmac_sha256_hex("key", "payload")) ? "valid" : "invalid", " / ");
print(crypto_equal(expected, "tampered") ? "valid" : "invalid", "\n");

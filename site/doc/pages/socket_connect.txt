:sig
u64 socket_connect(String host, u16 port)

:params
host : IPv4 address in dotted-quad form, such as `127.0.0.1`
port : port number from 0 through 65535

:returns
socket handle, or zero when the connection fails

:see
>socket

:content
Capy `socket_connect(host, port)` opens a socket to an IPv4 address and port. Give it a dotted-quad address and a port from 0 through 65535.

It returns a socket handle. It returns zero when it cannot connect. Use a nonzero handle with `socket_read()`, `socket_write()`, and `socket_close()`.

Capy does not resolve host names. Use an IPv4 address. The C++ API uses `u16` for `port`. Capy accepts `s32` and rejects values outside the valid port range.

:example capy render
var fd := socket_connect("127.0.0.1", 80)
if fd != 0 { print("connected to the local server\n") } else { print("connect failed\n") }
socket_close(fd)

:example cpp render
u64 fd = socket_connect("127.0.0.1", 80);
print(fd != 0 ? "connected to the local server" : "connect failed", "\n");
socket_close(fd);

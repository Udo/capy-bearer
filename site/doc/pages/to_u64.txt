
:sig
u64 to_u64(String s, u64 fallback = 0)

:params
s : C++ text to parse
fallback : value for empty or invalid text

:returns
parsed C++ `u64` or `fallback`

:see
>types
2_DValue_to_u64

:capy-status cpp-specific

:content
`to_u64()` is a C++ API. It accepts a leading `+`. Negative, overflowing, empty, or partial text returns `fallback`.

Capy does not expose `to_u64`. Use `u64(value, fallback)`.

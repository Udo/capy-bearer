:sig
String gz_compress(String src)

:params
src : uncompressed input bytes

:returns
gzip-format compressed bytes

:see
>sys
gz_uncompress
zip_create
zip_read

:content
`gz_compress()` returns gzip-compressed bytes for a string. The returned string is binary data.

Pass the result to `gz_uncompress()`, write it to a file, or send it with the correct HTTP encoding. Use it to create gzip payloads.

The result uses the standard gzip format, including CRC32 and uncompressed-size fields.

:example capy render
var original := "hello hello hello hello hello"
var packed := gz_compress(original)
print("restores to: ", gz_uncompress(packed), "\n")

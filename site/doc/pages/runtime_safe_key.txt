:sig
String runtime_safe_key(String key, String label = "runtime key")

:params
key : caller-provided runtime key
label : error label for an empty key
return value : stable SHA-1 key

:see
>sys
>gen_sha1

:content
In Capy, use this function to make a stable runtime key from a non-empty name.

The function trims `key` and returns its SHA-1 value. Use the result for runtime task names or file names. An empty key is an error. `label` identifies that key in the error message.

:example capy render
print(runtime_safe_key("  My Task Name  "), "\n")

:example cpp render
print(runtime_safe_key("  My Task Name  "), "\n");

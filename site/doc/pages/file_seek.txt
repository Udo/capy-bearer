:sig
s64 file_seek(u64 h, s64 offset, s64 whence)

:params
h : handle from `file_open()`
offset : byte offset relative to `whence`
whence : 0 for start, 1 for the current position, or 2 for end

:returns
new absolute byte offset, or -1 on error

:content
`file_seek` sets the read and write position for a handle. Use it before `file_read()` or `file_write()` for random access. It returns -1 when it cannot set the position. `file_tell()` returns the current position.

:example capy render
var writer := file_open("/tmp/doc-seek.txt", "w")
file_write(writer, "hello world")
file_close(writer)
var reader := file_open("/tmp/doc-seek.txt", "r")
file_seek(reader, 6, 0)
print(file_read(reader, 5), "\n")
file_close(reader)

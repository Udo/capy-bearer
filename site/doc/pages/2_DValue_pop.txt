:sig
DValue DValue::pop()

:params
return value : removed child as a `dval`, or an empty `dval` when no child exists

:see
0_DValue
2_DValue_push

:content
`dval_pop(value)` takes a `dval` and returns the updated value after it removes one child. Assign the result back to retain the change. An empty value becomes an empty map-shaped value.

For a list, it removes the last numeric child and resets the next list index. For a map, it removes the last key in reverse map order. Capy does not return the removed child.

## C++ API

`DValue::pop()` returns the removed child. It uses reverse `std::map` key order for maps.


:example capy render
var list := dval_push(dval_push(dval([]), "first"), "last")
var popped := list[1]
list = dval_pop(list)
if dval_has(list, "0") { print("popped ", popped, ", remaining 1\n") } else { print("popped ", popped, ", remaining 0\n") }

:example cpp render
DValue list;
list.set_array();
DValue a; a.set("first"); list.push(a);
DValue b; b.set("last"); list.push(b);
DValue popped = list.pop();
print("popped ", popped.to_string(), ", remaining ", list.keys().size(), "\n");

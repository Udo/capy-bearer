:title
Remove the final child

:sig
function dval_pop(value : dval) dval

:params
value : target value

:returns
The changed target value.

:content
`dval_pop` removes the final child and returns `value`. It does not return the removed child.

:example capy render
var list := dval(["first", "last"])
list = dval_pop(list)
print(list[0], "\n")

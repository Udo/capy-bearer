:sig
String backtrace_get_frames(void* const* frames, size_t size, u32 skip_frames = 0)

:params
frames : frame pointer array returned by native backtrace collection
size : number of frames in the array
skip_frames : number of newest frames to omit
return value : formatted backtrace string

:see
>runtime
backtrace_capture
signal_name

:content
Capy's `backtrace_get_frames()` returns a source-mapped guest backtrace as a `string`. Use it for Capy diagnostic output.

The zero-argument form uses 32 frames and skips none. The other forms accept a maximum frame count and an optional skip count. The function returns an empty string when no frames are available. It does not report errors.

Capy does not accept native frame pointers. The C++ `backtrace_get_frames` function formats a `void*` frame array. Use `backtrace_capture()` for normal C++ page code.

:example capy cli
var frames := backtrace_get_frames()
if frames == "" { print("(no frames available in the wasm sandbox)\n") }
else { print("frames captured\n") }
:example cpp cli
print(backtrace_get_frames(0, 0) == "" ? "(no frames available in the wasm sandbox)" : "frames captured", "\n");

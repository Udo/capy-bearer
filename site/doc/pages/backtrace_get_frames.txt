:sig
function backtrace_get_frames(max_frames : s32 = 32, skip_frames : s32 = 0) string

:params
max_frames : maximum number of frames
skip_frames : number of newest frames to omit

:returns
a backtrace string

:content
`backtrace_get_frames` gets source-mapped frames for the current Capy call stack.

Set `max_frames` to limit the result. Set `skip_frames` to omit the newest frames.

:example capy cli
print(backtrace_get_frames(4, 0), "\n")

:see
backtrace_capture

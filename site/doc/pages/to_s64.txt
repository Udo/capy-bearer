:sig
s64 to_s64(String s, s64 fallback = 0)

:params
s : text to parse
fallback : value returned for empty or invalid integer text
return value : parsed `s64`, or `fallback`

:see
>types
to_u64
to_f64
to_bool
int_val

:content
In Capy, call `to_s64(raw[, fallback])` to convert text to an `s64` value.

Invalid text returns `fallback`. Use this function for signed numeric input.

C++ uses the legacy `s` parameter and default shown above. It parses a base-10 integer from complete trimmed text. Empty or partial text such as `"-12px"` returns `fallback`.

:example capy render
print(to_s64("-7"), "\n")

:example cpp render
print(to_s64("-7"), "\n");

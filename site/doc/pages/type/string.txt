:title
String

:sig
type string

:content
`string` stores text or raw bytes in Capy.

Use string literals, variables, parameters, and return values directly. Use `length`, `find`, `contains`, `replace`, `lower`, `upper`, and `substr` for common text work.

Use `split_utf8` when you must split UTF-8 text by characters.

:example capy render
var name := "Ada"
print(upper(name), "\n")

:sig
f64 draw_float(f64 from, f64 to, f64 decimal_precision = 0.000000000001)

:params
from : first range value
to : second range value
decimal_precision : output precision

:returns
`f64` noise value between `from` and `to`

:see
>noise
draw_int
gen_noise01
gen_noise32

gen_int
:content
`draw_float()` returns a Capy `f64` noise value between two values.

Pass the range values and optional precision. Bearer uses the request random seed and advances its random index after each call.

Use it when one request needs repeatable noise values from its random sequence.

The Capy call has the same arguments.

:example capy render
if draw_float(1.0, 0.0, 1.0) >= 0.0 { print("float\n") } else { print("bad\n") }

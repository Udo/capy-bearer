:sig
DValue task_cancel(String id)

:params
id : opaque ID returned by `task`
return value : current task status after the cancellation request

:see
>task
task
task_status
task_await

:content
Use `task_cancel` to request cancellation of a Capy task. Pass the task ID. The function returns the current status after it processes the request.

A queued task becomes `canceled`. A running task can finish before cancellation takes effect. In that case, its completed status remains valid. Check the returned status because cancellation can race with task completion.

Capy task IDs are `string` values, and task status is a `dval` value. C++ `.uce` uses `String` and `DValue`, as the signature shows.

:example capy render
var id := task("/doc/examples/task_worker.capy:STORE", dval({"message": "cancel"}))
var status := task_cancel(id)
var result := "missing"
if dval_to_string(status["id"]) == id { result = "requested" }
print(result, "\n")

:example cpp render
DValue props; props["message"] = "cancel";
String id = task("/doc/examples/task_worker.capy:STORE", props);
DValue status = task_cancel(id);
print(status["id"].to_string() == id ? "requested\n" : "missing\n");

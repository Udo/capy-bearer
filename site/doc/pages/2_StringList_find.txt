:sig
DValue::find(String predicate, String fallback = "") (legacy `StringList` page)

:content
`string_list_find(items, predicate, fallback)` takes a list-shaped `dval`, a string predicate, and a fallback string. It returns the first matching string. It returns the fallback when no item matches.

Capy has no separate `StringList` type. It uses copied `dval` values.

## C++ API

`DValue::find()` provides the legacy StringList operation.

:see
0_DValue

:example capy render
var items := split("one,two", ",")
print(string_list_find(items, function(value : string) bool { return value == "two" }, "missing"), "\n")
:example cpp render
StringList items = split("one,two", ",");
print(items.find([](String value) { return value == "two"; }, "missing"), "\n");

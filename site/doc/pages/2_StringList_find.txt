:sig
DValue::find(String predicate, String fallback = "") (legacy `StringList` page)

:content
Removed as a separate StringList API. List-shaped `DValue::find()` returns the first matching string or the fallback.

:see
0_DValue

:example capy render
var items := split("one,two", ",")
print(string_list_find(items, function(value : string) bool { return value == "two" }, "missing"), "\n")
:example cpp render
StringList items = split("one,two", ",");
print(items.find([](String value) { return value == "two"; }, "missing"), "\n");

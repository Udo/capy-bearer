:sig
bool str_ends_with(String haystack, String needle)

:params
haystack : Capy string to inspect
needle : suffix to compare

:returns
`true` when the string ends with the suffix. Otherwise, `false`.

:see
>string

:content
Use `str_ends_with` to test whether a Capy string ends with a suffix. Pass the string and the suffix. The function returns a Boolean value.

Capy uses `string` values. C++ `.uce` uses `String`, as the signature shows.

:example capy render
if str_ends_with("index.uce", ".uce") { print("yes\n") } else { print("no\n") }

:example cpp render
print(str_ends_with("index.uce", ".uce") ? "yes\n" : "no\n");

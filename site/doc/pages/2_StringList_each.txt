:sig
DValue::each(String callback) (legacy `StringList` page)

:content
`each(items, callback)` takes a list-shaped `dval` and a callback that takes one string. It calls the callback once for each item in numeric list order. It returns no value.

Use a list from `split` or `dval([...])`. Capy has no separate `StringList` type. It uses list-shaped DValues. Callback values are copied strings.

## C++ API

`DValue::each()` provides the legacy StringList operation.

:see
0_DValue
2_DValue_each

:example capy render
var items := split("one,two", ",")
each(items, function(value : string) string { print(value); return "" })
print("\n")
:example cpp render
StringList items = split("one,two", ",");
items.each([](String value) { print(value); });
print("\n");

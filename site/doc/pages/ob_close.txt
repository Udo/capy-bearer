:sig
void ob_close()

:returns
no value

:content
`ob_close()` discards the current output buffer and returns to the previous buffer.

Use this when you do not need captured output.

:example capy render
ob_start()
print("this output is discarded")
ob_close()
print("the buffered text never reached the response\n")

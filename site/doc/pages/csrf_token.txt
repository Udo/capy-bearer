:sig
String csrf_token(String session_name = "bearer-session", String token_name = "csrf_token")

:params
session_name : session and cookie name
token_name : token namespace in the session

:returns
printable CSRF token for the active session

:content
`csrf_token()` returns a stable Capy CSRF token for one session and token namespace.

Pass the session name and token namespace. It starts the named session when necessary. Use different token namespaces when forms need separate tokens.

Use the returned value in a hidden form field. Call `csrf_valid()` before you apply a browser-submitted change.

The Capy call has the same arguments.

:example capy render
var token := csrf_token("bearer-doc-session")
if length(token) > 0 { print("token ready\n") }
else { print("token missing\n") }

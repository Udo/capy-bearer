:sig
function time_parse(value : string) u64

:params
value : date or time text

:returns
parsed Unix timestamp, or zero when parsing fails

:see
>time
time_format_utc
time_format_relative
time_format_local
time
time_precise
usleep

:content
`time_parse` converts date or time text to a Unix timestamp.

:example capy render
print(time_parse("1970-01-01 00:00:05 UTC"), "\n")

:sig
function route_from_raw_path(raw_path : string, default_path : string = "index") dval

:params
raw_path : route text to validate
default_path : route for empty input

:returns
Route data with `path`, `page`, `raw_path`, and `valid`.

:content
Use `path` only below an application-controlled route root. It is empty when the route is unsafe.

:example capy render
var route := route_from_raw_path("docs/api")
print(string(route.page), "\n")

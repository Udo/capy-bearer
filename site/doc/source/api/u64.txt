:sig
function u64(value : dval, fallback : u64 = 0) u64
function u64(value : string, fallback : u64 = 0) u64

:params
value : value to convert
fallback : value to return if conversion fails

:returns
converted `u64`, or `fallback`

:content
`u64` converts a `dval` or `string` to `u64`.

:example capy render
print(u64("42"), "\n")

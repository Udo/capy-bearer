:sig
function file_put_contents(path : string, content : string) bool

:params
path : path of the file to write
content : text that replaces the file content

:returns
`true` when Capy writes the file. Otherwise, it returns `false`.

:content
`file_put_contents` writes a complete string to a file. It creates or replaces a small file.

:example capy render
file_put_contents("/tmp/doc-put.txt", "first")
file_put_contents("/tmp/doc-put.txt", "second")
print(file_get_contents("/tmp/doc-put.txt"), "\n")

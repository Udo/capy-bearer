:sig
function hmac_sha256(key : string, value : string) string

:params
key : secret key bytes
value : message bytes

:returns
A raw 32-byte HMAC-SHA256 value.

:content
`hmac_sha256()` returns a raw binary HMAC-SHA256 value. Use `hmac_sha256_hex()` when you need hexadecimal text.

:example capy render
print(length(hmac_sha256("key", "message")), "\n")

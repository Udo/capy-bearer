:sig
function mysql_query(handle : u64, query : string) dval
function mysql_query(handle : u64, query : string, params : dval) dval

:params
handle : the MySQL connection handle
query : the SQL query text
params : the named parameter values

:returns
the query result rows

:content
`mysql_query()` runs a query and returns its rows as a `dval`.

Use named `:name` placeholders with a `dval` map. The API rejects positional `?` placeholders. Add `!` to a placeholder only for an unquoted non-negative integer.

:example capy render
var database := mysql_connect("localhost", "root", "", "")
if bool(mysql_info(database, "connection")) { var rows := mysql_query(database, "select :name as name", dval({"name": "Ada"})); print(rows[0]["name"], "\n") }
if database != u64(0) { mysql_disconnect(database) }

:see
mysql_connect
mysql_info

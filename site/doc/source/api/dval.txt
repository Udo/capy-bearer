:params
value : a scalar, literal structure, or `dval`

:returns
A `dval` value.

:content
`dval()` converts a scalar or literal structure to a dynamic value.

Use it for request payloads and nested map or list data. Existing `dval` input stays a `dval` value.

:example capy render
var profile := dval({name: "Ada", scores: [1, 2, 3]})
print(string(profile.name), " ", length(profile.scores), "\n")

:sig
function regex_split(pattern : string, subject : string, flags : string = "") dval

:params
pattern : regular expression separator
subject : text to split
flags : regular expression flags

:returns
A list of text parts.

:content
`regex_split()` removes separators and keeps empty parts.

:example capy render
var parts := regex_split(",", "a,,b")
print(parts[1], "\n")

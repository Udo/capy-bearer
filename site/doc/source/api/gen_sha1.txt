:sig
function gen_sha1(value : string, as_binary : bool = false) string

:params
value : bytes to hash
as_binary : `false` for hexadecimal text, `true` for raw digest bytes

:returns
A SHA-1 digest string.

:content
`gen_sha1()` returns the SHA-1 digest of a string.

It returns hexadecimal text by default. Set `as_binary` to `true` for raw digest bytes.

Use it only for SHA-1 compatibility.

:example capy render
var digest := gen_sha1("abc")
print(digest, "\n")

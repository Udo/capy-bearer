:sig
function sqlite_query(handle : u64, query : string) dval
function sqlite_query(handle : u64, query : string, params : dval) dval

:returns
Query result as `dval`.

:content
Use `sqlite_query` to run one SQL statement. Use `:name` placeholders with a parameter map.

:example capy render
var db := sqlite_connect(":memory:")
var rows := sqlite_query(db, "select :name as name", dval({"name": "Ada"}))
print(rows[0]["name"], "\n")
sqlite_disconnect(db)

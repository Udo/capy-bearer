function max(a : u32, b : u32) u32
function max(a : u64, b : u64) u64

:params
a : the first value
b : the second value

:returns
A value with the same type as the inputs

:content
`max()` returns the larger of `a` and `b`.

The compiler emits a direct lib call.

:example capy render
var value := max(3.0, 2.0)
print(value, "\n")

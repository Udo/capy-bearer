:sig
function gen_noise32(index : u64, seed : u64 = 0) u64

:params
index : deterministic input position
seed : deterministic input seed

:returns
A deterministic `u64` value.

:content
`gen_noise32()` returns deterministic integer noise for an index and seed.

Use the same inputs to reproduce a value.

:example capy render
var value := gen_noise32(u64(1), u64(2))
print(value, "\n")

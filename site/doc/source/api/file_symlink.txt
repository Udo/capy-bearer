:sig
function file_symlink(target : string, linkpath : string) bool

:params
target : path for the symbolic link
linkpath : path of the new symbolic link

:returns
`true` if Capy creates the link. Otherwise, `false`.

:content
`file_symlink` creates a symbolic link at `linkpath` that points to `target`.

:example capy render
file_put_contents("/tmp/doc-symlink-target.txt", "data")
file_unlink("/tmp/doc-symlink-link.txt")
if file_symlink("/tmp/doc-symlink-target.txt", "/tmp/doc-symlink-link.txt") {
    print(file_get_contents("/tmp/doc-symlink-link.txt"), "\n")
}

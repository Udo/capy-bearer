:sig
function brb_encode(value : dval) string

:params
value : value to encode

:returns
BRRB data as a string

:content
`brb_encode` encodes a `dval` value as BRRB data.

Use `brb_decode` to restore the value.

:example capy render
var packed := brb_encode(dval({"name": "Ada"}))
print(brb_decode(packed)["name"], "\n")

:see
brb_decode
json_encode

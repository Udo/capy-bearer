function bit_count_lz(value : u64) s64

:params
value : the integer value

:returns
An `s64` count.

:content
`bit_count_lz()` counts leading zero bits in the width of `value`. An `u8` value uses eight bits, not its container width.

The compiler emits a direct lib call.

:example capy render
var value := bit_count_lz(u8(1))
print(value, "\n")

:sig
function gen_noise01(index : u64, seed : u64 = 0) f64

:params
index : deterministic input position
seed : deterministic input seed

:returns
A deterministic `f64` value from `0` to `1`.

:content
`gen_noise01()` returns normalized noise for an index and seed.

Use the same inputs to reproduce a value.

:example capy render
var value := gen_noise01(u64(1), u64(2))
print(value, "\n")

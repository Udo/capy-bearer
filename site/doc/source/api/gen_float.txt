:sig
function gen_float(from : f64, to : f64, index : u64, seed : u64 = 0, precision : f64 = 0.000000000001) f64

:params
from : first range value
to : second range value
index : deterministic input position
seed : deterministic input seed
precision : output precision

:returns
A deterministic `f64` value.

:content
`gen_float()` returns a deterministic value for the range values, index, seed, and precision.

Use the same inputs to reproduce a value.

:example capy render
var value := gen_float(0.0, 1.0, u64(1))
print(value, "\n")

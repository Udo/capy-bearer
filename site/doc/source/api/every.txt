:title
Test every string

:sig
function every(items : dval, predicate : function(value : string) bool) bool

:returns
This function returns `true` when every item matches. It returns `true` for an empty list.

:content
`every` tests each string in a list-shaped `dval` with `predicate`.

This function does not change `items`.

:example capy render
var items := split("one,two", ",")
print(every(items, function(value : string) bool { return value != "" }), "\n")

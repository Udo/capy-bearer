:sig
function memcache_delete(connection : u64, key : string) bool

:params
connection : the connection handle
key : the entry key

:returns
`true` when the server deletes the entry

:content
`memcache_delete()` deletes the entry for `key`.

It returns `true` only when the server returns `DELETED`.

:example capy render
var connection := memcache_connect()
if connection != u64(0) { print(memcache_delete(connection, "doc-key"), "\n") }

:see
memcache_connect

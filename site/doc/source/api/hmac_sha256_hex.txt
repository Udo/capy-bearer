:sig
function hmac_sha256_hex(key : string, value : string) string

:params
key : secret key bytes
value : message bytes

:returns
A 64-character lowercase hexadecimal HMAC-SHA256 value.

:content
`hmac_sha256_hex()` returns an HMAC-SHA256 value as hexadecimal text. Use `crypto_equal()` to compare received signatures.

:example capy render
print(hmac_sha256_hex("key", "message"), "\n")

:see
hmac_sha256
sha256_hex
crypto_equal

:sig
function parse_query(query : string) dval

:params
query : the URL query text

:returns
the decoded parameters

:content
`parse_query()` decodes URL query text into a map-shaped `dval`.

An ampersand separates pairs. The first equals sign separates a key and value. A key without an equals sign has an empty value. The last repeated key wins.

:example capy render
var values := parse_query("name=Ada&role=admin")
print(values["name"], "\n")

:see
parse_uri

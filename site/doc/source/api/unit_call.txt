:sig
function unit_call(file_name : string, function_name : string) dval
function unit_call(file_name : string, function_name : string, props : as dval) dval

:params
file_name : unit path
function_name : exported function name
props : function input

:returns
exported function result

:content
`unit_call` calls an exported function in a unit. The two-argument form sends an empty map as the function input.

:example capy render
var result := unit_call("/tests/capy-module-target.capy", "echo", "hello")
print(result, "\n")

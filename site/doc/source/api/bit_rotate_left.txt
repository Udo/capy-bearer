function bit_rotate_left(value : u8, count : u8) u8
function bit_rotate_left(value : u16, count : u16) u16
function bit_rotate_left(value : u32, count : u32) u32
function bit_rotate_left(value : u64, count : u64) u64

:params
value : the integer value
count : the shift or rotation count. It has the same width as `value`.

:returns
An integer with the same type as `value`.

:content
`bit_rotate_left()` rotates bits left by `count` positions.

The compiler emits a direct lib call.

:example capy render
var value := bit_rotate_left(u8(1), u8(2))
print(value, "\n")

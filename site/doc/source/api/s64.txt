:sig
function s64(value : dval, fallback : s64 = 0) s64
function s64(value : string, fallback : s64 = 0) s64

:params
value : value to convert
fallback : value for a failed conversion

:returns
A signed 64-bit integer, or `fallback`.

:content
`s64()` converts supported scalar values and integer text. It returns `fallback` when conversion fails.

:example capy render
print(s64("64", -1), "\n")

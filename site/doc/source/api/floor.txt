:sig
function floor(value : f32) f32
function floor(value : f64) f64

:params
value : the input value

:returns
An `f32` or `f64` value.

:content
`floor()` returns the result for `value`.

The compiler emits a direct lib call.

:example capy render
var value := floor(2.5)
print(value, "\n")

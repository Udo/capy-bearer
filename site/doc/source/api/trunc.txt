:sig
function trunc(value : f32) f32
function trunc(value : f64) f64

:params
value : the input value

:returns
An `f32` or `f64` value.

:content
`trunc()` returns the result for `value`.

The compiler emits a direct lib call.

:example capy render
var value := trunc(2.5)
print(value, "\n")

math

:sig
function gz_compress(source : string) string

:params
source : uncompressed bytes

:returns
Gzip-compressed bytes as a string.

:content
`gz_compress()` compresses a string with gzip.

The result contains binary data. Pass it to `gz_uncompress()` to restore the source.

:example capy render
var source := "archive data"
var packed := gz_compress(source)
print(gz_uncompress(packed), "\n")

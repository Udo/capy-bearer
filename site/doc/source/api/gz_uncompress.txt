:sig
function gz_uncompress(source : string) string

:params
source : gzip-compressed bytes

:returns
Uncompressed bytes as a string.

:content
`gz_uncompress()` uncompresses gzip data from a string.

Use it with data from `gz_compress()`.

:example capy render
var packed := gz_compress("archive data")
var source := gz_uncompress(packed)
print(source, "\n")

:see
gz_compress
zip_read
zip_extract

:sig
function gen_int(from : u64, to : u64, index : u64, seed : u64 = 0) u64

:params
from : first range value
to : second range value
index : deterministic input position
seed : deterministic input seed

:returns
A deterministic `u64` value.

:content
`gen_int()` returns a deterministic value for the range values, index, and seed.

Use the same inputs to reproduce a value.

:example capy render
var value := gen_int(u64(1), u64(10), u64(1))
print(value, "\n")

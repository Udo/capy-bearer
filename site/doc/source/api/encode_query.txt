:sig
function encode_query(map : dval) string

:params
map : map-shaped `dval` of URL parameters

:returns
URL query string

:content
`encode_query()` converts a map-shaped `dval` to a URL query string.

Pass the returned string after `?` in a URL.

:example capy render
var query := dval({"name": "Ada"})
print(encode_query(query), "\n")

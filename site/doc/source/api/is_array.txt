:title
Test for a container

:sig
function is_array(value : dval) bool

:params
value : value to test

:returns
`true` for a map or list.

:content
`is_array(value)` returns `true` when a value is a map or list.

:example capy render
print(is_array(dval({"name": "Ada"})), "\n")

:see-group
dval-access

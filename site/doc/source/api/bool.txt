:sig
function bool(value : dval, fallback : bool = false) bool

:params
value : value to convert
fallback : value to return when conversion fails

:returns
a Boolean value

:content
`bool` converts a `dval` to a Boolean value. It accepts Boolean words in a dynamic value and returns `fallback` when conversion fails.

Wrap a string in `dval` before conversion.

:example capy render
print(bool(dval("YES")), "\n")
print(bool(dval("unknown"), true), "\n")

:see
string

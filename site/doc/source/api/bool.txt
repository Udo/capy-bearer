:sig
function bool(value : dval, fallback : bool = false) bool
function bool(value : string, fallback : bool = false) bool

:params
value : value to convert
fallback : value to return when conversion fails

:returns
a Boolean value

:content
`bool` converts a `dval` or string to a Boolean value.

For strings, it ignores outer whitespace and accepts case-insensitive Boolean text. It returns `fallback` when conversion fails.

:example capy render
print(bool("YES"), "\n")
print(bool("unknown", true), "\n")

:see
string

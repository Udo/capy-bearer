:sig
function ceil(value : f32) f32
function ceil(value : f64) f64

:params
value : the input value

:returns
An `f32` or `f64` value.

:content
`ceil()` returns the result for `value`.

The compiler emits a direct lib call.

:example capy render
var value := ceil(2.5)
print(value, "\n")

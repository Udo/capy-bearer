:sig
function first() string
function first(one : string) string
function first(one : string, two : string) string
function first(one : string, two : string, three : string) string
function first(one : string, two : string, three : string, four : string) string

:params
one : first value
two : second value
three : third value
four : fourth value

:returns
The first nonblank value. Returns `""` if no value is nonblank.

:content
`first` checks values in order. It ignores values that contain only whitespace.

:example capy render
print(first("", "  ", "fallback", "other"), "\n")

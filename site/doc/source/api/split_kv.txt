:sig
function split_kv(value : string, separator : string = "=", trim_whitespace : bool = true, uppercase_keys : bool = false) dval

:returns
Map-shaped `dval`.

:content
Use `split_kv` to parse lines that contain key and value pairs.

:example capy render
var values := split_kv("name=Ada")
print(values["name"], "\n")

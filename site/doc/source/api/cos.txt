:sig
function cos(value : f32) f32
function cos(value : f64) f64

:params
value : the input value

:returns
An `f32` or `f64` value.

:content
`cos()` returns the host math result for `value`.

This function uses a host call.

:example capy render
var value := cos(2.0)
print(value, "\n")

math

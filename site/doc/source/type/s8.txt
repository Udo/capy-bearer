:sig
function s8(value : as string, opt : dval = {}) s8

:params
value : scalar value or text to convert
opt : options map with `fallback` and `base`

:returns
A signed 8-bit integer, or `opt.fallback`.

:content
`s8()` parses text in the range -128 through 127. It uses base 10 unless `opt.base` selects another integer base. Invalid or out-of-range text returns `opt.fallback`. The default fallback is `0`.

:example capy render
print(s8("7f", {base: 16}), "\n")

:sig
function u32(value : as string, opt : dval = {}) u32

:params
value : scalar value or text to convert
opt : options map with `fallback` and `base`

:returns
An unsigned 32-bit integer, or `opt.fallback`.

:content
`u32()` parses text in the range 0 through 4294967295. Invalid, negative, or out-of-range text returns `opt.fallback`. The default fallback is `0`.

:example capy render
print(u32("ffffffff", {base: 16}), "\n")
